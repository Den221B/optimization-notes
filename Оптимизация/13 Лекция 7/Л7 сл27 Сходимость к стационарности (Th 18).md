# Л7 сл27 Сходимость к стационарности (Th 18)

> [!abstract] Theorem 18 · [[OptChapter_Lecture7_slides.pdf#page=27|сл. 27–29]]
> Пусть $f$ $L$-гладкая и ограничена снизу, $x_{k+1} = x_k - \frac1L \nabla f(x_k)$. Тогда для любого $K \ge 1$
> $$\min_{0 \le k < K} \|\nabla f(x_k)\|^2 \le \frac{2L\big(f(x_0) - f_{\inf}\big)}{K}.$$
> Выпуклость функции не предполагается.
> **Доказательство.** При $\alpha = \frac1L$: $\frac{1}{2L} \|\nabla f(x_k)\|^2 \le f(x_k) - f(x_{k+1})$. Сумма по $k = 0, \dots, K - 1$ телескопируется:
> $$\frac{1}{2L} \sum_{k=0}^{K-1} \|\nabla f(x_k)\|^2 \le f(x_0) - f(x_K) \le f(x_0) - f_{\inf}.$$
> Дальше $K \min_{0 \le k < K} \|\nabla f(x_k)\|^2 \le \sum_{k=0}^{K-1} \|\nabla f(x_k)\|^2$. С обозначением $\Delta_0 := f(x_0) - f_{\inf}$:
> $$\min_{0 \le k < K} \|\nabla f(x_k)\| \le \sqrt{\frac{2L\Delta_0}{K}}.$$

## На пальцах
$f = \cos x$, $L = 1$, $f_{\inf} = -1$, шаг $\frac1L = 1$: $x^+ = x + \sin x$.

Старт $x_0 = 0{,}5$, $\Delta_0 = \cos 0{,}5 + 1 \approx 1{,}8776$. Модули градиента по шагам: $0{,}479;\ 0{,}830;\ 0{,}972;\ 0{,}353;\ 0{,}008$. Гарантия $\sqrt{2L\Delta_0 / K}$:
- $K = 1$: $1{,}938 \ge 0{,}479$;
- $K = 4$: $0{,}969 \ge \min = 0{,}353$;
- $K = 5$: $0{,}867 \ge 0{,}008$.

На первых шагах градиент **растёт**: точка скатывается со склона всё круче. Теорема это допускает: она про наименьший градиент среди первых $K$, а не про каждый шаг.

Старт $x_0 = 0{,}01$, у самой вершины: $|f'(x_0)| = \sin 0{,}01 \approx 0{,}0099998$, $\Delta_0 \approx 1{,}99995$, и неравенство теоремы выполнено при каждом $K \le 40\,000$ только за счёт точки $x_0$, где $f$ почти максимальна. Малый градиент гарантирован, но он может оказаться градиентом у вершины.

Упрощение: 1D; здесь вся траектория считается по формуле, и гарантия выглядит грубой. Теорема обещает её для любой $L$-гладкой функции.

На что смотреть: по горизонтали — номер шага $k$. Ползунок `a` — старт $x_0$. Оранжевые точки — $|f'(x_k)|$, красные — наименьший из них среди шагов $0, \dots, k$. Синяя — гарантия теоремы для $K = k + 1$ шагов. Красные точки всегда под синей; оранжевые могут быть выше красных — градиент на отдельном шаге не обязан падать. При $a = 0{,}01$ красные лежат почти на нуле с самого начала: малый градиент найден в вершине.
