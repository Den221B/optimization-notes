# Л7 сл30 Итерационная сложность (Утв. 19)

> [!abstract] Утверждение 19 · [[OptChapter_Lecture7_slides.pdf#page=30|сл. 30]]
> Чтобы среди первых $K$ итераций гарантированно существовала точка $x_k$ с $\|\nabla f(x_k)\| \le \varepsilon$, достаточно
> $$K \ge \frac{2L\Delta_0}{\varepsilon^2}.$$
> Следовательно, $K = O(1/\varepsilon^2)$.
> **Что означает эта оценка:** она гарантирует малый градиент. Она не утверждает $f(x_k) - f^\star \le \varepsilon$ и не гарантирует, что найденная точка является локальным или глобальным минимумом.

## На пальцах
Косинус, $L = 1$, GD с шагом $\frac1L = 1$: $x^+ = x + \sin x$; худший старт — у вершины, $\Delta_0 = f(x_0) - f^\star \le 2$. Достаточно $K \ge \frac{2L\Delta_0}{\varepsilon^2} = \frac{4}{\varepsilon^2}$:
- $\varepsilon = 0{,}1$: $K = 400$;
- $\varepsilon = 0{,}01$: $K = 40\,000$.

Точность в $10$ раз выше — шагов в $100$ раз больше: $O(1/\varepsilon^2)$. При сильной выпуклости оценка $O(\kappa \log \frac1\varepsilon)$, и каждый лишний десятичный порядок стоит лишь прибавки около $\kappa \ln 10$ шагов ([[Б21 Геометрическая прогрессия и число шагов]]). Там, правда, $\varepsilon$ — порог для разрыва по значению, а здесь — для нормы градиента; сравнивать можно только характер роста: степенной против логарифмического.

Что не обещано. Из $x_0 = 0$ GD стоит на месте, и уже при $K = 1$ есть точка с $|f'| = 0 \le \varepsilon$ — максимум, где разрыв $f - f^\star = 2$.

Упрощение: оценка для худшего случая. На косинусе из $x_0 = 0{,}5$ градиент меньше $0{,}01$ уже на шаге $4$.

```desmos-graph

---
```

На что смотреть: по горизонтали — $\frac1\varepsilon$, по вертикали — достаточное число шагов $K = \frac{4}{\varepsilon^2}$. Ползунок `v` — $\frac1\varepsilon$. При $v = 10$ точка на высоте $400$, при $v = 100$ — $40\,000$: парабола, а не прямая.
