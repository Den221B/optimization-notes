# Л7 сл58 Сложность под PL

> [!abstract] Следствие · [[OptChapter_Lecture7_slides.pdf#page=58|сл. 58]]
> Из $f(x_k) - f^\star \le (1 - \frac\mu L)^k (f(x_0) - f^\star)$ и $1 - t \le e^{-t}$:
> $$f(x_k) - f^\star \le \exp\Big(-\frac\mu L k\Big) \big(f(x_0) - f^\star\big).$$
> Чтобы достичь $f(x_k) - f^\star \le \varepsilon$, достаточно
> $$k \ge \frac L\mu \log \frac{f(x_0) - f^\star}{\varepsilon}.$$
> Следовательно, $O\big(\frac L\mu \log \frac1\varepsilon\big)$.

Уточнение: условия — как в [[Л7 сл56 Линейная сходимость при PL (Th 28)]], $L > 0$, $0 < \mu \le L$. Формула содержательна при $0 < \varepsilon < \Delta_0 = f(x_0) - f^\star$: при $\varepsilon \ge \Delta_0$ шаги не нужны, при $\Delta_0 = 0$ точка уже оптимальна. Число шагов целое — $k = \big\lceil \frac L\mu \ln \frac{\Delta_0}{\varepsilon} \big\rceil$.

## На пальцах
Тот же пример: $f = x^2 + 3\sin^2 x$, $\frac L\mu = 48$, $\Delta_0 \approx 9{,}06$. Для $f(x_k) - f^\star \le 10^{-6}$ достаточно $k \ge 48 \ln \frac{9{,}06}{10^{-6}} \approx 769$ шагов; на деле хватило $9$. Оценка — для худшего случая в классе, а не для этой функции.

Переход через $1 - t \le e^{-t}$: $\big(\frac{47}{48}\big)^{48} \approx 0{,}364 \le e^{-1} \approx 0{,}368$ — каждые $48$ шагов разрыв гарантированно падает хотя бы в $e$ раз ([[Б21 Геометрическая прогрессия и число шагов]]).

Сравнение с общим невыпуклым случаем — только по характеру роста, потому что $\varepsilon$ там другое. Там $\varepsilon$ — порог для нормы градиента, $K \sim \frac{1}{\varepsilon^2}$, и точность в $10$ раз выше стоит в $100$ раз больше шагов. Здесь $\varepsilon$ — порог для разрыва по значению, и каждый лишний десятичный порядок стоит прибавки $48 \ln 10 \approx 110{,}5$ шага: степенной рост против логарифмического.

Упрощение: в $\log$ слайда — натуральный логарифм.

```desmos-graph
left=0; right=1000;
bottom=-8; top=2;
---
m=0.1667|slider:0.05..1..0.0001
y=\log(9.06)+x\log(1-\frac{m}{8})|red
y=\log(9.06)-\frac{mx}{8\ln(10)}|blue|dashed
y=-6|green|dashed
```
На что смотреть: по горизонтали — шаг $k$, по вертикали — десятичный логарифм гарантии на разрыв. Ползунок `m` — $\mu$ при $L = 8$. Красная — $9{,}06 (1 - \frac m8)^k$, синий пунктир — экспоненциальная оценка $9{,}06\, e^{-mk/8}$, она чуть выше красной. Зелёная — уровень $10^{-6}$. При $m = 0{,}1667$ синяя пересекает его около $k \approx 769$. Вдвое большее `m` — вдвое меньше шагов.
