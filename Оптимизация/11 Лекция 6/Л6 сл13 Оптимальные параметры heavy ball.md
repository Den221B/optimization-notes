# Л6 сл13 Оптимальные параметры heavy ball

> [!abstract] Утверждение · [[OptChapter_Lecture6_slides.pdf#page=13|сл. 13]]
> Из $\sqrt L (1 - q) \le \sqrt\mu (1 + q)$:
> $$q \ge \frac{\sqrt L - \sqrt\mu}{\sqrt L + \sqrt\mu} = \frac{\sqrt\kappa - 1}{\sqrt\kappa + 1}.$$
> Минимум достигается при равенстве, $q^\star = \frac{\sqrt\kappa - 1}{\sqrt\kappa + 1}$. Тогда обе границы для $\alpha$ совпадают:
> $$\alpha^\star = \frac{4}{(\sqrt L + \sqrt\mu)^2}, \qquad \beta^\star = \Big(\frac{\sqrt L - \sqrt\mu}{\sqrt L + \sqrt\mu}\Big)^2 .$$
> При большой $\kappa$: $q^\star = 1 - \Theta(1/\sqrt\kappa)$, тогда как для оптимально настроенного GD характерен масштаб $1 - \Theta(1/\kappa)$.

## На пальцах
Две задачи:
- **Овраг, $\kappa = 9$:** $q^\star = \frac{3 - 1}{3 + 1} = \frac12$, $\alpha^\star = \frac{4}{(3 + 1)^2} = \frac14$, $\beta^\star = \frac14$. У лучшего GD — $0{,}8$ за шаг.
- **$\kappa = 100$** ($\mu = 1$, $L = 100$): $q^\star = \frac{9}{11} \approx 0{,}818$, $\alpha^\star = \frac{4}{121} \approx 0{,}033$, $\beta^\star = \frac{81}{121} \approx 0{,}669$. У лучшего GD — $\frac{99}{101} \approx 0{,}980$.

Считая только по модулю за шаг, тысячекратное уменьшение ошибки: GD — $\frac{\ln 1000}{\ln (101/99)} \approx 345{,}4$, то есть $346$ шагов; шарик — $\frac{\ln 1000}{\ln (11/9)} \approx 34{,}4$, то есть $35$, в $\sqrt\kappa = 10$ раз меньше. Масштабы слайда: $1 - q^\star = \frac{2}{11} \approx 0{,}18$ — порядка $\frac{2}{\sqrt\kappa} = 0{,}2$; у GD $1 - \frac{99}{101} = \frac{2}{101}$ — порядка $\frac2\kappa = 0{,}02$.

Упрощение: здесь счёт только по модулю корней. На концах спектра корень двойной и добавляет множитель $k$: на деле шарику при $\kappa = 100$ нужно $58$ шагов, а не $35$ ([[Л6 сл14 Что доказал квадратичный анализ]]). Всё равно в $6$ раз меньше, чем GD.

На что смотреть: по горизонтали — положение $\lambda$ на спектре: $0$ — это $\mu = 1$, $1$ — это $L = \kappa$ (зелёные линии); по вертикали — множитель за шаг. Оранжевая «галочка» — GD с лучшим шагом $\frac{2}{1 + \kappa}$, красная — модуль корней шарика с $\alpha^\star$, $\beta^\star$. Внутри спектра красная — ровная полка на высоте $q^\star$, за его краями она поднимается. Ползунок `K` — $\kappa$: при $\kappa = 100$ полка на $0{,}818$, а края галочки — на $0{,}980$.
