# Л6 сл10 Heavy ball на квадратичной задаче

> [!abstract] Утверждение · [[OptChapter_Lecture6_slides.pdf#page=10|сл. 10]]
> Для $f(x) = \frac12 x^\top A x - b^\top x$ и ошибки $e_k = x_k - x^\star$:
> $$e_{k+1} = \big((1 + \beta) I - \alpha A\big)\, e_k - \beta e_{k-1}.$$
> В собственных координатах $z_k = Q^\top e_k$: $z^{(i)}_{k+1} = (1 - \alpha\lambda_i + \beta)\, z^{(i)}_k - \beta z^{(i)}_{k-1}$. Для одного собственного значения $\lambda$ — скалярная рекурсия
> $$z_{k+1} = (1 - \alpha\lambda + \beta)\, z_k - \beta z_{k-1}.$$
> Элементарное решение $z_k = r^k$ даёт характеристическое уравнение
> $$r^2 - (1 - \alpha\lambda + \beta)\, r + \beta = 0.$$
> Модули корней задают скорость затухания; комплексно-сопряжённые корни соответствуют затухающим колебаниям.

## На пальцах
Овраг $\frac12 (x^2 + 9y^2)$ плюс третье направление с $\lambda = 5$; $\alpha = \beta = \frac14$, старт $z_0 = 1$, $z_1 = 1 - \alpha\lambda$ (первый шаг без инерции, $v_0 = 0$).
- $\lambda = 1$: $r^2 - r + \frac14 = \big(r - \frac12\big)^2$ — двойной корень $\frac12$; $z_k = 1, \frac34, \frac12, \frac{5}{16}, \frac{3}{16}, \dots = \frac{k + 2}{2^{k+1}}$.
- $\lambda = 5$: $r^2 + \frac14 = 0$ — корни $\pm \frac i2$, модуль $\frac12$; $z_k = 1, -\frac14, -\frac14, \frac{1}{16}, \frac{1}{16}, -\frac{1}{64}, \dots$ — колебания, за каждые два шага в $4$ раза меньше.
- $\lambda = 9$: $r^2 + r + \frac14 = \big(r + \frac12\big)^2$ — двойной корень $-\frac12$; $z_k = 1, -\frac54, 1, -\frac{11}{16}, \frac{7}{16}, \dots = (-1)^k \frac{3k + 2}{2^{k+1}}$ — знак чередуется.

Все три направления затухают с одним модулем корней $\frac12$. У GD с лучшим шагом крайние множители $\pm 0{,}8$: второй параметр $\beta$ выиграл у одного $\alpha$.

Упрощение: здесь каждую рекурсию легко решить явно. В общем случае хватает характеристического уравнения: о скорости говорит модуль корней ([[Б36 Линейная рекурсия второго порядка]]).

На что смотреть: красные точки — $z_k$ для одного собственного значения; ползунки: `s` — шаг $\alpha$, `b` — инерция $\beta$, `l` — собственное значение $\lambda$. Синий пунктир — $\pm\rho^k$, где $\rho$ — больший модуль корня. При $s = b = 0{,}25$ проведи `l` от $1$ до $9$: точки затухают с одной скоростью $\frac12$ — то колеблясь, то нет; на концах $1$ и $9$ корень двойной, и точки лежат выше пунктира на всех шагах: их отношение к $\rho^k$ растёт как $\frac{k + 2}{2}$ и $\frac{3k + 2}{2}$ — это множитель $k$. Сами точки всё равно убывают: $2^{-k}$ побеждает линейный рост. Выведи `l` за $9$, к $12$: модуль корня больше $1$, точки разлетаются.
