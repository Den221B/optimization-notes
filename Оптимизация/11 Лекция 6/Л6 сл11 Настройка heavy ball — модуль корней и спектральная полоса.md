# Л6 сл11 Настройка heavy ball — модуль корней и спектральная полоса

> [!abstract] Утверждение · [[OptChapter_Lecture6_slides.pdf#page=11|сл. 11–12]]
> $\rho_\lambda(\alpha, \beta)$ — максимальный модуль двух корней характеристического многочлена. Цель — минимизировать худший коэффициент затухания по всему спектру:
> $$\min_{\alpha, \beta} \ \max_{\lambda \in [\mu, L]} \rho_\lambda(\alpha, \beta).$$
> Введём желаемый общий модуль корней $q \in (0, 1)$ и положим $\beta = q^2$. Если дискриминант неположителен, корни комплексно-сопряжённые или совпадают, и по теореме Виета их модуль равен $q$. Для $a(\lambda) = 1 - \alpha\lambda + q^2$ требование $\rho_\lambda \le q$ равносильно $a(\lambda)^2 - 4q^2 \le 0$:
> $$-2q \le 1 - \alpha\lambda + q^2 \le 2q \iff (1 - q)^2 \le \alpha\lambda \le (1 + q)^2 .$$
> Для всех $\lambda \in [\mu, L]$ это выполнено тогда и только тогда, когда $(1 - q)^2 \le \alpha\mu$ и $\alpha L \le (1 + q)^2$. Значит, допустимый $\alpha$ существует тогда и только тогда, когда
> $$\frac{(1 - q)^2}{\mu} \le \frac{(1 + q)^2}{L} \iff \sqrt L\, (1 - q) \le \sqrt\mu\, (1 + q).$$

## На пальцах
Овраг: $\mu = 1$, $L = 9$. Возьмём $q = \frac12$, то есть $\beta = \frac14$.
- Полоса $(1 - q)^2 \le \alpha\lambda \le (1 + q)^2$ — это $\frac14 \le \alpha\lambda \le \frac94$. При $\alpha = \frac14$ она ровно $1 \le \lambda \le 9$ — весь спектр оврага, и для каждого $\lambda$ корни комплексные или двойные с модулем $\frac12$.
- Меньший модуль, $q = 0{,}4$, не получится: нужно $0{,}36 \le \alpha \cdot 1$ и $\alpha \cdot 9 \le 1{,}96$, то есть $\alpha \ge 0{,}36$ и $\alpha \le 0{,}218$ — противоречие. Полоса накрывает спектр, только если отношение её краёв $\frac{(1 + q)^2}{(1 - q)^2}$ не меньше $\kappa = 9$: при $q = \frac12$ оно ровно $9$, при $q = 0{,}4$ — около $5{,}4$.
- Вне полосы корни вещественные, и один из них по модулю больше $q$. При $\alpha = \beta = \frac14$: для $\lambda = 12$ корни $\approx -1{,}593$ и $-0{,}157$ — расходимость; для $\lambda = 0{,}5$ — $\approx 0{,}820$ и $0{,}305$, затухание медленнее, чем $\frac12$.

Упрощение: здесь спектр — весь отрезок $[1, 9]$, как будто собственные значения могут быть любыми между $\mu$ и $L$. У конкретной матрицы их конечное число, и настройка «на весь отрезок» — гарантия для худшего случая.

На что смотреть: корни характеристического многочлена на комплексной плоскости, пока $\lambda$ пробегает спектр $[1, 9]$; ползунок `s` — шаг $\alpha$, `b` — $\beta$. Красные дуги — комплексные корни, оранжевые отрезки на оси — вещественные. Синий пунктир — окружность радиуса $\sqrt\beta$, зелёная — единичная. При $s = b = 0{,}25$ все корни на синей окружности радиуса $\frac12$. Уменьши `s` до $0{,}2$: у $\lambda = 1$ корни сходят на ось, правый — около $0{,}685$, затухание хуже. Подними `s` выше $0{,}28$: левый корень выходит за единичную окружность — расходимость.
