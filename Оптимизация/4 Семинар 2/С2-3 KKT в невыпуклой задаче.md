# С2-3 KKT в невыпуклой задаче

> [!question] Условие · семинар 2, [[OptChapter_Sem2_slides.pdf#page=15|сл. 15–23]]
> $\min_{x, y} \ -\frac12 (x + 1)^2 - \frac12 (y + 1)^2$ при $x^2 + y^2 \le 2$, $y \le 1$. Найдите все KKT-точки и определите, какие из них — точки минимума.

> [!success]- Итог семинара — открыть после своей попытки
> Четыре случая по знакам $\lambda_1$, $\lambda_2$. KKT-точки: $(-1, -1)$ с $\lambda = (0, 0)$; $(-1, 1)$ с $\lambda = (0, 2)$; $(1, 1)$ с $\lambda = (1, 0)$; значения $0$, $-2$, $-4$. Глобальный минимум — $(1, 1)$: по Коши–Буняковскому $x + y \le 2$, откуда $f \ge -4$. Две другие KKT-точки не минимумы даже локально: сдвиг $x \to -1 + \varepsilon$ уменьшает $f$. В невыпуклой задаче KKT не гарантируют оптимальность.
