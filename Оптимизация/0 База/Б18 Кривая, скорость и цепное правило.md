# Б18 Кривая, скорость и цепное правило

## Кривая и её скорость
Кривая — отображение $x : (-\varepsilon, \varepsilon) \to \mathbb R^n$, $t \mapsto x(t)$: точка, бегущая во времени. Её **скорость** $x'(t)$ — вектор из производных координат; если $x'(t) \ne 0$, он касается кривой. $C^1$-кривая — кривая с непрерывной $x'$.

Прямая $x + tv$ из [[Б8 Градиент и сужение на прямую]] — частный случай: скорость постоянна и равна $v$. В лекции 1 мы двигались по прямым внутри выпуклого $C$; в лекции 2 допустимое множество бывает кривым (окружность, сфера), прямые из него сразу выходят, и приходится двигаться по кривым ([[OptChapter_Lecture2_slides.pdf#page=9|сл. 9]]).

## Цепное правило
Для дифференцируемой $f$
$$\frac{d}{dt} f(x(t)) = \nabla f(x(t))^\top x'(t), \qquad \frac{d}{dt} f(x(t)) \Big|_{t = 0} = \nabla f(x(0))^\top x'(0).$$
Скорость изменения $f$ вдоль кривой зависит только от того, где точка и с какой скоростью она бежит в данный момент, а не от того, как кривая изогнута дальше.

## Два следствия, на которых стоит лекция 2
1. **Градиент перпендикулярен линии уровня.** Если кривая лежит на множестве $\{h = c\}$, то $h(x(t)) \equiv c$, и производная равна нулю: $\nabla h(x(t))^\top x'(t) = 0$. Так на [[OptChapter_Lecture2_slides.pdf#page=10|сл. 10]] получают условие $\nabla h_j(x^\star)^\top d = 0$.
2. **В минимуме вдоль кривой производная ноль.** Пусть кривая проходит через $x^\star$ при $t = 0$ и определена при $t$ обоих знаков. Если $t = 0$ — точка минимума $f(x(t))$, то $\nabla f(x^\star)^\top x'(0) = 0$ ([[OptChapter_Lecture2_slides.pdf#page=13|сл. 13]]).

## Линеаризация
Дифференцируемость ([[Б8 Градиент и сужение на прямую]]) значит $h(x + d) = h(x) + \nabla h(x)^\top d + o(\|d\|)$.
- Равенство: если $h(x) = 0$, то шаг $d$ сохраняет его в первом приближении, когда $\nabla h(x)^\top d = 0$.
- Активное неравенство: если $s(x) = 0$, то шаг $d$ не выводит наружу в первом приближении, когда $\nabla s(x)^\top d \le 0$ ([[OptChapter_Lecture2_slides.pdf#page=24|сл. 24]]).

«В первом приближении» — главная оговорка. Если $\nabla h(x) = 0$, линейная часть пропадает, и линеаризация ничего не видит.

## На пальцах
Единичная окружность $h = x^2 + y^2 - 1$, точка бежит по ней: $x(t) = (\cos t, \sin t)$. Момент, когда она в $P = (0{,}6;\ 0{,}8)$:
- точка всё время на окружности, значит, $h(x(t)) \equiv 0$ и $\frac{d}{dt} h(x(t)) = 0$; по цепному правилу это $\nabla h^\top x' = 0$;
- проверим числами: скорость $x' = (-\sin t, \cos t) = (-0{,}8;\ 0{,}6)$ — по касательной, против часовой стрелки; $\nabla h(P) = (2x, 2y) = (1{,}2;\ 1{,}6)$ — по радиусу наружу; $\nabla h^\top x' = -0{,}96 + 0{,}96 = 0$: градиент перпендикулярен скорости, то есть касательной;
- для $f = x + y$: $\nabla f^\top x' = (1, 1)^\top (-0{,}8;\ 0{,}6) = -0{,}2$. Напрямую: $f(x(t)) = \cos t + \sin t$, производная $-\sin t + \cos t = -0{,}8 + 0{,}6 = -0{,}2$. Совпало.

Упрощение: в 2D касательная к кривой — одна прямая. В $\mathbb R^n$ через точку поверхности проходит много кривых, и их скорости заполняют целое касательное подпространство.

## Проверь себя
1. Кривая $x(t) = (t, t^2)$, функция $f(x, y) = x^2 + y$. Найдите $\frac{d}{dt} f(x(t))$ при $t = 1$ двумя способами.
2. $h = x^2 + y^2 - 1$, точка $(1, 0)$. Какие из направлений $(0, 1)$ и $(1, 1)$ удовлетворяют $\nabla h^\top d = 0$?

> [!success]- Ответы
> 1. Через градиент: $\nabla f = (2x, 1) = (2, 1)$, $x'(1) = (1, 2t) = (1, 2)$, произведение $2 + 2 = 4$. Напрямую: $f(x(t)) = t^2 + t^2 = 2t^2$, производная $4t = 4$.
> 2. $\nabla h(1, 0) = (2, 0)$. Для $(0, 1)$: $0$ — подходит, это касательная. Для $(1, 1)$: $2 \ne 0$ — нет.
