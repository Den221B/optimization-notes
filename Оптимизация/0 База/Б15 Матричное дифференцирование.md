# Б15 Матричное дифференцирование

Градиенты и гессианы, которые в лекции и семинаре берутся «в одну строку».

## Таблица
- $f(x) = a^\top x + b$: $\nabla f = a$, $\nabla^2 f = 0$.
- $f(x) = \tfrac12 \|x\|_2^2$: $\nabla f = x$, $\nabla^2 f = I$.
- $f(x) = \tfrac12 x^\top A x$, $A = A^\top$: $\nabla f = A x$, $\nabla^2 f = A$.
- $f(x) = \tfrac12 x^\top A x - b^\top x + c$: $\nabla f = A x - b$, $\nabla^2 f = A$ ([[OptChapter_Lecture1_slides.pdf#page=47|сл. 47]]).
- $f(x) = \tfrac12 \|A x - b\|_2^2$: $\nabla f = A^\top (A x - b)$, $\nabla^2 f = A^\top A$ ([[OptChapter_Lecture1_slides.pdf#page=50|сл. 50]]).
- $g(x) = f(A x + b)$: $\nabla g(x) = A^\top \nabla f(A x + b)$, $\nabla^2 g(x) = A^\top \nabla^2 f(A x + b) \, A$.

Множитель $\tfrac12$ ставят, чтобы при дифференцировании квадрата не появлялась двойка.

## Как проверить по координатам (2×2)
$A = \begin{pmatrix} a & b \\ b & c \end{pmatrix}$, $\tfrac12 x^\top A x = \tfrac12 (a x_1^2 + 2 b x_1 x_2 + c x_2^2)$.
Частные производные: $\partial / \partial x_1 = a x_1 + b x_2$, $\partial / \partial x_2 = b x_1 + c x_2$ — это и есть $A x$.

## Откуда $\nabla \tfrac12 \|A x - b\|^2$
Раскроем: $\tfrac12 (A x - b)^\top (A x - b) = \tfrac12 x^\top A^\top A x - (A^\top b)^\top x + \tfrac12 b^\top b$. Это квадратичная функция с матрицей $A^\top A$ и линейной частью $(A^\top b)^\top x$; по таблице $\nabla f = A^\top A x - A^\top b$ (семинар, задача 7a).

## На пальцах
Возьми $n = 1$ — формулы таблицы станут школьными:
- $\tfrac12 a x^2 \to a x$ — это $\tfrac12 x^\top A x \to A x$;
- $\tfrac12 (a x - b)^2 \to a (a x - b)$ — это $\tfrac12 \|A x - b\|^2 \to A^\top (A x - b)$.

Проверка $n = 1$ ловит потерянный множитель или $\tfrac12$, но **не** порядок множителей и не $\top$: при $n = 1$ их не видно, и ошибочное $A(Ax - b)$ тоже превратится в $a(ax - b)$. Порядок и $\top$ проверяй размерностями: $A^\top (Ax - b)$ — это $(n \times m)(m \times 1)$, столбец длины $n$, как и $x$; а $A(Ax - b)$ при $m \ne n$ просто не определено.

## Проверь себя
Найдите градиент и гессиан $F(x) = \tfrac12 \|A x - b\|^2 + \tfrac{\lambda}{2} \|x\|^2$.

> [!success]- Ответ
> $\nabla F = A^\top (A x - b) + \lambda x$, $\nabla^2 F = A^\top A + \lambda I$ ([[OptChapter_Lecture1_slides.pdf#page=51|сл. 51]]).
