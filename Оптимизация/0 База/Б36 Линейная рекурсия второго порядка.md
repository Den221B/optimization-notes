# Б36 Линейная рекурсия второго порядка

## Суть
Последовательность задана двумя начальными значениями $z_0$, $z_1$ и правилом
$$z_{k+1} = a\, z_k - \beta\, z_{k-1}.$$
Подстановка $z_k = r^k$ даёт $r^{k+1} = a r^k - \beta r^{k-1}$, то есть **характеристическое уравнение**
$$r^2 - a r + \beta = 0, \qquad r_1 + r_2 = a, \quad r_1 r_2 = \beta \quad \text{(теорема Виета).}$$
Три случая:
- **разные вещественные корни** ($a^2 > 4\beta$): $z_k = C_1 r_1^k + C_2 r_2^k$;
- **комплексно-сопряжённые корни** ($a^2 < 4\beta$): $r_{1,2} = \rho\, e^{\pm i\theta}$. Произведение сопряжённых чисел — квадрат модуля, $r_1 r_2 = \rho^2 = \beta$, поэтому **модуль обоих корней $\sqrt\beta$**, каким бы ни было $a$. Решение $z_k = \rho^k (A \cos k\theta + B \sin k\theta)$ — затухающие колебания;
- **двойной корень** ($a^2 = 4\beta$): $r = \frac a2$, $z_k = (C_1 + C_2 k)\, r^k$ — появляется лишний множитель $k$.

Константы находятся из $z_0$ и $z_1$. **Скорость задаёт больший модуль корня:** при $\max |r_i| < 1$ последовательность стремится к нулю, при $\max |r_i| > 1$ — в общем случае разбегается.

**Матричная запись.** $\begin{pmatrix} z_{k+1} \\ z_k \end{pmatrix} = \begin{pmatrix} a & -\beta \\ 1 & 0 \end{pmatrix} \begin{pmatrix} z_k \\ z_{k-1} \end{pmatrix}$: двухшаговая рекурсия — одношаговая в удвоенном состоянии $(z_k, z_{k-1})$. Её корни — собственные значения этой матрицы: $\det \begin{pmatrix} a - r & -\beta \\ 1 & -r \end{pmatrix} = r^2 - a r + \beta$.

## Зачем это лекции
Тяжёлый шарик в каждом собственном направлении квадратичной задачи — именно такая рекурсия: $z_{k+1} = (1 - \alpha\lambda + \beta)\, z_k - \beta z_{k-1}$, то есть $a = 1 - \alpha\lambda + \beta$ ([[Л6 сл10 Heavy ball на квадратичной задаче]]). Вся настройка параметров ([[Л6 сл11 Настройка heavy ball — модуль корней и спектральная полоса]]) — требование «корни комплексные, значит, их модуль $\sqrt\beta$» сразу для всех $\lambda \in [\mu, L]$. Метод Нестерова с постоянным коэффициентом на квадратичной задаче даёт такую же рекурсию ([[Л6 сл26 Нестеров в сильно выпуклом случае]]).

## На пальцах
$z_{k+1} = z_k - \frac12 z_{k-1}$, $z_0 = z_1 = 1$:
$$1,\ 1,\ \tfrac12,\ 0,\ -\tfrac14,\ -\tfrac14,\ -\tfrac18,\ 0,\ \tfrac{1}{16},\ \dots$$
Корни $r^2 - r + \frac12 = 0$: $r = \frac{1 \pm i}{2}$, модуль $\sqrt{\frac12} \approx 0{,}707 = \sqrt\beta$. Это видно и без комплексных чисел: знаки повторяются с периодом $8$ (угол $\theta = 45^\circ$), а через $8$ шагов все значения ровно в $16$ раз меньше, $z_{k+8} = \frac{z_k}{16}$, — по $0{,}707$ за шаг, потому что $0{,}707^8 = \frac{1}{16}$.
- **Вещественные корни:** $z_{k+1} = 0{,}75\, z_k - 0{,}125\, z_{k-1}$. Корни $\frac12$ и $\frac14$: сумма $0{,}75$, произведение $0{,}125$. Колебаний нет, затухание — как $\big(\frac12\big)^k$.
- **Двойной корень:** $z_{k+1} = z_k - \frac14 z_{k-1}$, $z_0 = 1$, $z_1 = \frac34$. Здесь $z_k = \frac{k + 2}{2^{k+1}}$. Модуль корня $\frac12$, но при $k = 10$ значение $\frac{12}{2048} \approx 0{,}0059$ — в $6$ раз больше, чем $\big(\frac12\big)^{10} \approx 0{,}00098$: так проявляется множитель $k$.

Упрощение: здесь одна рекурсия. В тяжёлом шарике их столько, сколько собственных значений у матрицы $A$; у каждой своё $a = 1 - \alpha\lambda + \beta$, а $\beta$ общий — поэтому все направления с комплексными корнями затухают с одним и тем же модулем $\sqrt\beta$.

На что смотреть: красные точки — $z_k$ при $z_0 = z_1 = 1$, ползунки — $a$ и $\beta$ (в графике буква `b`). Синий пунктир — огибающая $\pm R\, (\sqrt\beta)^k$ с амплитудой $R$, рассчитанной по $z_0$, $z_1$; она есть только при комплексных корнях, $a^2 < 4\beta$. При $a = 1$, $\beta = \frac12$ точки качаются между пунктирами и касаются их. Двигай $a$ к $\pm 2\sqrt\beta$: корни становятся вещественными, пунктир исчезает, колебания пропадают. Увеличивай $\beta$ к $1$: затухание почти останавливается.

## Проверь себя
1. Найдите корни и скорость затухания для $z_{k+1} = z_k - 0{,}21\, z_{k-1}$.
2. При каких $\beta$ корни уравнения $r^2 - r + \beta = 0$ комплексные? Каков их модуль при $\beta = 0{,}81$?
3. Почему $z_{k+1} = 2 z_k - z_{k-1}$ не затухает ни при каких $z_0$, $z_1$, кроме нулевых?

> [!success]- Ответы
> 1. $r^2 - r + 0{,}21 = 0$: корни $0{,}7$ и $0{,}3$ (сумма $1$, произведение $0{,}21$). Затухание как $0{,}7^k$.
> 2. Дискриминант $1 - 4\beta < 0 \iff \beta > \frac14$. При $\beta = 0{,}81$ модуль $\sqrt{0{,}81} = 0{,}9$.
> 3. $r^2 - 2r + 1 = (r - 1)^2$ — двойной корень $1$, и $z_k = C_1 + C_2 k$: арифметическая прогрессия. Она постоянна или растёт по модулю, к нулю не стремится.
