# Б22 Метод касательных и парабола — мост к лекции 3

Градиентный спуск и метод касательных знакомы по матанализу. **Лекция 3 — это один вопрос: какую параболу подставить вместо функции и насколько ей доверять.** Градиентный спуск берёт параболу с угаданной кривизной, метод Ньютона — с настоящей, квазиньютоновские методы — с кривизной, восстановленной по прошлым шагам.

## Метод касательных из матана
Чтобы решить уравнение $\varphi(x) = 0$, проводят касательную к графику $\varphi$ в текущей точке и берут её пересечение с осью:
$$x^+ = x - \frac{\varphi(x)}{\varphi'(x)}.$$
Минимум гладкой $f$ — корень уравнения $f'(x) = 0$. Метод касательных для $\varphi = f'$:
$$x^+ = x - \frac{f'(x)}{f''(x)}.$$
Это и есть метод Ньютона для минимизации ([[OptChapter_Lecture3_slides.pdf#page=25|сл. 25]] лекции 3).

## Та же формула — вершина параболы
Формула Тейлора второго порядка ([[Б9 Гессиан]]): около точки $x$
$$f(x + p) \approx m(p) = f(x) + f'(x)\, p + \tfrac12 f''(x)\, p^2 .$$
При $f''(x) > 0$ это парабола ветвями вверх, её вершина — в $p = -\frac{f'(x)}{f''(x)}$ (школьное $-\frac{b}{2a}$). Шаг в вершину — тот же шаг Ньютона: **метод Ньютона прыгает в минимум параболы, которая в точке $x$ совпадает с $f$ до второй производной.**

## Градиентный спуск — та же парабола с угаданной кривизной
Подставим вместо настоящей кривизны $f''(x)$ число $\frac{1}{\alpha}$:
$$m_\alpha(p) = f(x) + f'(x)\, p + \frac{1}{2\alpha} p^2, \qquad \text{вершина } p = -\alpha f'(x).$$
Получился градиентный шаг $x^+ = x - \alpha f'(x)$. Шаг $\alpha = \frac1L$ ([[OptChapter_Lecture3_slides.pdf#page=11|сл. 11]]) — это парабола с кривизной $L$, самой большой из возможных. Она лежит не ниже $f$ (лемма о спуске), поэтому шаг в её вершину никогда не повышает $f$, но там, где настоящая кривизна меньше $L$, он слишком осторожен.

В $\mathbb R^n$ то же самое с градиентом и гессианом:
$$m(p) = f(x) + \nabla f(x)^\top p + \tfrac12 p^\top H p, \qquad \nabla m = \nabla f(x) + H p = 0 \iff H p = -\nabla f(x).$$
Ньютон берёт $H = \nabla^2 f(x)$, градиентный спуск — $H = \frac{1}{\alpha} I$, одинаковую кривизну во все стороны.

## Что лекция добавляет
1. **Скорость.** Насколько быстро сходится каждый метод и от чего это зависит: у градиентного — от $\kappa = L / \mu$, у Ньютона — квадратично, но только вблизи решения → [[Л3 сл17 Линейная сходимость и число обусловленности]], [[Л3 сл27 Локальная квадратичная сходимость (Th 7)]].
2. **Когда парабола врёт.** Далеко от решения или при невыпуклой $f$ вершина параболы может оказаться плохой точкой → [[Л3 сл29 Полный шаг далеко от решения]], [[Л3 сл30 Ньютон при неопределённом гессиане]].
3. **Цена.** Гессиан хранить и обращать дорого → [[Б23 Стоимость операций линейной алгебры]], [[Л3 сл44 Сравнение методов]].
4. **Кривизна без гессиана.** Её можно восстановить по изменению градиента — квазиньютоновские методы → [[Л3 сл34 Изменение градиента несёт кривизну]].

## На пальцах
$f(x) = x - \ln x$ при $x > 0$, минимум в $x^\star = 1$: $f' = 1 - \frac1x$, $f'' = \frac{1}{x^2}$.
- Из $x = 0{,}5$: $f' = -1$, $f'' = 4$. Парабола $m(p) = f(0{,}5) - p + 2p^2$, вершина в $p = \frac14$, шаг в $x^+ = 0{,}75$.
- Формула касательных даёт то же: $x^+ = x - \frac{1 - 1/x}{1/x^2} = 2x - x^2 = 1 - 0{,}25 = 0{,}75$.
- Ошибка ровно возводится в квадрат: $1 - x^+ = (1 - x)^2$. Ошибки по шагам $0{,}5 \to 0{,}25 \to 0{,}0625 \to 0{,}0039$ — число верных знаков удваивается.
- Градиентный шаг с $\alpha = \frac14$ угадывает кривизну $4$ — здесь угадал верно: $0{,}5 + \frac14 \cdot 1 = 0{,}75$, тот же шаг.
- Но из $x = 2$ Ньютон даёт $x^+ = 4 - 4 = 0$ — на границу области $x > 0$: кривизна $f'' = 0{,}25$ мала, парабола широкая, и её вершина улетает далеко. Градиентный шаг с той же $\alpha = \frac14$ держит узкую параболу кривизны $4$: $2 - \frac14 \cdot 0{,}5 = 1{,}875$ — осторожно, но не вылетает.

Упрощение: в 1D «кривизна» — одно число $f''$. В $\mathbb R^n$ это гессиан, и кривизна в разные стороны разная — тут градиентный спуск со своей одинаковой кривизной и проигрывает.

На что смотреть: ползунок $a$ — текущая точка. Синий пунктир — парабола $m$, касающаяся графика в $a$ вместе с кривизной; красная точка — её вершина, это следующая точка Ньютона $2a - a^2$. При $a = 0{,}5$ вершина в $0{,}75$, рядом с минимумом. Тяни $a$ к $2$: парабола расширяется, и вершина уходит к нулю.

## Проверь себя
1. Сделайте один шаг Ньютона для $f(x) = x^2 + x^4$ из $x = 1$. Сравните с градиентным шагом $\alpha = \frac{1}{14}$.
2. Какой кривизне соответствует градиентный шаг $\alpha = 0{,}1$?

> [!success]- Ответы
> 1. $f' = 2x + 4x^3 = 6$, $f'' = 2 + 12x^2 = 14$. Ньютон: $x^+ = 1 - \frac{6}{14} = \frac47 \approx 0{,}571$. Градиентный шаг с $\alpha = \frac{1}{14}$ — тот же: в этой точке угаданная кривизна совпала с настоящей. В следующей точке они разойдутся: настоящая кривизна уменьшится, а $\alpha$ останется прежним.
> 2. $\frac{1}{\alpha} = 10$: шаг ведёт в вершину параболы с кривизной $10$.
