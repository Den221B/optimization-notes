# Б40 Оба корня внутри единичного круга — треугольник устойчивости

## Суть
Многочлен $p(r) = r^2 - a r + \beta$ с вещественными $a$, $\beta$ — характеристический многочлен рекурсии $z_{k+1} = a z_k - \beta z_{k-1}$ ([[Б36 Линейная рекурсия второго порядка]]). Рекурсия затухает при любых $z_0$, $z_1$ ровно тогда, когда оба корня по модулю меньше $1$. Это равносильно трём неравенствам на коэффициенты:
$$|\beta| < 1, \qquad p(1) = 1 - a + \beta > 0, \qquad p(-1) = 1 + a + \beta > 0,$$
то есть $|\beta| < 1$ и $|a| < 1 + \beta$. На плоскости $(a, \beta)$ это открытый треугольник с вершинами $(-2, 1)$, $(2, 1)$, $(0, -1)$ — **треугольник устойчивости**. Корни считать не нужно.

**Зачем каждое условие.**
- $|\beta| < 1$. По теореме Виета $\beta = r_1 r_2$; если $|r_1| < 1$ и $|r_2| < 1$, то $|\beta| < 1$.
- $p(1) > 0$. Здесь $p(1) = (1 - r_1)(1 - r_2)$. У вещественных корней из $(-1, 1)$ оба множителя положительны. У комплексно-сопряжённых $p(1) = |1 - r_1|^2 > 0$. При $p(1) = 0$ один корень равен $1$, и его составляющая $C \cdot 1^k$ не затухает.
- $p(-1) > 0$. Здесь $p(-1) = (1 + r_1)(1 + r_2)$, рассуждение то же. При $p(-1) = 0$ один корень равен $-1$: составляющая $C (-1)^k$ качается без затухания.

**Почему этого достаточно.**
- Комплексные корни: $|r_1|^2 = r_1 \bar r_1 = r_1 r_2 = \beta < 1$.
- Вещественные корни: между ними парабола $p$ отрицательна. Раз $p(1) > 0$ и $p(-1) > 0$, ни $1$, ни $-1$ между корнями не лежат. Остаются три расклада: оба корня в $(-1, 1)$, оба больше $1$, оба меньше $-1$. В двух последних $|r_1 r_2| > 1$, а это противоречит $|\beta| < 1$.

**Где корни комплексные.** При $a^2 < 4\beta$, то есть над параболой $\beta = \frac{a^2}{4}$. Её дуга при $|a| < 2$ лежит внутри треугольника, потому что $\frac{a^2}{4} - (|a| - 1) = \frac{(|a| - 2)^2}{4} > 0$. В вершинах $(\pm 2, 1)$ парабола касается боковых сторон: наклон параболы $\frac a2 = \pm 1$ совпадает с наклоном сторон $\beta = \pm a - 1$. Значит, при $\beta < 1$ комплексные корни всегда внутри круга, а их модуль равен $\sqrt\beta$. Под параболой корни вещественные.

## Зачем это лекции
У тяжёлого шарика на $f = \frac\lambda2 x^2$ коэффициент $a = 1 - \alpha\lambda + \beta$. Тогда $p(1) = \alpha\lambda$, $p(-1) = 2(1 + \beta) - \alpha\lambda$, и треугольник превращается в условие устойчивости семинара: $0 \le \beta < 1$, $0 < \alpha\lambda < 2(1 + \beta)$ ([[С6-1 Устойчивость метода тяжёлого шарика]]). При $\beta = 0$ получается условие градиентного спуска $|1 - \alpha\lambda| < 1$.

Лекция ([[Л6 сл11 Настройка heavy ball — модуль корней и спектральная полоса]]) работает только над параболой: там модуль корней равен $\sqrt\beta$, и по нему настраивают скорость. Треугольник отвечает на другой вопрос — сходится ли метод вообще, в том числе при вещественных корнях.

## На пальцах
Рекурсия $z_{k+1} = a z_k - \frac12 z_{k-1}$: зафиксируем $\beta = \frac12$ и будем менять $a$. Внутри треугольника это отрезок $|a| < 1{,}5$.
- $a = 1$: $p(r) = r^2 - r + \frac12$. Здесь $p(1) = \frac12$ и $p(-1) = \frac52$ — точка внутри. Корни $\frac{1 \pm i}{2}$ с модулем $\sqrt{\frac12} \approx 0{,}707$ — это пример из [[Б36 Линейная рекурсия второго порядка]].
- $a = 1{,}5$: $p(1) = 0$ и $p(r) = (r - 1)(r - \frac12)$. Корень $1$ лежит на окружности, поэтому $z_k = C_1 + C_2 \big(\frac12\big)^k \to C_1$. При $C_1 \ne 0$ предел ненулевой — затухания для любых $z_0$, $z_1$ нет.
- $a = 1{,}6$: $p(1) = -0{,}1 < 0$. Корни $\approx 0{,}426$ и $\approx 1{,}174$, и единица лежит между ними. Один корень снаружи — рекурсия разбегается.
- $a = -1{,}5$: $p(-1) = 0$, корни $-1$ и $-\frac12$. Составляющая $(-1)^k$ качает знак и не затухает.

Что ломается без условия $|\beta| < 1$: у $(r - 2)(r - 3) = r^2 - 5r + 6$ значения $p(1) = 2$ и $p(-1) = 12$ положительны, но оба корня за единицей. Выдаёт их только $\beta = 6 > 1$.

Упрощение: коэффициенты вещественные. Тогда комплексные корни сопряжены, и модуль одного равен модулю другого. Для многочлена с комплексными коэффициентами треугольник не работает. Неравенства строгие: на сторонах треугольника есть корень $\pm 1$ или $|r_1 r_2| = 1$, и затухания нет.

Ползунок `a` задаёт коэффициент $a$, ползунок `b` — свободный член $\beta$, красная точка — $(a, \beta)$. Синий пунктир — парабола $\beta = \frac{a^2}{4}$: над ней корни комплексные с модулем $\sqrt\beta$, под ней вещественные. При `b` $= 0{,}5$ веди `a` от $1$ к $1{,}6$: на $1{,}5$ точка выходит через правую сторону, где корень равен $1$. Опусти `b` до $-1$: треугольник сходится в вершину $(0, -1)$, где $p(r) = r^2 - 1$ и корни $\pm 1$.

## Проверь себя
1. Затухает ли $z_{k+1} = \frac12 z_k + \frac12 z_{k-1}$ при любых $z_0$, $z_1$?
2. При каких $a$ оба корня $r^2 - a r + \frac14$ лежат внутри единичного круга? При каких из них корни комплексные?
3. Тяжёлый шарик с $\beta = 0{,}9$: до какого $\alpha\lambda$ он устойчив и во сколько раз эта граница больше, чем у градиентного спуска?

> [!success]- Ответы
> 1. Нет. Здесь $a = \frac12$, $\beta = -\frac12$, и $p(1) = 1 - \frac12 - \frac12 = 0$: $p(r) = (r - 1)(r + \frac12)$. Есть корень $1$, поэтому $z_k$ стремится к константе $C_1$, в общем случае ненулевой.
> 2. $|a| < 1 + \frac14 = \frac54$. Комплексные корни — при $a^2 < 4 \cdot \frac14$, то есть $|a| < 1$, с модулем $\frac12$. При $1 \le |a| < \frac54$ корни вещественные, но тоже внутри.
> 3. $\alpha\lambda < 2(1 + 0{,}9) = 3{,}8$ — в $1{,}9$ раза больше границы $2$ у градиентного спуска.
