# Б1 Скалярное произведение

## Суть
Для $x, y \in \mathbb R^n$
$$x^\top y = \sum_{i=1}^n x_i y_i .$$
Запись $x^\top y$ — «строка на столбец»; в других курсах то же самое пишут $(x, y)$ или $\langle x, y \rangle$.

Геометрический смысл:
$$x^\top y = \|x\|_2 \, \|y\|_2 \cos\varphi ,$$
где $\varphi$ — угол между векторами. Поэтому **знак** скалярного произведения говорит об угле:
- $x^\top y > 0$ — угол острый, векторы смотрят «в одну сторону»;
- $x^\top y = 0$ — перпендикулярны;
- $x^\top y < 0$ — угол тупой.

Почти все «геометрические» фразы лекции — про знак скалярного произведения.

## Гиперплоскость и полупространство
- $\{x : a^\top x = b\}$ — гиперплоскость (в $\mathbb R^2$ прямая, в $\mathbb R^3$ плоскость), $a$ — нормаль к ней.
- $\{x : a^\top x \le b\}$ — полупространство: всё по одну сторону от гиперплоскости, включая её саму.

Пример: $a = (1, 1)$, $b = 1$. Множество $x_1 + x_2 \le 1$ — полуплоскость под прямой $x_1 + x_2 = 1$.

## Линейность
$$a^\top (\theta x + (1 - \theta) y) = \theta \, a^\top x + (1 - \theta) \, a^\top y .$$
В этом равенстве весь «секрет» выпуклости полупространства ([[OptChapter_Lecture1_slides.pdf#page=7|сл. 7]]) и аффинной функции ([[OptChapter_Lecture1_slides.pdf#page=13|сл. 13]]).

## На пальцах
Склон и шаг. Пусть $g = \nabla f(x) = (1, 0)$: круче всего склон поднимается на восток. Шаг $d$ меняет высоту примерно на $g^\top d = \|g\| \|d\| \cos\varphi$ — для малого шага; на большом склон успевает измениться.
- $d = (1, 1)$, угол $45^\circ$, острый: $g^\top d = 1 > 0$ — вверх;
- $d = (0, 1)$, угол $90^\circ$: $0$ — вдоль склона, высота не меняется;
- $d = (-1, 1)$, угол $135^\circ$, тупой: $-1 < 0$ — вниз.

Отсюда фраза лекции: $\nabla f(x)^\top d < 0$ — тупой угол с градиентом, малый шаг вдоль $d$ ведёт вниз.

## Проверь себя
1. Найдите $x^\top y$ для $x = (1, 2, -1)$, $y = (3, 0, 3)$. Какой угол между ними?
2. Нарисуйте $\{x \in \mathbb R^2 : -x_1 + x_2 \le 0\}$.

> [!success]- Ответы
> 1. $3 + 0 - 3 = 0$ — векторы перпендикулярны.
> 2. Это $x_2 \le x_1$: полуплоскость под биссектрисой $x_2 = x_1$, включая её.
