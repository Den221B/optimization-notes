# Б13 Липшицевость

## Суть
Функция одной переменной $g$ называется **$L$-липшицевой**, если
$$|g(x) - g(y)| \le L \, |x - y| \quad \forall x, y .$$
Смысл: **наклон любой хорды графика $g$ по модулю не больше $L$**. Функция не может меняться быстрее, чем со скоростью $L$.

Для дифференцируемой $g$ на интервале: $L$-липшицева $\iff |g'(x)| \le L$ всюду (теорема Лагранжа о среднем).

## Примеры
- $\sin x$ — 1-липшицева, потому что $|\cos x| \le 1$.
- $|x|$ — 1-липшицева, хотя в нуле не дифференцируема.
- $x^2$ на $\mathbb R$ — не липшицева: наклон $2x$ неограничен.
- $\sqrt{x}$ на $[0, 1]$ — не липшицева: в нуле вертикальная касательная.

## Для векторных отображений
$G : \mathbb R^n \to \mathbb R^m$ — $L$-липшицево, если $\|G(x) - G(y)\| \le L \|x - y\|$.

## $L$-гладкость = липшицевость градиента
Def 11: $\|\nabla f(x) - \nabla f(y)\|_2 \le L \|x - y\|_2$. В одномерном случае это «$f'$ липшицева», то есть $|f''| \le L$: **кривизна ограничена**. Гладкость — потолок для кривизны, выпуклость — пол.

Пример: у $f(x) = \log(1 + e^x)$ вторая производная $f'' = \frac{e^x}{(1 + e^x)^2} \le \frac14$, поэтому $f$ является $\tfrac14$-гладкой (семинар, задача 5c). А $x^4$ на $\mathbb R$ не гладкая ни с каким $L$: $f'' = 12x^2$ неограничена.

## На пальцах
Ограничитель скорости. Машина едет с ограничителем $L = 60$ км/ч: за 2 часа она уедет не дальше чем на $120$ км. Это $|g(x) - g(y)| \le L |x - y|$, где $g$ — положение, $x, y$ — моменты времени. Липшицево само положение, $L$ — предел скорости.

$L$-гладкость — то же самое на ступень выше: $f$ — положение, $f'$ — скорость, и липшицева уже скорость, $|f'(x) - f'(y)| \le L|x - y|$, то есть $L$ — предел ускорения. Ускорение не больше $2$ м/с²: за 5 с скорость изменится не больше чем на $10$ м/с. Так устроена $f = x^2$: $f'' = 2$, $L = 2$. Излом, как у $|x|$ в нуле, запрещён: это мяч, отскочивший от стены, — скорость мгновенно меняется с $-1$ на $+1$.

## Проверь себя
1. Является ли $f(x) = \tfrac12 x^2$ $L$-гладкой? С каким наименьшим $L$?
2. А $f(x) = |x| + x^2$?

> [!success]- Ответы
> 1. $f' = x$ — 1-липшицева, наименьшее $L = 1$.
> 2. В нуле у $|x| + x^2$ нет производной, поэтому $L$-гладкой она не является ни при каком $L$. Её выпуклость — контрольный вопрос в [[00 Оптимизация — маршрут]].
