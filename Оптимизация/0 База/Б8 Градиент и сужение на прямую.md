# Б8 Градиент и сужение на прямую

## Градиент и дифференцируемость
Градиент — столбец частных производных:
$$\nabla f(x) = \Big( \frac{\partial f}{\partial x_1}, \dots, \frac{\partial f}{\partial x_n} \Big)^\top .$$
$f$ **дифференцируема** в $x$, если вблизи $x$ она почти аффинная:
$$f(x + h) = f(x) + \nabla f(x)^\top h + o(\|h\|).$$
Касательная плоскость — это $f(x) + \nabla f(x)^\top (y - x)$. В Th 7 она станет нижней оценкой выпуклой функции.

## Главный приём лекции: сужение на прямую
Зафиксируем точку $x$ и направление $v$ и рассмотрим функцию **одной** переменной
$$\varphi(t) = f(x + t v).$$
Это разрез графика $f$ вертикальной плоскостью вдоль прямой. По цепному правилу
$$\varphi'(t) = \nabla f(x + t v)^\top v, \qquad \varphi'(0) = \nabla f(x)^\top v .$$
$\varphi'(0)$ — **производная по направлению** $v$: скорость изменения $f$, если выйти из $x$ со скоростью $v$.

Зачем это нужно: многомерные утверждения доказываются по схеме «сузили на прямую → применили школьный факт про функцию одной переменной → вернулись». Так устроены [[OptChapter_Lecture1_slides.pdf#page=12|сл. 12]], [[OptChapter_Lecture1_slides.pdf#page=21|21]], [[OptChapter_Lecture1_slides.pdf#page=26|26]], [[OptChapter_Lecture1_slides.pdf#page=28|28–30]], [[OptChapter_Lecture1_slides.pdf#page=43|43]].

## Направление спуска
Если $\nabla f(x)^\top d < 0$, то $\varphi'(0) < 0$, и при малом $t > 0$ функция уменьшается. Такое $d$ называют **направлением спуска**. Самое крутое — $d = -\nabla f(x)$: для него $\nabla f^\top d = -\|\nabla f\|^2$ ([[OptChapter_Lecture1_slides.pdf#page=23|сл. 23]]).

## Правая производная
Если двигаться можно только при $t \ge 0$ (например, по отрезку $[0, 1]$ внутри $C$), берут правую производную $\varphi'(0+)$ — предел только по $t \downarrow 0$ ([[OptChapter_Lecture1_slides.pdf#page=26|сл. 26]]).

## Пример
$f(x) = x_1^2 + 3 x_1 x_2$, точка $x = (1, 1)$, направление $v = (1, -1)$.
- Напрямую: $\varphi(t) = (1 + t)^2 + 3(1 + t)(1 - t) = 4 + 2t - 2t^2$, $\varphi'(0) = 2$.
- Через градиент: $\nabla f = (2x_1 + 3x_2, \ 3x_1) = (5, 3)$, $\nabla f^\top v = 5 - 3 = 2$. Совпало.

## На пальцах
Линейка на карте. Рельеф — яма-чаша $f = x_1^2 + x_2^2$ (дно в нуле, $x_1$ — на восток), ты стоишь в точке $(1, 0)$. Профиль высоты вдоль линейки через эту точку — $\varphi(t) = f(x + tv)$, обычный график одной переменной.
- На запад, $v = (-1, 0)$: профиль $(1 - t)^2$, в начале вниз со скоростью $2$, $\varphi'(0) = -2$.
- На север, $v = (0, 1)$: профиль $1 + t^2$, в начале горизонтален, $\varphi'(0) = 0$.
- На северо-восток, $v = (1, 1)$: профиль $(1 + t)^2 + t^2$, $\varphi'(0) = 2$.

Градиент $(2, 0)$ даёт все три скорости разом: $\nabla f^\top v = -2,\ 0,\ 2$. Скорость здесь — на единицу $t$, а не на метр: у $v = (1, 1)$ длина $\sqrt 2$.

## Проверь себя
$f(x) = x_1^2 + x_2^2$, $x = (1, 0)$. Найдите производную по направлениям $v = (0, 1)$ и $v = (-1, 0)$. Какое из них — направление спуска?

> [!success]- Ответ
> $\nabla f(1, 0) = (2, 0)$. Для $v = (0, 1)$ получаем $0$: движение по касательной к линии уровня (окружности). Для $v = (-1, 0)$ получаем $-2 < 0$ — это направление спуска.
