# Б17 Линейная оболочка и ортогональное дополнение

## Определения
- **Линейная оболочка** $\operatorname{span}\{v_1, \dots, v_k\}$ — все линейные комбинации $c_1 v_1 + \dots + c_k v_k$ с любыми числами $c_i$ ([[OptChapter_Lecture2_slides.pdf#page=14|сл. 14]] лекции 2). Для одного $v \ne 0$ — прямая через ноль, для двух непараллельных — плоскость через ноль.
- $v_1, \dots, v_k$ **линейно независимы**, если $c_1 v_1 + \dots + c_k v_k = 0$ только при всех $c_i = 0$: ни один из них не выражается через остальные.
- **Ранг** матрицы — наибольшее число линейно независимых строк; столько же и линейно независимых столбцов. Матрица $p \times n$ имеет **полный строковый ранг**, если ранг равен $p$, то есть все строки независимы. Для этого нужно $p \le n$.
- **Ортогональное дополнение** подпространства $V$: $V^\perp = \{w : w^\top v = 0 \ \ \forall v \in V\}$ — все векторы, перпендикулярные каждому вектору из $V$.

## Главный факт
Пусть $J$ — матрица $p \times n$ со строками $a_1^\top, \dots, a_p^\top$. Тогда
$$\ker J = \{d : a_j^\top d = 0 \ \ \forall j\}, \qquad (\ker J)^\perp = \operatorname{span}\{a_1, \dots, a_p\}.$$
Словами: **вектор, перпендикулярный всему, что перпендикулярно каждому $a_j$, сам есть комбинация векторов $a_j$.**

Почему. Каждое $a_j$ перпендикулярно $\ker J$ по определению ядра, поэтому $\operatorname{span}\{a_j\} \subseteq (\ker J)^\perp$. Размерности равны: $\dim \ker J = n - \operatorname{rank} J$, значит $\dim (\ker J)^\perp = n - \dim \ker J = \operatorname{rank} J = \dim \operatorname{span}\{a_j\}$. Подпространство внутри другого подпространства той же размерности совпадает с ним.

## Зачем это лекции
В минимуме задачи с равенствами получается $\nabla f(x^\star) \perp T_{lin}(x^\star)$, где $T_{lin} = \ker J$, а строки $J$ — градиенты $\nabla h_j(x^\star)^\top$. Главный факт превращает «перпендикулярен» в «есть комбинация»: $\nabla f(x^\star) = -\sum_j \nu_j \nabla h_j(x^\star)$. Числа $\nu_j$ — это и есть множители Лагранжа ([[OptChapter_Lecture2_slides.pdf#page=14|сл. 14]]).

Линейная независимость градиентов для самого факта не нужна. Она нужна в другом месте — чтобы $T_{lin}$ совпало с настоящими касательными направлениями ([[OptChapter_Lecture2_slides.pdf#page=11|сл. 11]]). Заодно она даёт единственность множителей.

## На пальцах
$\mathbb R^3$, две строки: $a_1 = (0, 0, 1)$ и $a_2 = (1, 0, 0)$.
- $\ker J$: $d_3 = 0$ и $d_1 = 0$ — ось $y$, прямая.
- $(\ker J)^\perp$: векторы с нулевой $y$-координатой — плоскость $xz$, то есть $\operatorname{span}\{a_1, a_2\}$. Например, $w = (3, 0, -2)$ перпендикулярен оси $y$ и равен $3 a_2 - 2 a_1$.
- Размерности: $1 + 2 = 3$.

С одной строкой $a_1$: ядро — горизонтальная плоскость $d_3 = 0$, дополнение — вертикальная ось, кратные $a_1$.

Без независимости: $a_1 = (0, 0, 1)$, $a_2 = (0, 0, 2)$. Ядро — та же горизонтальная плоскость, оболочка — та же ось, но $(0, 0, 4) = 4 a_1 = 2 a_2 = 2 a_1 + a_2$: коэффициенты не единственны.

Упрощение: здесь $a_j$ лежат на осях координат, и всё видно сразу. Для косых $a_j$ картинка поворачивается, а рассуждение через размерности остаётся тем же.

![[Б17 — ядро и дополнение.png]]
На что смотреть: слева одна строка — ядро есть плоскость, дополнение есть ось $a_1$. Справа две строки — ядро сжалось до оси $y$, дополнение выросло до плоскости $xz$, в ней лежит $w = 3a_2 - 2a_1$. Чем больше независимых строк, тем меньше ядро и тем больше дополнение; вместе их размерности всегда дают $3$.

## Проверь себя
$a_1 = (1, 1, 0)$, $a_2 = (0, 1, 1)$.
1. Найдите $\ker J$.
2. Проверьте, что $w = (1, 2, 1)$ лежит в $(\ker J)^\perp$, и разложите его по $a_1$, $a_2$.
3. Независимы ли $(1, 2)$ и $(2, 4)$? Каков ранг матрицы из этих строк?

> [!success]- Ответы
> 1. $d_1 + d_2 = 0$ и $d_2 + d_3 = 0$ → $d = t (1, -1, 1)$, прямая.
> 2. $w^\top (1, -1, 1) = 1 - 2 + 1 = 0$; $w = a_1 + a_2$.
> 3. Нет: $(2, 4) = 2 \cdot (1, 2)$. Ранг $1$.
