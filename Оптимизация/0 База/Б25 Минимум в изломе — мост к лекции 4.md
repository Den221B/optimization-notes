# Б25 Минимум в изломе — мост к лекции 4

Как искать минимум функции с изломом, знакомо из школы: проверить точки, где производная равна нулю или не существует. **Лекция 4 — это один вопрос: чем заменить производную в изломе, чтобы условие минимума и методы спуска работали и там.** Ответ — вместо одного наклона касательной взять все наклоны опорных прямых.

## Школьный способ
У $f(x) = |x|$ в нуле производной нет: слева график идёт с наклоном $-1$, справа — с наклоном $+1$. Минимум там всё равно есть: слева функция убывает, справа возрастает.

Аккуратно это записывают **односторонними производными**:
$$f'_-(x) = \lim_{t \uparrow 0} \frac{f(x + t) - f(x)}{t}, \qquad f'_+(x) = \lim_{t \downarrow 0} \frac{f(x + t) - f(x)}{t}.$$
У $|x|$ в нуле $f'_-(0) = -1$, $f'_+(0) = 1$. У выпуклой функции одной переменной обе односторонние производные существуют в каждой внутренней точке области и $f'_-(x) \le f'_+(x)$; равенство — ровно там, где есть обычная производная.

## Опорные прямые
Касательная к выпуклой функции лежит под графиком ([[сл20 Критерий выпуклости первого порядка (Th 7)]]). В изломе касательной нет, но прямых через точку графика, которые целиком лежат под ним, много: годится любой наклон $g$ из отрезка $[f'_-(x),\ f'_+(x)]$. У $|x|$ в нуле это прямые $y = gx$ с $|g| \le 1$.

Это и есть **субградиент** в 1D, а отрезок наклонов — **субдифференциал**:
$$\partial f(x) = [f'_-(x),\ f'_+(x)].$$
В гладкой точке отрезок стягивается в одно число $f'(x)$.

## Условие минимума
Выпуклая $f$ имеет минимум в $x^\star$ $\iff$ слева от $x^\star$ она не возрастает, а справа не убывает $\iff$
$$f'_-(x^\star) \le 0 \le f'_+(x^\star) \iff 0 \in \partial f(x^\star).$$
Геометрически: горизонтальная прямая через $(x^\star, f(x^\star))$ — опорная. В гладкой точке это школьное $f'(x^\star) = 0$.

## Что лекция добавляет
1. **Субградиент в $\mathbb R^n$** — вектор $g$ с $f(y) \ge f(x) + g^\top (y - x)$ для всех $y$; субдифференциал — множество таких векторов → [[Л4 сл04 Субградиент и субдифференциал (Def 1–2)]], [[Л4 сл10 Субградиентное условие оптимальности (Th 4)]].
2. **Субградиентный метод** — шаг против любого субградиента. В 1D в неоптимальной точке короткий такой шаг ведёт вниз, а в $\mathbb R^n$ может вести вверх → [[Л4 сл12 Минус субградиент может вести вверх]].
3. **Prox** — точный минимум суммы «негладкая часть + парабола»; для $|x|$ это мягкий порог из примера ниже → [[Л4 сл27 Проксимальный оператор (Def 6)]], [[Л4 сл30 Prox ℓ1-нормы — мягкий порог]].
4. **Проксимальный градиент** — гладкую часть заменяем параболой, негладкую оставляем как есть → [[Л4 сл35 Проксимальный градиентный метод (Def 7)]].

## На пальцах
$F(x) = \frac12 (x - 3)^2 + |x|$ — парабола плюс излом в нуле.
- В нуле: $F'_-(0) = (0 - 3) - 1 = -4$, $F'_+(0) = (0 - 3) + 1 = -2$. Обе отрицательны: справа от нуля функция ещё убывает, минимум не здесь.
- При $x > 0$: $F'(x) = x - 3 + 1 = 0$, $x^\star = 2$. Значения: $F(0) = 4{,}5$, $F(2) = 2{,}5$, $F(3) = 3$. Минимум параболы $x = 3$ сдвинулся к нулю ровно на $1$ — на коэффициент при $|x|$.

Теперь $F(x) = \frac12 (x - 0{,}5)^2 + |x|$:
- В нуле: $F'_-(0) = -0{,}5 - 1 = -1{,}5$, $F'_+(0) = -0{,}5 + 1 = 0{,}5$. Ноль между ними, $0 \in [-1{,}5;\ 0{,}5]$ — минимум ровно в изломе, $x^\star = 0$.
- Проверка гладкими ветвями: при $x > 0$ уравнение $x - 0{,}5 + 1 = 0$ даёт $x = -0{,}5$ — не положительное; при $x < 0$ уравнение $x - 0{,}5 - 1 = 0$ даёт $x = 1{,}5$ — не отрицательное. Ни на одной ветви корня нет.

Правило: минимум $\frac12 (x - v)^2 + |x|$ — это $v$, сдвинутое к нулю на $1$, а если сдвиг перескакивает через ноль, то ровно $0$. В лекции это **мягкий порог** $\operatorname{sign}(v) \max\{|v| - 1, 0\}$.

Упрощение: в 1D субдифференциал — отрезок наклонов, и минимум виден по знакам двух односторонних производных. В $\mathbb R^n$ субдифференциал — множество векторов (например, квадрат), «знаков» уже нет, остаётся условие $0 \in \partial f(x^\star)$.

## Проверь себя
1. $f(x) = |x| + 2x$. Найдите $\partial f(0)$. Минимум ли $x = 0$?
2. Найдите минимум $\frac12 (x - v)^2 + 2|x|$ при $v = 5$ и при $v = -1$.

> [!success]- Ответы
> 1. $f'_-(0) = -1 + 2 = 1$, $f'_+(0) = 1 + 2 = 3$, $\partial f(0) = [1, 3]$. Ноля в нём нет — не минимум. Более того, минимума нет вообще: при $x < 0$ $f(x) = -x + 2x = x \to -\infty$.
> 2. $v = 5$: при $x > 0$ $x - 5 + 2 = 0$, $x^\star = 3$. $v = -1$: в нуле $F'_-(0) = 1 - 2 = -1$, $F'_+(0) = 1 + 2 = 3$, ноль между ними — $x^\star = 0$.
