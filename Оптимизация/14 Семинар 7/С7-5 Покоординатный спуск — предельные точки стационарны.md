# С7-5 Покоординатный спуск — предельные точки стационарны

> [!question] Условие · семинар 7, [[OptChapter_Sem7_slides.pdf#page=22|сл. 22–32]]
> Рассмотрим итерационный метод $x_{k+1} = x_k + \alpha_k d_k$, где $\alpha_k$ выбирается либо по правилу Армихо, либо с помощью точной одномерной минимизации. На каждой итерации выбирается индекс $i_k \in \arg\max_{1 \le j \le n} \big|\frac{\partial f(x_k)}{\partial x_j}\big|$, а направление определяется формулой $d_k = -\frac{\partial f(x_k)}{\partial x_{i_k}} e_{i_k}$. Предполагается, что $f$ непрерывно дифференцируема. Докажите, что всякая предельная точка последовательности $\{x_k\}$ является стационарной.

> [!success]- Итог семинара — открыть после своей попытки
> От противного: $x_{k_j} \to \bar x$, $\nabla f(\bar x) \ne 0$. Направление: $g_k = \nabla f(x_k)$, $|(g_k)_{i_k}| = \|g_k\|_\infty$, $g_k^\top d_k = -(g_k)_{i_k}^2 = -\|g_k\|_\infty^2$, $\|d_k\|_2 = \|g_k\|_\infty$. Окрестность: $\gamma = \|\nabla f(\bar x)\|_\infty > 0$; по непрерывности есть $r > 0$, что в $B(\bar x, 2r)$ выполнено $\|\nabla f(x)\|_\infty \ge \frac\gamma2$ и $\le M$, поэтому $\nabla f(x)^\top d \le -\frac{\gamma^2}{4}$, $\|d\|_2 \le M$. Армихо: $f(x + \alpha d) - f(x) = \alpha \nabla f(x)^\top d + \alpha \int_0^1 \big(\nabla f(x + t\alpha d) - \nabla f(x)\big)^\top d\, dt$; градиент равномерно непрерывен на компакте $B(\bar x, 2r)$ — есть $\delta$, при котором $\|u - v\|_2 \le \delta \Rightarrow \|\nabla f(u) - \nabla f(v)\|_2 \le \frac{(1 - c)\gamma^2}{4M}$; с $\alpha_0 M \le \min\{r, \delta\}$ ошибка не больше $(1 - c)\|\nabla f(x)\|_\infty^2$, и любой $0 < \alpha \le \alpha_0$ проходит Армихо во всей окрестности. Возврат $\bar\alpha, \beta\bar\alpha, \dots$ даёт $\alpha_k \ge \alpha_{\min} = \min\{\bar\alpha, \beta\alpha_0\}$ и $f(x_{k+1}) \le f(x_k) - \Delta$, $\Delta = c\alpha_{\min} \frac{\gamma^2}{4}$. Для больших $j$: $x_{k_j} \in B(\bar x, r)$, $|f(x_{k_j}) - f(\bar x)| < \frac\Delta4$, тогда $f(x_{k_j + 1}) < f(\bar x) - \frac{3\Delta}{4}$, и по монотонности $f(x_{k_\ell}) < f(\bar x) - \frac{3\Delta}{4}$ для всех $\ell > j$ — противоречие с $f(x_{k_\ell}) \to f(\bar x)$. Точная минимизация: пробный шаг $\hat\alpha$ с $\hat\alpha M \le \min\{r, \hat\delta\}$ ($\hat\delta$ — для порога $\frac{\gamma^2}{8M}$) даёт $f(x + \hat\alpha d) - f(x) \le -\frac{\hat\alpha \gamma^2}{8}$; точный шаг не хуже, $\hat\Delta = \frac{\hat\alpha \gamma^2}{8}$, а $\alpha = 0$ допустимо, так что $f(x_{k+1}) \le f(x_k)$ всегда — то же противоречие. Логика: $\nabla f(\bar x) \ne 0$ ⇒ $\|\nabla f\|_\infty \ge \frac\gamma2$ рядом ⇒ $\nabla f^\top d \le -\frac{\gamma^2}{4}$ ⇒ фиксированное уменьшение ⇒ бесконечно возвращаться к $\bar x$ нельзя.

## На пальцах
$f = x_1^2 - x_1 x_2 + x_2^2$, шаг — точная одномерная минимизация. Вдоль $e_i$ кривизна $\frac{\partial^2 f}{\partial x_i^2} = 2$, поэтому точный шаг обнуляет выбранную частную производную, а $f$ уменьшается ровно на $\frac{(g_k)_{i_k}^2}{4} = \frac{\|g_k\|_\infty^2}{4}$.
- $x_0 = (4;\ 1)$: $g_0 = (7;\ -2)$, $i_0 = 1$, $d_0 = (-7;\ 0)$, $g_0^\top d_0 = -49 = -\|g_0\|_\infty^2$. Точный шаг $\alpha_0 = \frac12$: $x_1 = (\frac12;\ 1)$, $f$: $13 \to \frac34$ — на $\frac{49}{4}$.
- $g_1 = (0;\ \frac32)$, $i_1 = 2$: $x_2 = (\frac12;\ \frac14)$, $f = \frac{3}{16}$. Дальше $(\frac18;\ \frac14)$, $(\frac18;\ \frac{1}{16})$, … — каждый шаг умножает $f$ на $\frac14$. Предел — $(0, 0)$, и $\nabla f(0, 0) = 0$, как и требует теорема.

Почему нестационарная точка не может быть предельной — на примере $\bar x = (2;\ 2)$: $\nabla f(\bar x) = (2;\ 2)$, $\gamma = 2$, $f(\bar x) = 4$. В круге радиуса $\frac13$ около неё обе частные производные не меньше $1 = \frac\gamma2$, и шаг из любой точки круга уменьшает $f$ хотя бы на $\frac{1^2}{4} = \frac14$ — это фиксированное уменьшение, роль $\Delta$ в доказательстве. Пусть итерация попала в круг и там $f < 4 + \frac{1}{16}$. После шага $f < 4 - \frac{3}{16}$, и раз $f$ не растёт, так навсегда. А во всех точках достаточно близко к $\bar x$ по непрерывности $f > 4 - \frac{3}{16}$ — туда метод уже не вернётся.

Упрощение: у квадратичной функции точный шаг считается формулой, и уменьшение видно сразу. В доказательстве для произвольной $f$ с непрерывным градиентом его заменяет пробный шаг $\hat\alpha$, а ровную кривизну $2$ — равномерная непрерывность градиента на компактном шаре ([[Б46 Равномерная непрерывность на компакте]]).

![[С7-5 Покоординатный спуск — путь и окрестность нестационарной точки.png]]
На что смотреть: серые линии — уровни $f$, наклонные эллипсы вокруг $(0, 0)$. Красный путь — шаги по одной координате: отрезки по очереди горизонтальны и вертикальны, их длины $3{,}5;\ 0{,}75;\ 0{,}375;\ 0{,}1875;\ \dots$ — начиная с третьего, каждый вдвое короче предыдущего. Оранжевый круг около $\bar x = (2;\ 2)$ — место, где каждый шаг снижал бы $f$ хотя бы на $\frac14$: путь в него не заходит, и предельной точкой $\bar x$ быть не может.
