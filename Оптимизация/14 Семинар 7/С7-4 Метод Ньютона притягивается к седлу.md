# С7-4 Метод Ньютона притягивается к седлу

> [!question] Условие · семинар 7, [[OptChapter_Sem7_slides.pdf#page=16|сл. 16–21]]
> Пусть $f : \mathbb R^n \to \mathbb R$ имеет непрерывные производные до третьего порядка в некоторой окрестности точки $x^\star$, причём $\nabla f(x^\star) = 0$. Рассмотрим метод Ньютона $x_{k+1} = x_k - [\nabla^2 f(x_k)]^{-1} \nabla f(x_k)$. Пусть $H^\star = \nabla^2 f(x^\star)$ невырождена. Докажите, что $x^\star$ является локально притягивающей неподвижной точкой метода Ньютона независимо от того, является ли $H^\star$ положительно определённой.

> [!success]- Итог семинара — открыть после своей попытки
> $x^\star$ — неподвижная точка: $\nabla f(x^\star) = 0$ и $H^\star$ обратима. Ошибка $e_k = x_k - x^\star$, $H_k = \nabla^2 f(x_k)$: $e_{k+1} = e_k - H_k^{-1} \nabla f(x_k)$. По формуле Ньютона–Лейбница для $\phi(t) = \nabla f(x^\star + t e_k)$: $\nabla f(x_k) = \int_0^1 \nabla^2 f(x^\star + t e_k)\, e_k\, dt$, откуда $e_{k+1} = H_k^{-1} \int_0^1 \big(H_k - \nabla^2 f(x^\star + t e_k)\big) e_k\, dt$. Два контроля в малой окрестности: (1) гессиан остаётся невырожденным и $\|[\nabla^2 f(x)]^{-1}\| \le B$ — непрерывность обращения; (2) третьи производные ограничены, поэтому гессиан локально липшицев: $\|\nabla^2 f(x) - \nabla^2 f(y)\| \le M \|x - y\|$, и $\|H_k - \nabla^2 f(x^\star + t e_k)\| \le M (1 - t) \|e_k\|$. Итог: $\|e_{k+1}\| \le B \int_0^1 M (1 - t) \|e_k\|^2 dt = \frac{BM}{2} \|e_k\|^2$, $C = \frac{BM}{2}$. Радиус $\rho$ с $C\rho < 1$: при $\|e_0\| \le \rho$ имеем $\|e_{k+1}\| \le C\rho \|e_k\| < \|e_k\|$ — итерации остаются в шаре, $x_k \to x^\star$ квадратично. $H^\star \succ 0$ нигде не использовано — только невырожденность. Пример: $f = \frac12 (x^2 - y^2)$, $\nabla^2 f = \operatorname{Diag}(1, -1)$, $[\nabla^2 f]^{-1} \nabla f = (x;\ y)$ — шаг Ньютона из любой точки попадает в седло $(0, 0)$ за один шаг.

## На пальцах
Жёлоб лекции $f = \cos x + \frac12 y^2$ ([[Б41 Перевал и дно — мост к лекции 7]]): седло $x^\star = (0, 0)$, $H^\star = \operatorname{Diag}(-1, 1)$ — невырожден, но не $\succ 0$. Шаг Ньютона по координатам: $x^+ = x - \frac{-\sin x}{-\cos x} = x - \operatorname{tg} x$, $y^+ = y - \frac{y}{1} = 0$.
- Старт $(0{,}4;\ 0{,}3)$, $\|e_0\| = 0{,}5$. Шаг 1: $(-0{,}0228;\ 0)$. Шаг 2: $x \approx 3{,}9 \cdot 10^{-6}$ — метод практически в седле, где $f = 1$, а минимум $f^\star = -1$.
- Оценка из доказательства на шаре $\rho = \frac12$: $\|[\nabla^2 f]^{-1}\| = \max\{\frac{1}{|\cos x|}, 1\} \le B = \frac{1}{\cos 0{,}5} \approx 1{,}14$; гессиан меняется только через $-\cos x$, его производная $\sin x$, поэтому $M = \sin 0{,}5 \approx 0{,}48$. $C = \frac{BM}{2} \approx 0{,}273$, $C\rho \approx 0{,}14 < 1$. Обещано $\|e_1\| \le C \|e_0\|^2 \approx 0{,}068$, на деле $0{,}0228$.
- GD с шагом $\frac12$ из той же точки: $x^+ = x + \frac12 \sin x$, $y^+ = \frac12 y$. Первый шаг — $(0{,}595;\ 0{,}15)$, прочь от седла; дальше GD сходится в дно $(\pi, 0)$.
- Притяжение локальное: Ньютон из $(1{,}2;\ 0{,}3)$ даёт по $x$: $-1{,}37;\ 3{,}6;\ 3{,}11;\ 3{,}14$ — вылетел из шара и сел в дно $(\pi, 0)$. Оно тоже стационарная точка.

Почему так: Ньютон ищет нуль градиента, а не минимум, — для него седло такая же цель, как дно. GD идёт против градиента, и отрицательная кривизна в седле его выталкивает ([[С7-3 Градиентный метод у строгого седла]]).

Упрощение: здесь сходимость даже быстрее квадратичной: $x - \operatorname{tg} x \approx -\frac{x^3}{3}$, отношение $\frac{|e_2|}{|e_1|^3} \approx 0{,}33$ — потому что у $\cos$ третья производная в нуле равна нулю. Теорема обещает только $\|e_{k+1}\| \le C \|e_k\|^2$.

![[С7-4 Метод Ньютона притягивается к седлу — Ньютон и GD на жёлобе.png]]
На что смотреть: серые линии — уровни жёлоба, оранжевый крест — седло, зелёная звезда — дно $(\pi, 0)$, оранжевый пунктирный круг — шар $\rho = \frac12$ из оценки. Красный путь — Ньютон из $(0{,}4;\ 0{,}3)$: первым шагом прыгает почти в седло, вторым — в него. Синий путь — GD с шагом $\frac12$ из той же точки: уходит вправо в дно. Сиреневый пунктир — Ньютон из $(1{,}2;\ 0{,}3)$, вне шара: скачет через седло влево, потом вправо и садится в дно.
