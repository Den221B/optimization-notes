# Л4 сл42 LASSO и ISTA

> [!abstract] Пример · [[OptChapter_Lecture4_slides.pdf#page=42|сл. 42]]
> $F(x) = \frac12 \|Ax - b\|_2^2 + \lambda \|x\|_1$: $f(x) = \frac12 \|Ax - b\|_2^2$, $g(x) = \lambda \|x\|_1$, $\nabla f(x) = A^\top (Ax - b)$. Из $\nabla f(x) - \nabla f(y) = A^\top A (x - y)$
> $$\|\nabla f(x) - \nabla f(y)\| \le \|A^\top A\|_{op} \|x - y\|, \qquad L = \|A^\top A\|_{op} = \|A\|_{op}^2 .$$
> Поэтому
> $$x_{k+1} = S_{\alpha\lambda}\big(x_k - \alpha A^\top (Ax_k - b)\big), \qquad 0 < \alpha \le \frac{1}{\|A\|_{op}^2}.$$
> Это **ISTA** (iterative shrinkage-thresholding algorithm). Градиентный шаг уменьшает квадратичную ошибку, а soft-thresholding обнуляет малые координаты и уменьшает остальные по модулю: регуляризатор встроен в алгоритм.

Уточнение: граница $\frac{1}{\|A\|_{op}^2}$ требует $A \ne 0$. При $A = 0$ имеем $L = 0$, $f \equiv \frac12 \|b\|^2$ — годится любой $\alpha > 0$, ISTA сводится к мягкому порогу $x_{k+1} = S_{\alpha\lambda}(x_k)$ и при $\lambda > 0$ за конечное число шагов приходит в $x^\star = 0$.

## На пальцах
$A = \operatorname{Diag}(1, 2)$, $b = (2;\ 0{,}4)$, $\lambda = 1$: $\frac12 \|Ax - b\|^2 = \frac12 (x_1 - 2)^2 + 2(x_2 - 0{,}2)^2$ — та же $f$, что в [[Л4 сл35 Проксимальный градиентный метод (Def 7)]].
- $L = \|A\|_{op}^2 = 2^2 = 4$, шаг $\alpha = \frac14$, порог $\alpha\lambda = 0{,}25$.
- Без штрафа (МНК): $x = (2;\ 0{,}2)$. LASSO: $x^\star = (1, 0)$ — вторая координата обнулилась.
- Почему именно она. Задача распалась на две одномерные. Во второй, $2(x_2 - 0{,}2)^2 + \lambda |x_2|$, производная гладкой части в нуле $4(0 - 0{,}2) = -0{,}8$, и $0 \in -0{,}8 + \lambda[-1, 1]$ при $\lambda \ge 0{,}8$. Первая обнулилась бы только при $\lambda \ge 2$: там производная в нуле $-2$.
- При $\lambda = 0{,}5$: $x^\star = (1{,}5;\ 0{,}075)$ — штраф слабее, нулей нет.

Упрощение: $A$ диагональна, и решение выписывается сразу. При общей $A$ координаты связаны, явной формулы нет — тогда ISTA нужна по-настоящему.

bottom=-0.2; top=2.2;

На что смотреть: по горизонтали $\lambda$, по вертикали координаты решения LASSO. Синяя — $x_1^\star = \max\{2 - \lambda, 0\}$, красная — $x_2^\star = \max\{0{,}2 - \frac\lambda4, 0\}$. Красная доходит до нуля уже при $\lambda = 0{,}8$, синяя — только при $\lambda = 2$. Двигай $\lambda$: с ростом штрафа координаты по очереди становятся точными нулями.
