# Л4 сл35 Проксимальный градиентный метод (Def 7)

> [!abstract] Definition 7 · [[OptChapter_Lecture4_slides.pdf#page=35|сл. 35]]
> Для $\min_x F(x) = f(x) + g(x)$ строим
> $$x_{k+1} = \operatorname{prox}_{\alpha_k g}\big(x_k - \alpha_k \nabla f(x_k)\big).$$
> Для $L$-гладкой $f$ стандартно берут $0 < \alpha_k \le 1/L$; для доказательства скорости — $\alpha_k = 1/L$. Итерацию удобно читать как две стадии:
> $$z_k = x_k - \alpha \nabla f(x_k), \qquad x_{k+1} = \operatorname{prox}_{\alpha g}(z_k).$$

## На пальцах
Тот же LASSO: $f = \frac12 (x_1 - 2)^2 + 2(x_2 - 0{,}2)^2$, $g = \|x\|_1$, $\alpha = \frac1L = \frac14$, $x_0 = (0, 1)$.
- $k = 0$: $z_0 = (0{,}5;\ 0{,}2)$, $x_1 = S_{0{,}25}(z_0) = (0{,}25;\ 0)$.
- $k = 1$: $z_1 = (0{,}6875;\ 0{,}2)$, $x_2 = (0{,}4375;\ 0)$.
- $k = 2$: $x_3 = (0{,}578125;\ 0)$, …
- Вторая координата $z_k$ всегда равна $0{,}2$: шаг $\frac14$ ровно гасит кривизну $4$ по этой оси. Порог $0{,}25$ её обнуляет — ноль сразу и навсегда.
- По первой оси кривизна $1$, в $4$ раза меньше той, на которую рассчитан шаг: ошибка $1 - x_{k,1} = 0{,}75^k$ умножается на $0{,}75$ за шаг.
- Решение $x^\star = (1, 0)$; без штрафа было бы $(2;\ 0{,}2)$.

Упрощение: на этой $f$ координаты не связаны, и метод разбирается по осям. При недиагональной $A^\top A$ градиентный шаг смешивает координаты, и порог действует на уже смешанный вектор.

![[Л4 сл35 — итерации ISTA.png]]
На что смотреть: линии уровня $F = f + \|x\|_1$ с изломом на оси $x_2 = 0$. Пунктир — градиентный шаг к $z_k$ (все $z_k$ на высоте $0{,}2$), сплошная — мягкий порог: сдвиг на $0{,}25$ по каждой координате, вторая обнуляется. Красные точки едут по оси к зелёному квадрату $(1, 0)$.
