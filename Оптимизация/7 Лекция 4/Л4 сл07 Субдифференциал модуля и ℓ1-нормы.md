# Л4 сл07 Субдифференциал модуля и ℓ1-нормы

> [!abstract] Пример · [[OptChapter_Lecture4_slides.pdf#page=7|сл. 7]]
> $$\partial |x| = \begin{cases} \{-1\}, & x < 0, \\ [-1, 1], & x = 0, \\ \{1\}, & x > 0. \end{cases}$$
> В нуле — из определения: $g$ — субградиент $\iff$ $|y| \ge g y$ для всех $y$; при $y > 0$ это $g \le 1$, при $y < 0$ — $g \ge -1$.
> Для $\|x\|_1 = \sum_i |x_i|$ субдифференциал считается покоординатно:
> $$\partial \|x\|_1 = \{g : g_i = \operatorname{sign}(x_i) \text{ при } x_i \ne 0, \ \ g_i \in [-1, 1] \text{ при } x_i = 0\}.$$

## На пальцах
$\|x\|_1 = |x_1| + |x_2|$ на плоскости; субдифференциал считается по координатам.
- $x = (2, 0)$: первая координата положительна — $g_1 = 1$; вторая ноль — $g_2 \in [-1, 1]$. $\partial \|x\|_1 = \{1\} \times [-1, 1]$ — вертикальный отрезок.
- $x = (0, 0)$: обе координаты ноль, $\partial \|x\|_1 = [-1, 1]^2$ — квадрат.
- $x = (1, -1)$: $g = (1, -1)$ — одна точка, функция там гладкая.

Проверка определением в $(2, 0)$. Вектор $g = (1;\ 0{,}5)$ — субградиент: $|y_1| + |y_2| \ge 2 + (y_1 - 2) + 0{,}5\, y_2 = y_1 + 0{,}5\, y_2$ для всех $y$, потому что $|y_1| \ge y_1$ и $|y_2| \ge 0{,}5\, y_2$. А $g = (1;\ 1{,}2)$ — нет: при $y = (2, 1)$ слева $3$, справа $2 + 0 + 1{,}2 = 3{,}2$.

Упрощение: в $\mathbb R^2$ субдифференциалы ℓ1-нормы — угловые точки, рёбра и весь квадрат $[-1, 1]^2$. В $\mathbb R^n$ — грани куба $[-1, 1]^n$: свободны те $g_i$, у которых $x_i = 0$.

![[Л4 сл07 — субдифференциалы ℓ1.png]]
На что смотреть: слева три точки на плоскости $x$, справа их субдифференциалы на плоскости $g$. Все они внутри квадрата $[-1, 1]^2$: в нуле — весь квадрат, в $(2, 0)$ — правое ребро, в $(1, -1)$ — угол. Белый крестик $(1;\ 0{,}5)$ лежит на ребре, серый $(1;\ 1{,}2)$ — вне квадрата.
