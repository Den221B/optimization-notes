# Л4 сл33 Локальная модель составной задачи

> [!abstract] Утверждение · [[OptChapter_Lecture4_slides.pdf#page=33|сл. 33–34]]
> Для $F = f + g$ линеаризуем в $x_k$ только $f$, добавляем квадратичную стабилизацию, а $g$ оставляем без изменений:
> $$Q_\alpha(y; x_k) = f(x_k) + \nabla f(x_k)^\top (y - x_k) + \frac{1}{2\alpha} \|y - x_k\|^2 + g(y), \qquad x_{k+1} = \arg\min_y Q_\alpha(y; x_k).$$
> С точностью до слагаемых, не зависящих от $y$,
> $$\nabla f(x_k)^\top (y - x_k) + \frac{1}{2\alpha} \|y - x_k\|^2 = \frac{1}{2\alpha} \big\|y - (x_k - \alpha \nabla f(x_k))\big\|^2 + \text{const},$$
> поэтому
> $$x_{k+1} = \arg\min_y \Big\{g(y) + \frac{1}{2\alpha} \big\|y - (x_k - \alpha \nabla f(x_k))\big\|^2\Big\} = \operatorname{prox}_{\alpha g}\big(x_k - \alpha \nabla f(x_k)\big).$$
> Формула возникает из точной минимизации локальной модели, а не из формального «приклеивания prox» к градиентному шагу.

## На пальцах
LASSO на плоскости: $f(x) = \frac12 (x_1 - 2)^2 + 2(x_2 - 0{,}2)^2$, $g(x) = \|x\|_1$, $L = 4$, $\alpha = \frac14$, $x_0 = (0, 1)$.
- $\nabla f(x_0) = (0 - 2;\ 4 \cdot 0{,}8) = (-2;\ 3{,}2)$.
- Выделяем квадрат ([[Б30 Квадрат нормы суммы и выделение квадрата]]): линейная часть плюс штраф $\frac{1}{2\alpha}\|y - x_0\|^2 = 2\,\|y - x_0\|^2$ — это $2\,\|y - z_0\|^2 + \text{const}$ с центром $z_0 = x_0 - \frac14 \nabla f(x_0) = (0{,}5;\ 0{,}2)$.
- Модель — это $\|y\|_1 + 2\,\|y - z_0\|^2 + \text{const}$, её минимум — prox: каждая координата $z_0$ сдвигается к нулю на $\alpha\lambda = 0{,}25$. Получаем $x_1 = (0{,}25;\ 0)$: вторая координата $0{,}2 \le 0{,}25$ обнулилась.

Упрощение: здесь $f$ квадратичная с диагональным гессианом, и всё считается по координатам. Для общей гладкой $f$ модель — приближение; точно в ней представлена только $g$.
