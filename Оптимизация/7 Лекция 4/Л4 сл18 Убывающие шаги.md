# Л4 сл18 Убывающие шаги

> [!abstract] Утверждение · [[OptChapter_Lecture4_slides.pdf#page=18|сл. 18]]
> Классическое асимптотическое условие:
> $$\alpha_k > 0, \qquad \sum_k \alpha_k = \infty, \qquad \sum_k \alpha_k^2 < \infty .$$
> Пример: $\alpha_k = c / (k + 1)$. Первая сумма не позволяет шагам закончиться слишком рано; вторая контролирует накопление $\alpha_k^2 \|g_k\|^2$.
> Не следует смешивать это условие с конечногоризонтным выбором порядка $1 / \sqrt k$: для него сумма квадратов расходится.

## На пальцах
$f = |x|$, $x_0 = 1{,}2$, $\alpha_k = \frac{1}{k + 1}$: шаги $1;\ \frac12;\ \frac13;\ \dots$
- Точки: $1{,}2 \to 0{,}2 \to -0{,}3 \to 0{,}033 \to -0{,}217 \to -0{,}017 \to 0{,}15 \to \dots$ — качание, но всё уже.
- После первой смены знака $|x_k| \le \frac1k$: если точка ближе к нулю, чем очередной шаг, она перепрыгивает ноль и оказывается от него не дальше этого шага. Шаги убывают — качание затухает.
- Сравни с постоянным $\alpha = 0{,}5$ из той же точки: $1{,}2 \to 0{,}7 \to 0{,}2 \to -0{,}3 \to 0{,}2 \to \dots$ — качание между $0{,}2$ и $-0{,}3$ навсегда.
- Оба ряда ([[Б28 Ряды из шагов]]): $\sum \frac{1}{k + 1} = \infty$ — шагов хватит, чтобы дойти откуда угодно; $\sum \frac{1}{(k + 1)^2} < \infty$ — накопленная плата $\sum \alpha_k^2 \|g_k\|^2$ ограничена.
- Чего условие не даёт — скорости. Общая оценка для задачи с $R = G = 1$ (например, $|x|$ из $x_0 = 1$) при $N = 10^4$: для $\frac{1}{k + 1}$ — около $0{,}135$, а для шага $\frac{1}{\sqrt{k + 1}}$, который условию не удовлетворяет, — около $0{,}027$. Классическое условие достаточно для сходимости, но не необходимо и о быстроте ничего не говорит.

Упрощение: у $|x|$ качание видно напрямую, и оно затухает как $\frac1k$ — быстрее общей оценки. Общая оценка рассчитана на худшую выпуклую функцию с $\|g\| \le G$.

![[Л4 сл18 — убывающий шаг.png]]
На что смотреть: вертикальная шкала логарифмическая. Оба метода стартуют из $1{,}2$. Красные точки — $|x_k|$ при убывающем шаге: все под оранжевой огибающей $\frac1k$, качание затухает. Синие квадраты — постоянный шаг $0{,}5$: застряли на $0{,}2$ и $0{,}3$.
