# Л4 сл16 Шаг на конечном горизонте

> [!abstract] Утверждение · [[OptChapter_Lecture4_slides.pdf#page=16|сл. 16–17]]
> Пусть заранее известно число итераций $N$ и есть априорная оценка $\|x_0 - x^\star\| \le R$ для некоторой точки минимума — знание $R$ не означает знания самой $x^\star$. Возьмём постоянный на этих $N$ итерациях шаг
> $$\alpha = \frac{R}{G \sqrt N}: \qquad \min_{0 \le k < N} \big(f(x_k) - f^\star\big) \le \frac{R^2}{2\alpha N} + \frac{\alpha G^2}{2} = \frac{RG}{2\sqrt N} + \frac{RG}{2\sqrt N} = \frac{RG}{\sqrt N}.$$
> С лучшим найденным значением $f^{(N-1)}_{best} = \min_{0 \le k < N} f(x_k)$:
> $$f^{(N-1)}_{best} - f^\star \le \frac{RG}{\sqrt N} = O(N^{-1/2})$$
> — это скорость сходимости. Для точности $\varepsilon$ достаточно $N \ge \frac{R^2 G^2}{\varepsilon^2}$, то есть $N = O(\varepsilon^{-2})$ — итерационная сложность.

## На пальцах
$f = |x|$, $G = 1$, и известно только, что $|x_0 - x^\star| \le R = 1$ (на деле $x_0 = 0{,}95$). Горизонт $N = 100$.
- Шаг $\alpha = \frac{R}{G\sqrt N} = \frac{1}{10} = 0{,}1$, гарантия $\frac{RG}{\sqrt N} = 0{,}1$.
- На деле: $0{,}95;\ 0{,}85;\ \dots;\ 0{,}05;\ -0{,}05;\ 0{,}05; \dots$ — лучшее значение $0{,}05 \le 0{,}1$.
- Откуда такой шаг. Оценка $\frac{R^2}{2\alpha N} + \frac{\alpha G^2}{2}$ — сумма убывающего и растущего по $\alpha$ слагаемых. Сумма $\frac{a}{\alpha} + b\alpha$ минимальна при $\alpha = \sqrt{a/b}$ и равна $2\sqrt{ab}$; здесь $a = \frac{R^2}{2N}$, $b = \frac{G^2}{2}$, откуда $\alpha = \frac{R}{G\sqrt N}$ и значение $\frac{RG}{\sqrt N}$. В минимуме слагаемые равны: $0{,}05 + 0{,}05$.
- Цена точности: $\varepsilon = 0{,}01$ требует $N \ge \frac{1}{0{,}01^2} = 10^4$ шагов, $\varepsilon = 0{,}001$ — уже $10^6$. Каждый новый верный знак — в $100$ раз больше шагов; у оценки $O(1/k)$ — в $10$ раз.

Упрощение: в примере $R = G = 1$. Если $R$ завышено в $10$ раз, шаг и обещанная гарантия тоже вырастут в $10$ раз: метод не сломается, но оценка станет грубой.

На что смотреть: по горизонтали — шаг $\alpha$, по вертикали — гарантия при $R = G = 1$. Синий пунктир $\frac{1}{2\alpha N}$ падает с ростом шага, зелёный $\frac\alpha2$ растёт, красная — их сумма. Её минимум — в $\alpha = \frac{1}{\sqrt N}$, там, где пунктиры пересекаются; при $N = 100$ это точка $(0{,}1;\ 0{,}1)$. Двигай $N$: чем длиннее горизонт, тем меньше лучший шаг и ниже гарантия — но лишь как $\frac{1}{\sqrt N}$.
