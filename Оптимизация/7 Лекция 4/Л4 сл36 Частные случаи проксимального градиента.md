# Л4 сл36 Частные случаи проксимального градиента

> [!abstract] Утверждение · [[OptChapter_Lecture4_slides.pdf#page=36|сл. 36]]
> - $g \equiv 0$: $\operatorname{prox}_{\alpha g}(v) = v$, и $x_{k+1} = x_k - \alpha \nabla f(x_k)$ — обычный градиентный метод.
> - $g = \delta_C$: $\operatorname{prox}_{\alpha g} = \Pi_C$, и $x_{k+1} = \Pi_C\big(x_k - \alpha \nabla f(x_k)\big)$ — проекционный градиентный метод.
> - $g(x) = \lambda \|x\|_1$: $x_{k+1} = S_{\alpha\lambda}\big(x_k - \alpha \nabla f(x_k)\big)$ — схема ISTA для задач с $\ell_1$-штрафом.

## На пальцах
Один градиентный шаг, три разных $g$. $f = \frac12 (x_1 - 2)^2 + 2(x_2 - 0{,}2)^2$, $x_0 = (0, 1)$, $\alpha = \frac14$; градиентная стадия даёт $z_0 = (0{,}5;\ 0{,}2)$. Дальше:
- $g \equiv 0$: prox ничего не делает, $x_1 = (0{,}5;\ 0{,}2)$ — градиентный метод.
- $g = \delta_C$, $C = [0;\ 0{,}4]^2$: проекция, $x_1 = (0{,}4;\ 0{,}2)$ — проекционный градиентный метод.
- $g = \|x\|_1$: мягкий порог $0{,}25$, $x_1 = (0{,}25;\ 0)$ — ISTA.

Вся разница между тремя методами — в последней стадии.

Упрощение: здесь у всех трёх $g$ prox выписывается явно. Если не выписывается, метод формально тот же, но каждая итерация требует решить вспомогательную задачу.
