# Л4 сл12 Минус субградиент может вести вверх

> [!abstract] Пример + следствие · [[OptChapter_Lecture4_slides.pdf#page=12|сл. 12]]
> Для дифференцируемой $f$: $\nabla f(x)^\top (-\nabla f(x)) = -\|\nabla f(x)\|^2 < 0$. Для субградиента определение даёт нижнюю, а не верхнюю оценку функции.
> **Контрпример:** $f(x_1, x_2) = \max\{x_1, -x_1 + 2x_2\} + \frac12 (x_1^2 + x_2^2)$. В $(0, 0)$: $\partial f(0, 0) = \operatorname{conv}\{(1, 0), (-1, 2)\}$, $0 \notin \partial f(0, 0)$ — точка не оптимальна. Но для $g = (1, 0)$ направление $-g = (-1, 0)$ даёт
> $$f(-t, 0) = t + \tfrac12 t^2 > 0 = f(0, 0), \qquad t > 0.$$
> **Следствие для анализа.** Значения $f(x_k)$ могут увеличиваться, поэтому отслеживают $f^{(k)}_{best} = \min_{0 \le i \le k} f(x_i)$ или усредняют итерации: монотонность здесь не базовое свойство.

## На пальцах
$f(x) = |x_1| + 2|x_2|$, минимум в $(0, 0)$. Точка $x = (1, 0)$ не оптимальна, $f(x) = 1$, $\partial f(1, 0) = \{1\} \times [-2, 2]$.
- $g = (1, 0)$: шаг $t$ против $g$ даёт $f(1 - t, 0) = 1 - t$ — вниз.
- $g = (1, 2)$ — тоже субградиент. Шаг против него: $f(1 - t, -2t) = (1 - t) + 4t = 1 + 3t$ при $0 < t < 1$ — вверх. При $t = 0{,}2$: точка $(0{,}8;\ -0{,}4)$, $f = 1{,}6 > 1$.
- Вообще против $g = (1, g_2)$: $f(1 - t, -g_2 t) = 1 - t + 2|g_2|\, t$, и функция убывает, только если $|g_2| < 0{,}5$.
- А расстояние до минимума при $g = (1, 2)$ всё равно уменьшилось: $\|(0{,}8;\ -0{,}4)\|^2 = 0{,}64 + 0{,}16 = 0{,}8 < 1$. На этом и держится анализ метода — [[Л4 сл13 Основное рекуррентное неравенство]].

Упрощение: в 1D так не бывает. Если выпуклая $f$ не в минимуме, все её субградиенты в точке одного знака и смотрят от минимума, так что короткий шаг против любого из них ведёт вниз. Чтобы субградиент мог смотреть «вбок», нужна хотя бы плоскость.

![[Л4 сл12 — минус субградиент вверх.png]]
На что смотреть: ромбы — линии уровня $f$. Зелёная стрелка — шаг $0{,}2$ против $(1, 0)$: на уровень $0{,}8$, ниже. Красная — шаг $0{,}2$ против $(1, 2)$: на уровень $1{,}6$, выше. Но красная стрелка кончается внутри пунктирной окружности радиуса $1$: к минимуму она подошла ближе.
