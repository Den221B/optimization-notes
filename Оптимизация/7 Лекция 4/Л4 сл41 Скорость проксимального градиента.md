# Л4 сл41 Скорость проксимального градиента

> [!abstract] Теорема · [[OptChapter_Lecture4_slides.pdf#page=41|сл. 41]], [[OptChapter_Lecture4_slides.pdf#page=48|48]]
> При предположениях одношагового неравенства положим $y = x^\star$ и просуммируем по $k = 0, \dots, N - 1$:
> $$\sum_{k=0}^{N-1} \big(F(x_{k+1}) - F^\star\big) \le \frac{L}{2} \big(\|x_0 - x^\star\|^2 - \|x_N - x^\star\|^2\big) \le \frac{L}{2} \|x_0 - x^\star\|^2 .$$
> При $\alpha = 1/L$ значения $F(x_k)$ не возрастают, поэтому $N\big(F(x_N) - F^\star\big) \le \sum_{k=0}^{N-1} \big(F(x_{k+1}) - F^\star\big)$, и
> $$F(x_N) - F^\star \le \frac{L \|x_0 - x^\star\|^2}{2N} = O(1/N).$$
> Структура $f + g$ улучшает общую негладкую оценку $O(N^{-1/2})$ до $O(N^{-1})$. Ускоренный проксимальный градиент даёт $O(1/N^2)$; здесь его не вводят.

## На пальцах
Тот же LASSO: $L = 4$, $\|x_0 - x^\star\|^2 = \|(0, 1) - (1, 0)\|^2 = 2$. Оценка теоремы: $F(x_k) - F^\star \le \frac{4 \cdot 2}{2k} = \frac4k$.
- $k = 1$: на деле $0{,}28125 \le 4$.
- $k = 2$: $0{,}158 \le 2$.
- $k = 6$: $0{,}0158 \le 0{,}67$.
- Реальная ошибка $F(x_k) - F^\star = \frac{0{,}5625^k}{2}$ падает в геометрической прогрессии, то есть линейно, а не как $\frac1k$. Причина — $f$ здесь сильно выпукла ($\mu = 1$); теорема этого не использует и даёт оценку для худшего случая.

Упрощение: здесь $f$ сильно выпукла, и реальность намного лучше оценки. Без сильной выпуклости — например, у LASSO с вырожденной $A^\top A$ — гарантировано только $O(1/k)$.

![[Л4 сл41 — оценка и реальная ошибка.png]]
На что смотреть: по вертикали шкала логарифмическая, по горизонтали $k$ — обычная. Красная — реальная ошибка: на такой шкале прямая, то есть геометрическая прогрессия. Оранжевая — оценка $\frac4k$: она выгибается и опускается всё медленнее. Оценка верна на всех шагах, и запас растёт с каждым шагом.
