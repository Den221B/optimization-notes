# Л4 сл46 ADMM — идея расщепления

> [!abstract] Определение · [[OptChapter_Lecture4_slides.pdf#page=46|сл. 46]]
> Для $\min_{x, z} f(x) + g(z)$ при $Ax + Bz = c$ масштабированная форма ADMM при $\rho > 0$:
> $$x_{k+1} = \arg\min_x \Big\{f(x) + \frac\rho2 \|Ax + Bz_k - c + u_k\|^2\Big\},$$
> $$z_{k+1} = \arg\min_z \Big\{g(z) + \frac\rho2 \|Ax_{k+1} + Bz - c + u_k\|^2\Big\},$$
> $$u_{k+1} = u_k + Ax_{k+1} + Bz_{k+1} - c.$$
> Совместная задача может быть трудной, а отдельные подзадачи по $x$ и $z$ — простыми. $u$ играет роль масштабированной двойственной переменной и накапливает нарушение ограничения. Сходимость, выбор $\rho$, невязки и распределённые реализации выходят за рамки лекции.

## На пальцах
$\min \frac12 (x - 3)^2 + |z|$ при $x - z = 0$ ($A = 1$, $B = -1$, $c = 0$), $\rho = 1$. Ответ известен из [[Б25 Минимум в изломе — мост к лекции 4]]: $x = z = 2$.
- Шаг по $x$ — гладкая задача: $x = \frac{3 + z - u}{2}$.
- Шаг по $z$ — prox модуля: $z = S_1(x + u)$.
- Старт $z = u = 0$: $x_1 = 1{,}5$, $z_1 = S_1(1{,}5) = 0{,}5$, $u_1 = 0 + 1{,}5 - 0{,}5 = 1$.
- Дальше $x_2 = z_2 = 1{,}25$, $x_3 = z_3 = 1{,}625$, $x_4 = 1{,}8125$, …: расстояние до $2$ делится пополам каждый шаг, $u$ остаётся равным $1$.
- $u = 1$ — масштабированный множитель Лагранжа ограничения $x = z$. В решении производная $\frac12 (x - 3)^2$ равна $-1$, и множитель $1$ её уравновешивает ([[Л2 сл51 Смысл множителей Лагранжа]]).

Упрощение: задача одномерная, и расщеплять её незачем — это показ механики. Выигрыш ADMM — когда части просты по отдельности, а вместе нет. Например, штраф $\|Dx\|_1$: prox для $\|\cdot\|_1$ дешёвый, а для $\|D\,\cdot\|_1$ — нет; ADMM вводит $z = Dx$ и разделяет их.
