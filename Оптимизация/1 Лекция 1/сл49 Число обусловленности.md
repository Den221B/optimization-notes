# сл49 Число обусловленности

> [!abstract] Определение · [[OptChapter_Lecture1_slides.pdf#page=49|сл. 49]]
> Для $\mu$-сильно выпуклой и $L$-гладкой функции
> $$\kappa = \frac{L}{\mu}.$$
> Для положительно определённой квадратичной функции $\kappa = \lambda_{\max}(A) / \lambda_{\min}(A)$ — спектральное число обусловленности. Чем больше $\kappa$, тем хуже обусловлена задача: сильнее различаются масштабы изменения функции по разным направлениям; $\kappa$ входит в оценки скорости сходимости.

## На пальцах
$\kappa$ — во сколько раз самая большая кривизна больше самой маленькой. Чаши $\tfrac12 (x_1^2 + \kappa x_2^2)$: $\mu = 1$, $L = \kappa$.
- $\kappa = 1$ — круглая чаша: из любой точки антиградиент смотрит прямо в минимум.
- $\kappa = 9$ — овраг из [[Б11 Положительная определённость и матричный порядок]]: шаг длины $1$ из минимума вдоль $x_1$ поднимает $f$ на $0{,}5$, вдоль $x_2$ — на $4{,}5$. Линии уровня вытянуты в $\sqrt{\kappa} = 3$ раза.
- $\kappa = 100$ — вытянуты в $10$ раз.

Что это даёт методу ([[Л3 сл17 Линейная сходимость и число обусловленности]]): ошибка по значению $f(x_k) - f^\star$ за шаг умножается не больше чем на $1 - \tfrac1\kappa$. Уменьшить её в $1000$ раз: при $\kappa = 9$ — $59$ шагов, при $\kappa = 100$ — $688$. Число шагов растёт примерно пропорционально $\kappa$.

Упрощение: у квадратичной функции $\kappa = \lambda_{\max} / \lambda_{\min}$ одно на всё пространство. У неквадратичной $\mu$ и $L$ — худшие кривизны по всем точкам, и $\kappa = L/\mu$ — глобальная оценка: местами задача обусловлена лучше.
