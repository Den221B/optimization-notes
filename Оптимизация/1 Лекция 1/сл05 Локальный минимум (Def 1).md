# сл05 Локальный минимум (Def 1)

> [!abstract] Definition 1 · [[OptChapter_Lecture1_slides.pdf#page=5|сл. 5]]
> Точка $x^\star \in C$ называется точкой локального минимума, если существует $\varepsilon > 0$ такое, что
> $$f(x^\star) \le f(x) \quad \forall x \in C \cap B_\varepsilon(x^\star).$$
> Для невыпуклой задачи локальный минимум может не быть глобальным; для выпуклой это различие исчезает.

## На пальцах
$f(x) = x^3 - 3x$ на $C = [-3, 3]$. Значения: $f(1) = -2$, $f(-1) = 2$, $f(-3) = -18$, $f(3) = 18$.
- $x^\star = 1$ — локальный минимум. Проверка без производных: $f(x) + 2 = (x - 1)^2 (x + 2)$, а это $\ge 0$ при всех $x \ge -2$. Поэтому $f(x) \ge -2$ на $C \cap B_\varepsilon(1)$ при любом $\varepsilon \le 3$; при $\varepsilon > 3$ шар захватывает точки левее $-2$, где $f < -2$.
- Глобальный минимум — край $x = -3$: $f(-3) = -18 < -2$. Локальный минимум $1$ не глобален, потому что есть точка ниже. У выпуклой функции так не бывает ([[сл18 Локальный минимум выпуклой функции глобален (Th 6)]]), а $f$ не выпукла — ей это разрешено.
- Сам край $-3$ — тоже локальный минимум, хотя $f'(-3) = 24 \ne 0$: в определении стоит $C \cap B_\varepsilon$, а левее $-3$ точек $C$ нет, сравнивать не с чем.

Упрощение: в 1D шар $B_\varepsilon(x^\star)$ — интервал $(x^\star - \varepsilon, x^\star + \varepsilon)$.

```desmos-graph
left=-3.5; right=4.5;
bottom=-20; top=20;
---
y=x^3-3x|-3<x<3|green
h=1|slider:0.1..4..0.1
y=-2|1-h<x<1+h|red
(1,-2)|red|label:x* = 1
(-3,-18)|blue|label:глобальный минимум
```
На что смотреть: ползунок $h$ — радиус $\varepsilon$, красный отрезок — уровень $f(x^\star) = -2$ над интервалом $(1 - h, 1 + h)$. Пока $h \le 3$, зелёный график не ниже красного отрезка; при $h > 3$ левый конец уходит за $-2$, и график ныряет под отрезок. Правее $3$ красный отрезок висит над пустотой: там нет точек $C$.
