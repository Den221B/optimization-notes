# Э38 Линейная сходимость при условии PL

## Официальный вопрос

**38. Линейная сходимость градиентного метода при условии Поляка–Лоясиевича.**

Совместное использование $L$-гладкости и условия PL; вывод одношагового сокращения разрыва по значению функции; доказательство
$$f(x_k)-f^\star\le\left(1-\frac\mu L\right)^k\bigl(f(x_0)-f^\star\bigr);$$
итерационная сложность
$$O\!\left(\frac L\mu\log\frac1\varepsilon\right);$$
сравнение гарантий для общей гладкой невыпуклой функции, PL-функции и гладкой сильно выпуклой функции.

Программа: [[OptChapter_Exam.pdf#page=7|с. 7]].

## Требования к ответу

- **Доказывать:** одношаговое сокращение разрыва из $L$-гладкости и PL; геометрическую оценку; достаточное число шагов $\frac L\mu\ln\frac{\Delta_0}\varepsilon$.
- **Формулировать и применять:** сложность $O(\frac L\mu\log\frac1\varepsilon)$; гарантии GD для гладкой невыпуклой, PL- и сильно выпуклой функций.
- **Объяснять идею:** PL заменяет сильную выпуклость в том же доказательстве; гарантии различаются тем, что измеряется, и тем, как растёт число шагов.

## План устного ответа

1. Предположения; почему $\mu\le L$.
2. Спуск плюс PL — сокращение разрыва за шаг.
3. Индукция и сложность через $1-t\le e^{-t}$.
4. Сравнение трёх классов.

## Полный ответ

Пусть $f$ $L$-гладкая, удовлетворяет PL с $\mu>0$, $f^\star=\inf f>-\infty$; выпуклость не предполагается. Для $x_{k+1}=x_k-\frac1L\nabla f(x_k)$
$$\boxed{f(x_k)-f^\star\le\Bigl(1-\frac\mu L\Bigr)^k\bigl(f(x_0)-f^\star\bigr).}$$
Источник: [[OptChapter_Lecture7_slides.pdf#page=56|Л7, с. 56–63]].

### Почему $\mu\le L$

Лемма о спуске в точке $y=x-\frac1L\nabla f(x)$ даёт $f^\star\le f(y)\le f(x)-\frac1{2L}\|\nabla f(x)\|^2$, то есть $\|\nabla f(x)\|^2\le2L(f(x)-f^\star)$. PL даёт $\|\nabla f(x)\|^2\ge2\mu(f(x)-f^\star)$. Если $f(x)>f^\star$ хоть в одной точке, отсюда $\mu\le L$; если нет, $f$ постоянна и доказывать нечего. Итак, $q:=1-\frac\mu L\in[0,1)$.

### Одношаговое сокращение

Обозначим $\Delta_k=f(x_k)-f^\star\ge0$. Из $L$-гладкости — одношаговое уменьшение при шаге $\frac1L$:
$$f(x_{k+1})\le f(x_k)-\frac1{2L}\|\nabla f(x_k)\|^2.$$
Из PL: $\frac1{2L}\|\nabla f(x_k)\|^2=\frac1L\cdot\frac12\|\nabla f(x_k)\|^2\ge\frac\mu L\Delta_k$. Подставляем и вычитаем $f^\star$:
$$\Delta_{k+1}\le\Delta_k-\frac\mu L\Delta_k=\Bigl(1-\frac\mu L\Bigr)\Delta_k.$$
По индукции $\Delta_k\le q^k\Delta_0$: умножение неравенства на $q\ge0$ сохраняет его направление. $\square$

Это доказательство для сильно выпуклой функции из лекции 3, где неравенство $\|\nabla f\|^2\ge2\mu\Delta$ выводили из сильной выпуклости. Здесь оно предположено, а больше выпуклость нигде не участвовала. Сходимость — по значению функции; к какой точке идут $x_k$, теорема не говорит, и минимумов может быть много. Заодно убывает и градиент: $\|\nabla f(x_k)\|^2\le2L\Delta_k\le2Lq^k\Delta_0$.

### Сложность

Из $1-t\le e^{-t}$: $\Delta_k\le e^{-k\mu/L}\Delta_0$. При $0<\varepsilon<\Delta_0$ для $\Delta_k\le\varepsilon$ достаточно $e^{-k\mu/L}\Delta_0\le\varepsilon$, то есть
$$k\ge\frac L\mu\ln\frac{\Delta_0}\varepsilon.$$
При фиксированном $\Delta_0$ это $O\bigl(\frac L\mu\log\frac1\varepsilon\bigr)$: каждые $\frac L\mu$ шагов разрыв гарантированно падает хотя бы в $e$ раз, каждый лишний десятичный знак точности стоит $\frac L\mu\ln10$ шагов. Здесь $\varepsilon$ — порог для разрыва по значению.

### Сравнение гарантий

| класс ($f$ $L$-гладкая, шаг $\frac1L$) | гарантия GD | шагов до точности $\varepsilon$ |
|---|---|---|
| ограниченная снизу, невыпуклая | $\min_{k<K}\lVert\nabla f(x_k)\rVert^2\le\frac{2L(f(x_0)-f_{\inf})}K$ | $O(\varepsilon^{-2})$ до $\lVert\nabla f\rVert\le\varepsilon$ |
| выпуклая, минимум есть (лекция 3) | $\Delta_k\le\frac{L\lVert x_0-x^\star\rVert^2}{2k}$ | $O(\varepsilon^{-1})$ до $\Delta\le\varepsilon$ |
| PL с $\mu$ | $\Delta_k\le(1-\frac\mu L)^k\Delta_0$ | $O(\frac L\mu\log\frac1\varepsilon)$ до $\Delta\le\varepsilon$ |
| $\mu$-сильно выпуклая | та же оценка, PL автоматически | $O(\kappa\log\frac1\varepsilon)$, $\kappa=\frac L\mu$ |

- **Общая невыпуклая:** гарантия про наименьший градиент и не различает минимум, максимум и седло.
- **PL:** малый градиент уже значит малый разрыв, и разрыв сжимается геометрически на **каждом** шаге — без выпуклости. Но минимум может быть не единственным, и PL-функция бывает невыпуклой.
- **Сильно выпуклая:** вдобавок единственный минимум $x^\star$ и сходимость точек, $\|x_k-x^\star\|^2\le\frac2\mu\Delta_k$. Ускоренные методы дают $O(\sqrt\kappa\log\frac1\varepsilon)$.

$\varepsilon$ в строках означает разное: в первой — порог для нормы градиента, в остальных — для разрыва. Поэтому сравнимы только характеры роста: степенной против логарифмического. Обе гипотезы глобальные: у PL-функции $(y-x^2)^2$ градиент не липшицев на всей плоскости, и к ней теорема напрямую не применяется.

## На пальцах

$f(x)=x^2+3\sin^2x$: $f''=2+6\cos2x\in[-4,8]$, так что $L=8$; PL с $\mu=\frac16$ (наименьшее отношение $\frac{\frac12f'^2}{f}\approx0{,}1755$, численно); $f^\star=0$. GD с шагом $\frac1L=\frac18$ из $x_0=3$; гарантированный множитель за шаг $1-\frac\mu L=\frac{47}{48}\approx0{,}979$.
- **Обе половины доказательства на шаге $0$.** $f'(3)=6+3\sin6\approx5{,}16$, $\Delta_0\approx9{,}06$. Спуск: $f(x_1)\le9{,}06-\frac{5{,}16^2}{16}\approx7{,}39$, на деле $7{,}05$. PL: $\frac12\cdot5{,}16^2\approx13{,}3\ge\frac16\cdot9{,}06\approx1{,}51$.
- **Разрыв по шагам:** $9{,}06;\ 7{,}05;\ 6{,}71;\ 6{,}39;\ 5{,}88;\ 4{,}85;\ 2{,}73;\ 0{,}41;\ 0{,}001$; на шаге $9$ — ниже $10^{-6}$. Медленнее всего — от шага $1$ к $2$ и от $2$ к $3$: множитель $0{,}952$. Эти шаги стартуют из $x_1\approx2{,}35$ и $x_2\approx2{,}14$ — там, где отношение PL близко к минимуму. Гарантию $0{,}979$ не нарушает ни один шаг.
- **Сложность:** для $\Delta_k\le10^{-6}$ достаточно $k\ge48\ln\frac{9{,}06}{10^{-6}}\approx769$; на деле хватило $9$. Оценка — для худшей функции класса.

## Ошибки и границы

- Нужны обе глобальные гипотезы — $L$-гладкость и PL; одна PL линейной сходимости GD не даёт.
- Сходимость линейная по значению функции, а не по точкам: минимумов может быть много.
- Оценка — на каждом шаге, в отличие от невыпуклой гарантии про лучший градиент.
- $\varepsilon$ в разных гарантиях — пороги для разных величин.
- Ускорение $O(\sqrt\kappa\log\frac1\varepsilon)$ в курсе — для сильно выпуклых функций, не для PL.
- Константа PL, найденная грубо, даёт осторожную оценку: на деле метод бывает намного быстрее.

## Самопроверка

1. Вывести одношаговое сокращение. Где использована выпуклость?
2. Почему у $L$-гладкой PL-функции $\mu\le L$?
3. $L=10$, $\mu=0{,}1$, $\Delta_0=1$, $\varepsilon=10^{-6}$: сколько шагов достаточно по оценке?
4. Заполнить таблицу гарантий для невыпуклой, PL и сильно выпуклой функции.
5. Почему теорема не применяется к $(y-x^2)^2$ на всей плоскости?

> [!success]- Ответы
> 1. $f(x_{k+1})\le f(x_k)-\frac1{2L}\|\nabla f(x_k)\|^2$ (только $L$-гладкость) и $\frac12\|\nabla f(x_k)\|^2\ge\mu\Delta_k$ (PL) дают $\Delta_{k+1}\le(1-\frac\mu L)\Delta_k$. Выпуклость не использована нигде.
> 2. Шаг $\frac1L$ даёт $f^\star\le f(x)-\frac1{2L}\|\nabla f(x)\|^2$, то есть $\|\nabla f\|^2\le2L\Delta$; с PL $2\mu\Delta\le\|\nabla f\|^2\le2L\Delta$, и при $\Delta>0$ $\mu\le L$.
> 3. $k\ge100\ln10^6\approx1381{,}6$, то есть $1382$ шага.
> 4. Невыпуклая: $\min_{k<K}\|\nabla f(x_k)\|^2\le\frac{2L\Delta_0}K$, $O(\varepsilon^{-2})$ для градиента. PL: $\Delta_k\le(1-\frac\mu L)^k\Delta_0$, $O(\frac L\mu\log\frac1\varepsilon)$ для разрыва. Сильно выпуклая: та же скорость плюс единственный $x^\star$ и $\|x_k-x^\star\|^2\le\frac2\mu\Delta_k$; ускорение — $O(\sqrt\kappa\log\frac1\varepsilon)$.
> 5. $\frac{\partial^2F}{\partial x^2}=12x^2-4y$ не ограничена — глобального $L$ нет.
