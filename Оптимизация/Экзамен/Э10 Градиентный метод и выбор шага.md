# Э10 Градиентный метод и выбор шага

## Официальный вопрос

**10. Градиентный метод и выбор шага.**

Общая схема градиентного метода; антиградиент как направление наискорейшего локального убывания; способы выбора шага; вывод гарантированного убывания для $L$-гладкой функции и выбор шага $\alpha=1/L$; стоимость одной итерации и требования к памяти.

Программа: [[OptChapter_Exam.pdf#page=2|с. 2]].
## Требования к ответу

- **Доказывать:** наискорейшее локальное убывание в евклидовой норме; оценку спуска и оптимальность $1/L$ для этой оценки; конечность backtracking для направления спуска.
- **Формулировать и применять:** алгоритм, фиксированный и заранее заданный шаг, точный поиск, условие Армихо; стоимость с учётом вычисления градиента.
- **Объяснять идею:** направление и длина шага решают разные задачи; локально лучший наклон не выбирает лучшую конечную длину.

## План устного ответа

1. Итерация $x_{k+1}=x_k+\alpha_kp_k$, затем $p_k=-\nabla f(x_k)$.
2. Минимизация производной по единичным направлениям.
3. Способы выбора шага и Армихо.
4. Лемма о спуске, диапазон $(0,2/L)$, шаг $1/L$.
5. Цена итерации и память.

## Полный ответ

Решаем $\min_{x\in\mathbb R^n}f(x)$ для дифференцируемой $f$. Итерационный метод выбирает направление $p_k$ и длину $\alpha_k>0$. Разложение
$$f(x+\alpha p)=f(x)+\alpha\nabla f(x)^\top p+o(\alpha)$$
показывает: если $\nabla f(x)^\top p<0$, то все достаточно малые положительные шаги уменьшают функцию. Градиентный метод задаёт
$$x_{k+1}=x_k-\alpha_k\nabla f(x_k).$$
При нулевом градиенте алгоритм останавливается; без выпуклости это лишь стационарная точка, а не сертификат минимума. Источник: [[OptChapter_Lecture3_slides.pdf#page=4|Л3, с. 4, 9]].

### Почему антиградиент

Пусть $a=\nabla f(x)\ne0$. При $\|p\|_2=1$ производная равна $a^\top p$. По Коши–Буняковскому
$$a^\top p\ge-\|a\|_2\|p\|_2=-\|a\|_2.$$
Равенство достигается при $p=-a/\|a\|_2$. Ненормированный $-a$ задаёт то же направление, а его масштаб можно включить в $\alpha$. Сравнение имеет смысл при одинаковой норме направлений: без нормировки линейная функция по $p$ не ограничена снизу. Результат относится к евклидовой геометрии и первому порядку при $\alpha\to0$.

### Выбор длины

**Фиксированный шаг** $\alpha_k\equiv\alpha$ удобен, если известен безопасный масштаб. Можно заранее задать и убывающую последовательность шагов; само условие $\alpha_k\to0$ ещё не даёт сходимости.

**Точный линейный поиск** решает $\alpha_k\in\arg\min_{\alpha>0}f(x_k+\alpha p_k)$, если минимум вдоль луча достигается. Он может быть дорогим. **Неточный поиск** удовлетворяет требованию достаточного убывания. При $c_1\in(0,1)$ условие Армихо:
$$f(x+\alpha p)\le f(x)+c_1\alpha\nabla f(x)^\top p.$$
Backtracking начинает, например, с $\alpha=1$ и умножает его на $\beta\in(0,1)$ до выполнения условия. Чтобы доказать завершение, обозначим $d=\nabla f(x)^\top p<0$. Остаток $o(\alpha)$ по модулю не больше $(1-c_1)(-d)\alpha$ при достаточно малом $\alpha$. Тогда
$$f(x+\alpha p)-f(x)=\alpha d+o(\alpha)\le c_1\alpha d.$$
Геометрическая последовательность пробных шагов стремится к нулю, поэтому одна из проб будет принята. См. [[OptChapter_Lecture3_slides.pdf#page=7|Л3, с. 7–8]].

### Гарантированное убывание

Пусть $\nabla f$ $L$-липшицев на всём пространстве, $L>0$. Для $h=y-x$ формула Ньютона–Лейбница даёт
$$f(y)-f(x)-\nabla f(x)^\top h
=\int_0^1[\nabla f(x+th)-\nabla f(x)]^\top h\,dt
\le\int_0^1Lt\|h\|^2dt=\frac L2\|h\|^2.$$
Это лемма о спуске. Подставляя $h=-\alpha\nabla f(x)$, получаем
$$f(x-\alpha\nabla f(x))\le f(x)-\alpha\left(1-\frac{L\alpha}{2}\right)\|\nabla f(x)\|^2.$$
При $0<\alpha<2/L$ и ненулевом градиенте правая часть строго меньше $f(x)$. Коэффициент $\psi(\alpha)=\alpha-L\alpha^2/2$ максимален при $\psi'(\alpha)=1-L\alpha=0$, то есть $\alpha=1/L$. Поэтому
$$f(x_{k+1})\le f(x_k)-\frac1{2L}\|\nabla f(x_k)\|^2.$$
Максимизируется гарантированное уменьшение по верхней модели, а не обязательно фактическое уменьшение данной функции. Выпуклость для этой оценки не нужна. При известной лишь локальной константе надо убедиться, что весь шаг лежит в соответствующей области. См. [[OptChapter_Lecture3_slides.pdf#page=10|Л3, с. 10–11]].

### Стоимость

Если вычисление полного градиента стоит $C_\nabla$, итерация с заданным шагом стоит $C_\nabla+O(n)$. Дополнительная память — $O(n)$ для постоянного числа векторов, сверх хранения данных задачи. Поиск шага добавляет пробные вычисления функции, иногда градиента. Писать просто «итерация $O(n)$» нельзя: например, для плотной квадратичной функции сам градиент стоит $O(n^2)$. См. [[OptChapter_Lecture3_slides.pdf#page=12|Л3, с. 12]].

## На пальцах

Возьмём $f(x)=x^2$, $L=2$, начальную точку $x_0=1$. Градиент $f'(1)=2$ положителен, поэтому спускаемся влево. С шагом $1/L=1/2$ получаем $x_1=1-(1/2)\cdot2=0$. Гарантия точно совпадает с результатом:
$$f(x_1)\le1-\frac1{4}\cdot2^2=0.$$
Если взять $\alpha=1=2/L$, выйдет $x_1=-1$: значение останется $1$, строгого спуска нет. При $\alpha=3/2$ выйдет $x_1=-2$, значение вырастет до $4$. Правильное направление само по себе не спасает от слишком длинного шага. Упрощение: в 1D направлений всего два, а $L$ — верхняя граница модуля второй производной.

## Ошибки и границы

- «Наискорейший» относится к единичным направлениям и локальной производной, а не к глобально лучшему пути.
- При $\alpha=2/L$ общая оценка обещает только неувеличение; интервал строгого убывания открыт.
- Наличие убывания не доказывает само по себе ни достижение минимума, ни скорость сходимости.
- Если $L$ неизвестна, $1/L$ нельзя подставить численно; нужен поиск или оценка константы.

## Самопроверка

1. Восстановить доказательство наискорейшего направления. Где нужна нормировка?
2. Вывести оценку спуска из липшицевости градиента.
3. Почему backtracking с Армихо завершится при направлении спуска?
4. Для $f(x)=3x^2$: безопасный диапазон шагов и лучший шаг по верхней модели.
5. Что входит в стоимость итерации кроме векторного обновления?

> [!success]- Ответы
> 1. При $\|p\|_2 = 1$ по Коши–Буняковскому $a^\top p \ge -\|a\|_2$, равенство при $p = -\frac{a}{\|a\|_2}$. Без $\|p\| = 1$ линейная функция $a^\top p$ не ограничена снизу — сравнивать нечего.
> 2. Лемма о спуске $f(y) \le f(x) + \nabla f(x)^\top h + \frac L2 \|h\|^2$ при $h = -\alpha \nabla f(x)$ даёт $f(x) - \alpha (1 - \frac{L\alpha}{2}) \|\nabla f(x)\|^2$.
> 3. При $d = \nabla f(x)^\top p < 0$: $f(x + \alpha p) - f(x) = \alpha d + o(\alpha) \le c_1 \alpha d$, как только $|o(\alpha)| \le (1 - c_1) |d| \alpha$; пробные шаги $\beta^j \to 0$, так что одна из проб пройдёт.
> 4. $L = 6$; строгое убывание гарантировано при $0 < \alpha < \frac13$, лучший шаг по модели $\frac16$. Проверка: $x^+ = (1 - 6\alpha) x$, при $\alpha = \frac16$ сразу $x^+ = 0$.
> 5. Вычисление градиента — по структуре задачи (у плотной квадратичной $O(n^2)$), пробные вычисления $f$ при поиске шага; память — $O(n)$ сверх данных.
