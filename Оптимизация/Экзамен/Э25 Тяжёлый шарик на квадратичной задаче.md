# Э25 Тяжёлый шарик на квадратичной задаче

## Официальный вопрос

**25. Метод тяжёлого шарика Поляка на квадратичной задаче.**

Спектральная динамика градиентного метода и роль обусловленности; метод тяжёлого шарика; анализ по собственным направлениям; вывод оптимальных параметров и коэффициента затухания
$$q^\star=\frac{\sqrt\kappa-1}{\sqrt\kappa+1};$$
границы применимости квадратичного анализа.

Программа: [[OptChapter_Exam.pdf#page=5|с. 5]].

## Требования к ответу

- **Доказывать:** рекурсии GD и heavy ball по спектру, спектральную полосу, оптимальные $\alpha,\beta,q$.
- **Формулировать и применять:** схему, начальные условия, смысл $\kappa$ и асимптотического коэффициента; ограничение результата квадратичным классом. Освобождения от доказательств программа здесь не даёт.

## План устного ответа

1. Квадратичная задача и переход в собственный базис.
2. Медленные и быстрые направления GD.
3. Инерция, характеристическое уравнение, полоса корней.
4. Минимаксная настройка и границы вывода.

## Полный ответ

### Спектральная динамика

Рассмотрим $f(x)=\frac12x^\top Ax-b^\top x$, $A=A^\top\succ0$, где $\mu=\lambda_{\min}(A)$, $L=\lambda_{\max}(A)$, $0<\mu\le L$. Тогда $x^\star=A^{-1}b$, $\nabla f(x)=A(x-x^\star)$. Для GD с постоянным шагом
$$e_{k+1}=(I-\alpha A)e_k,\qquad e_k=x_k-x^\star.$$
По спектральной теореме $A=Q\Lambda Q^\top$, $Q^\top Q=I$. В координатах $z_k=Q^\top e_k$ имеем $z_{k+1}^{(i)}=(1-\alpha\lambda_i)z_k^{(i)}$. Для сходимости всех компонент нужен $0<\alpha<2/L$. Худший модуль равен $\max\{|1-\alpha\mu|,|1-\alpha L|\}$: модуль аффинной функции достигает максимума на концах интервала. Минимум получается при равных противоположных крайних множителях: $\alpha=2/(L+\mu)$, $q_{GD}=(\kappa-1)/(\kappa+1)$, где $\kappa=L/\mu$. При большом $\kappa$ сильная кривизна ограничивает шаг, а вдоль слабой градиентный метод движется медленно. Источник: [[OptChapter_Lecture6_slides.pdf#page=5|Л6, с. 5–7]].

### Heavy ball и корни

Схема Поляка с шагом $\alpha>0$ и инерцией $\beta\ge0$ сохраняет предыдущее перемещение:
$$x_{k+1}=x_k-\alpha\nabla f(x_k)+\beta(x_k-x_{k-1}),\quad x_{-1}=x_0.$$
При $\beta=0$ это GD; затраты — один градиент и $O(n)$ векторных операций, память $O(n)$. Подстановка $\nabla f(x_k)=Ae_k$ даёт
$$e_{k+1}=((1+\beta)I-\alpha A)e_k-\beta e_{k-1}.$$
Каждая собственная компонента удовлетворяет
$$z_{k+1}=(1-\alpha\lambda+\beta)z_k-\beta z_{k-1},\quad r^2-(1-\alpha\lambda+\beta)r+\beta=0.$$
Для желаемого сходящегося режима положим $\beta=q^2$, $0<q<1$. Тогда оба корня имеют модуль не больше $q$ ровно при
$$|1-\alpha\lambda+q^2|\le2q.$$
Действительно, произведение корней равно $q^2$: если оба модуля $\le q$, то оба равны $q$; корни либо сопряжены, либо совпадают в $\pm q$. Обратно, неположительный дискриминант даёт именно такие корни. Отсюда полоса
$$ (1-q)^2\le\alpha\lambda\le(1+q)^2.$$
Для всего спектрального интервала она эквивалентна
$$\frac{(1-q)^2}{\mu}\le\alpha\le\frac{(1+q)^2}{L}.$$
Интервал непуст тогда и только тогда, когда $\sqrt L(1-q)\le\sqrt\mu(1+q)$, то есть
$$q\ge q^\star=\frac{\sqrt L-\sqrt\mu}{\sqrt L+\sqrt\mu}=\frac{\sqrt\kappa-1}{\sqrt\kappa+1}.$$
При равенстве
$$\alpha^\star=\frac4{(\sqrt L+\sqrt\mu)^2},\qquad \beta^\star=(q^\star)^2.$$

Почему выбор $\beta=q^2$ даёт глобальный минимум по параметрам? Пусть произвольные $\beta\ge0$ дают все корни в диске радиуса $q<1$. По произведению корней $\beta\le q^2$. При действительных корнях вычисление многочлена в $q$ и $-q$ даёт $|1+\beta-\alpha\lambda|\le q+\beta/q$; при сопряжённых $|r_1+r_2|\le2\sqrt\beta\le q+\beta/q$. Поэтому
$$\alpha\mu\ge(1-q)(1-\beta/q),\quad \alpha L\le(1+q)(1+\beta/q).$$
Следовательно, $\kappa\le\frac{(1+q)(1+\beta/q)}{(1-q)(1-\beta/q)}\le((1+q)/(1-q))^2$, поскольку $\beta/q\le q$. Это та же нижняя граница на $q$; найденная настройка её достигает. Этот дополнительный шаг раскрывает минимаксный смысл настройки слайдов [[OptChapter_Lecture6_slides.pdf#page=11|Л6, с. 11–13]]. При $\kappa=1$ отдельно: $\alpha=1/\mu$, $\beta=q=0$, решение за один шаг.

### Что означает скорость

$q^\star=1-\Theta(\kappa^{-1/2})$ — спектральный коэффициент, у GD $1-\Theta(\kappa^{-1})$. На концах спектра у оптимального heavy ball корень двойной, поэтому компонента обычно имеет вид $(a+bk)(\pm q^\star)^k$. Нельзя без оговорки написать $\|e_k\|\le C(q^\star)^k$ с постоянным $C$: остаётся множитель $k$. Асимптотический корневой коэффициент по-прежнему $q^\star$.

Линейная рекурсия точна именно для квадратичной функции с постоянной матрицей $A$. Для произвольной сильно выпуклой гладкой функции гессиан меняется вдоль траектории; приведённое доказательство не даёт глобального ускорения. Это ограничение явно отмечено на [[OptChapter_Lecture6_slides.pdf#page=14|с. 14]].

## На пальцах

Возьмём знакомый овраг $f(x,y)=\frac12(x^2+9y^2)$, $x_0=y_0=1$, предыдущее положение такое же. Здесь $\mu=1$, $L=9$, $\kappa=9$. Оптимальный GD: $\alpha=1/5$, множители $4/5$ и $-4/5$. Heavy ball: $q=1/2$, $\alpha=\beta=1/4$; вдоль $x$ корень $1/2$ двойной, вдоль $y$ — $-1/2$ двойной.

Первые положения: $(1,1)\to(3/4,-5/4)\to(1/2,1)$. После первого шага значение выросло с $5$ до $117/16=7{,}3125$: инерционный метод не обязан спускаться на каждом шаге. Точные формулы:
$$x_k=\frac{k+2}{2^{k+1}},\qquad y_k=(-1)^k\frac{3k+2}{2^{k+1}}.$$
Они показывают и быстрый множитель $1/2$, и добавочный $k$. Упрощение: главные оси уже совпадают с координатными осями.

![[Л6 сл14 — множитель k и контрпример.png]]
На что смотреть: слева тот же овраг из той же точки — худшая координата шарика $(3k+2)/2^{k+1}$ сначала растёт до $5/4$, потом падает быстрее GD с $0{,}8^k$: до $10^{-3}$ за $15$ шагов против $31$; пунктир $0{,}5^k$ — модуль корней без множителя $k$. Справа контрпример Лессара: гладкая сильно выпуклая, но не квадратичная функция с $\mu=1$, $L=25$, где квадратичная настройка $\alpha^\star=1/9$, $\beta^\star=4/9$ не сходится.

## Ошибки и границы применимости

- Не переносить квадратичную настройку на весь гладкий сильно выпуклый класс.
- $q$ относится к компонентам ошибки; значение квадратичной функции содержит их квадраты.
- Не забывать двойные корни и множитель $k$; убывание каждого значения цели не гарантировано.

## Самопроверка

1. Рекурсия по собственному направлению.
2. Спектральная полоса и все три оптимальных параметра.
3. Почему нельзя выкинуть множитель $k$?
4. Параметры при $\mu=1$, $L=100$.

> [!success]- Ответы
> 1. $z_{k+1} = (1 - \alpha\lambda + \beta) z_k - \beta z_{k-1}$, характеристическое $r^2 - (1 - \alpha\lambda + \beta) r + \beta = 0$.
> 2. При $\beta = q^2$ оба корня по модулю $\le q$ $\iff$ $|1 - \alpha\lambda + q^2| \le 2q$ $\iff$ $(1 - q)^2 \le \alpha\lambda \le (1 + q)^2$. На $[\mu, L]$: $\frac{(1 - q)^2}{\mu} \le \alpha \le \frac{(1 + q)^2}{L}$, непусто при $q \ge q^\star = \frac{\sqrt\kappa - 1}{\sqrt\kappa + 1}$; $\alpha^\star = \frac{4}{(\sqrt L + \sqrt\mu)^2}$, $\beta^\star = (q^\star)^2$.
> 3. На концах спектра корень двойной, компонента $(a + b k)(\pm q^\star)^k$ с $b \ne 0$; в примере $y_k = (-1)^k \frac{3k + 2}{2^{k+1}}$ и $|y_1| = \frac54 > |y_0|$. Оценка $C (q^\star)^k$ с постоянным $C$ неверна.
> 4. $\sqrt\kappa = 10$: $q^\star = \frac{9}{11}$, $\alpha^\star = \frac{4}{121}$, $\beta^\star = \frac{81}{121}$; у лучшего GD $q = \frac{99}{101}$.
