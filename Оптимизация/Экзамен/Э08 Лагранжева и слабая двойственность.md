# Э08 Лагранжева и слабая двойственность

## Официальный вопрос

**8. Лагранжева двойственность и слабая двойственность.**
Лагранжиан как источник нижних оценок; двойственная функция и её вогнутость; двойственная задача как задача выпуклой оптимизации; слабая двойственность; двойственный разрыв.

Программа: [[OptChapter_Exam.pdf#page=2|с. 2]].

## Требования к ответу

- **Формулировать и применять:** двойственную функцию с инфимумом по исходной области $x$, прямую и двойственную задачи, допустимость множителей, оптимальные значения и двойственный разрыв.
- **Доказывать:** нижнюю оценку из лагранжиана; вогнутость двойственной функции; выпуклость двойственной задачи в смысле максимизации вогнутой функции на выпуклой области; слабую двойственность.
- **Объяснять идею:** множители параметризуют гарантированные нижние оценки; двойственная задача выбирает лучшую из них. Выпуклость прямой задачи для этих фактов не нужна.

## План устного ответа

1. Стандартная форма задачи и знак множителей.
2. Цепочка $g\le L\le f$ и независимая от допустимой точки нижняя оценка.
3. Вогнутость инфимума аффинных функций.
4. Двойственная задача, слабая двойственность и сертификат точности.

## Полный ответ

### Лагранжиан как нижняя оценка

Пусть прямая задача имеет вид
$$p^\star=\inf\{f(x):s_i(x)\le0,\ h_j(x)=0\}.$$
Для простоты, как в основных формулах лекции, функции определены на $\mathbb R^n$. Если есть общая собственная область определения $D$, все инфимумы по $x$ ниже берутся по $D$; сами ограничения $s_i\le0,h_j=0$ при этом в инфимум не возвращают.

Лагранжиан:
$$L(x,\lambda,\nu)=f(x)+\sum_i\lambda_i s_i(x)+\sum_j\nu_jh_j(x).$$
При $\lambda\ge0$ и **прямо допустимой** $x$ имеем $\lambda_i s_i(x)\le0$, $\nu_jh_j(x)=0$, следовательно
$$L(x,\lambda,\nu)\le f(x).$$
Именно знак $\lambda_i\ge0$ обеспечивает нижнюю оценку при принятом соглашении $s_i\le0$. У множителей равенств знак свободный. При недопустимом $x$ такой оценки между $L$ и $f$ вообще может не быть. Источник: [[OptChapter_Lecture2_slides.pdf#page=34|Л2, с. 34]].

### Двойственная функция

Определим
$$g(\lambda,\nu)=\inf_{x\in\mathbb R^n}L(x,\lambda,\nu).$$
Значение может быть $-\infty$, а инфимум не обязан достигаться. Нельзя автоматически заменить инфимум решением уравнения $\nabla_xL=0$: это уравнение находит лишь стационарных кандидатов, если нет условий глобального минимума.

Для любых $\lambda\ge0$, $\nu$ и любой прямо допустимой $x$
$$g(\lambda,\nu)\le L(x,\lambda,\nu)\le f(x).$$
Первая оценка верна для любой $x$ по определению инфимума. Вторая — по допустимости $x$ и знаку множителей. Раз оценка верна для всех прямо допустимых $x$, то
$$g(\lambda,\nu)\le p^\star.$$
Получено число, не зависящее от неизвестной оптимальной точки; плохие множители могут давать бесполезное $-\infty$, но не завышенную нижнюю оценку. Источник: [[OptChapter_Lecture2_slides.pdf#page=35|Л2, с. 35]].

### Вогнутость двойственной функции

**Утверждение.** $g$ вогнута по совместной переменной $z=(\lambda,\nu)$ независимо от выпуклости исходной задачи.

**Доказательство.** При фиксированном $x$ зависимость $L(x,z)$ от $z$ аффинна. Поэтому для $0<t<1$
$$L(x,(1-t)z_1+tz_2)=(1-t)L(x,z_1)+tL(x,z_2).$$
Для каждого $x$ правая часть не меньше $(1-t)g(z_1)+tg(z_2)$, поскольку каждый лагранжиан не меньше своего инфимума по $x$. Взяв инфимум слева, получаем
$$g((1-t)z_1+tz_2)\ge(1-t)g(z_1)+tg(z_2).$$
Это вогнутость. Если одно из значений равно $-\infty$, неравенство для внутреннего $t$ тривиально в расширенном смысле; на концах оно читается как равенство без неопределённых произведений $0\cdot(-\infty)$. Источник: [[OptChapter_Lecture2_slides.pdf#page=37|Л2, с. 37]].

Смысл направления неравенства: инфимум суммы не меньше суммы инфимумов; одна и та же точка $x$ не обязана одновременно минимизировать два разных лагранжиана.

### Двойственная задача выпуклая

Ищем лучшую нижнюю оценку:
$$d^\star=\sup_{\lambda\ge0,\nu}g(\lambda,\nu).$$
Это **двойственная задача**. Даже если принято писать $\max$, достижение супремума требует отдельного обоснования.

Функция $g$ вогнута, а множество $\{(\lambda,\nu):\lambda\ge0\}$ выпукло. Максимизация вогнутой функции на выпуклом множестве — выпуклая задача оптимизации; эквивалентно минимизируется выпуклая функция $-g$. Если учитывать эффективную область $\{g>-\infty\}$, она также выпукла: вогнутость сохраняет конечную нижнюю границу на комбинациях точек с конечными значениями. Это не означает, что $g$ гладкая, максимум достигается или задача вычислительно проста. Источник: [[OptChapter_Lecture2_slides.pdf#page=38|Л2, с. 38–39]].

### Слабая двойственность и разрыв

**Теорема слабой двойственности:**
$$d^\star\le p^\star.$$
**Доказательство.** Для каждого допустимого набора множителей уже получено $g(\lambda,\nu)\le p^\star$. Число $p^\star$ — верхняя граница всех этих значений, значит их супремум не больше него. Выпуклость, регулярность и достижение оптимумов для этого перехода не требуются. Источник: [[OptChapter_Lecture2_slides.pdf#page=40|Л2, с. 40]].

При конечных оптимальных значениях величина $p^\star-d^\star\ge0$ — **оптимальный двойственный разрыв**. Если $d^\star=p^\star$, говорят о сильной двойственности; она не следует из слабой автоматически ([[OptChapter_Lecture2_slides.pdf#page=41|Л2, с. 41]]). С бесконечностями разность нужно обсуждать осторожно: выражение $\infty-\infty$ не определено.

Практический разрыв для прямо допустимой $\widehat x$ и двойственно допустимых $(\widehat\lambda,\widehat\nu)$ с конечным $g$ даёт сертификат
$$0\le f(\widehat x)-p^\star\le f(\widehat x)-g(\widehat\lambda,\widehat\nu).$$
Для него не нужны оптимальные множители и сильная двойственность: достаточно нижней оценки. Оптимальный разрыв $p^\star-d^\star$ и разрыв конкретной допустимой пары — разные величины.

## На пальцах

Сквозная задача: $\min (x-2)^2$ при $x\le1$. Имеем $p^\star=1$. Для $\lambda\ge0$
$$L(x,\lambda)=(x-2)^2+\lambda(x-1).$$
По $x$ это строго выпуклая парабола; её минимум достигается при $x(\lambda)=2-\lambda/2$. Подставляя, получаем
$$g(\lambda)=\lambda-\lambda^2/4.$$
При $\lambda=1$ оценка $g(1)=3/4\le1$. При $\lambda=2$ получаем $g(2)=1$, и никакая нижняя оценка не может быть больше $p^\star=1$. Следовательно, $d^\star=1$.

Возьмём допустимую в исходной задаче точку $\widehat x=0$, где цель $4$, и множитель $1$, где нижняя оценка $3/4$. Сертификат $4-3/4=13/4$ — верхняя оценка истинной ошибки $4-1=3$. Это работает, хотя ни $\widehat x$, ни множитель $1$ не оптимальны. Упрощение: инфимум параболы вычисляется точно; в общей задаче сам расчёт $g$ может быть отдельной трудной задачей. Источник формулы примера: [[OptChapter_Lecture2_slides.pdf#page=49|Л2, с. 49]].

```desmos-graph
left=0; right=5;
bottom=-1.5; top=1.5;
---
y=x-x^2/4|blue
y=1|green|dashed
(1,0.75)|black
(2,1)|red
```
На что смотреть: горизонтальная ось здесь означает $\lambda$, синяя кривая — $g(\lambda)$, а зелёная линия — оптимальное значение прямой задачи $p^\star=1$. Все двойственные оценки лежат не выше него.

## Типичные ошибки и границы

- В определении $g$ минимизируется лагранжиан по всей исходной области $x$, а не только по точкам, удовлетворяющим ограничениям задачи.
- $g$ вогнута по множителям, но $L$ по $x$ может быть невыпуклым.
- Нижняя оценка при фиксированном множителе, лучшая нижняя оценка $d^\star$ и минимум $p^\star$ — три разных объекта.
- Заменять $\inf$ и $\sup$ на достигаемые $\min$ и $\max$ без условий нельзя.

## Самопроверка

1. Доказать вогнутость $g$. Почему неравенство между инфимумами направлено именно так?
2. Вывести слабую двойственность. Где использован знак $\lambda$?
3. Для сквозной задачи: $g(4)$ и оценка ошибки допустимой точки $x=0$ по этому множителю.
4. Чем отличаются оптимальный двойственный разрыв и разрыв конкретной допустимой пары?

> [!success]- Ответы
> 1. При фиксированном $x$ лагранжиан аффинен по $z = (\lambda, \nu)$: $L(x, (1 - t) z_1 + t z_2) = (1 - t) L(x, z_1) + t L(x, z_2) \ge (1 - t) g(z_1) + t g(z_2)$; инфимум по $x$ слева даёт вогнутость. Инфимум суммы не меньше суммы инфимумов: одна точка $x$ не обязана минимизировать оба лагранжиана.
> 2. Для $\lambda \ge 0$ и допустимого $x$: $g \le L(x, \lambda, \nu) \le f(x)$; знак нужен во втором неравенстве — $\lambda_i s_i(x) \le 0$. Инфимум по допустимым $x$ даёт $g \le p^\star$, супремум по множителям — $d^\star \le p^\star$.
> 3. $g(4) = 4 - \frac{16}{4} = 0$. Оценка $f(0) - g(4) = 4 - 0 = 4$, истинная ошибка $4 - 1 = 3$ — оценка верна, но грубее, чем с $\lambda = 1$ ($\frac{13}{4}$).
> 4. $p^\star - d^\star$ — свойство задачи, здесь $0$. $f(\widehat x) - g(\widehat\lambda, \widehat\nu)$ считается для любой допустимой пары, не меньше $p^\star - d^\star$ и ограничивает сверху ошибку $f(\widehat x) - p^\star$.
