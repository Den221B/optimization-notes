# С1-7 МНК, константы L, μ, κ

> [!question] Условие · семинар 1, [[OptChapter_Sem1_slides.pdf#page=37|сл. 37–46]]
> $f(x) = \frac12 \|Ax - b\|_2^2$. (a) $\nabla f$, $\nabla^2 f$, выпуклость. (b) Точная $L^\star$. (c) Когда $f$ сильно выпукла; $\mu^\star$. (d) $\kappa_f$ при полном столбцовом ранге. (e) То же для $f_\lambda = f + \frac{\lambda}{2} \|x\|^2$.

> [!success]- Итог семинара — открыть после своей попытки
> $\nabla f = A^\top (Ax - b)$, $\nabla^2 f = A^\top A \succeq 0$; $L^\star = \sigma_{\max}^2$; сильно выпукла $\iff$ полный столбцовый ранг, $\mu^\star = \sigma_{\min}^2$; $\kappa_f = \kappa_2(A)^2$. Для $f_\lambda$: $\mu_\lambda = \sigma_{\min}^2 + \lambda$, $L_\lambda = \sigma_{\max}^2 + \lambda$, $\kappa_\lambda = \frac{\sigma_{\max}^2 + \lambda}{\sigma_{\min}^2 + \lambda}$ — меньше, чем без регуляризации.
