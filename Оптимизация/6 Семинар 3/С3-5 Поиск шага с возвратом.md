# С3-5 Поиск шага с возвратом

> [!question] Условие · семинар 3, [[OptChapter_Sem3_slides.pdf#page=33|сл. 33–37]]
> $f(x) = -\log x + \frac12 (x - 2)^2$, $x > 0$; $x_k = 4$, $p_k = -5$; условие Армихо с $c_1 = 0{,}1$, начальный шаг $\alpha = 1$, после отказа $\alpha \leftarrow \alpha / 2$. (1) Найдите первый принятый шаг. (2) Какие вычисления функции фактически потребовались?

> [!success]- Итог семинара — открыть после своей попытки
> $f'(4) = \frac74$, $f'(4)\, p_k = -\frac{35}{4} < 0$ — направление спуска. $\alpha = 1$: точка $-1 \notin \operatorname{dom} f$ — отказ без вычисления $f$. $\alpha = \frac12$: точка $\frac32$; условие Армихо сводится к $\log \frac83 \le \frac{23}{16}$, $0{,}981 < 1{,}4375$ — шаг принят. Итог: $\alpha_k = \frac12$, одно новое вычисление $f(3/2)$.
