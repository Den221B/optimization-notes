# С3-4 Скорость против цены итерации

> [!question] Условие · семинар 3, [[OptChapter_Sem3_slides.pdf#page=27|сл. 27–32]]
> Для двух алгоритмов $e^{(A)}_k \le C_A / k$ и $e^{(B)}_k \le C_B q^k$, $0 < q < 1$; итерация стоит $T_A$ и $T_B$. (1) Найдите достаточные $N_A(\varepsilon)$, $N_B(\varepsilon)$. (2) Оцените полную работу $W_A$, $W_B$. (3) Когда B выгоднее, несмотря на более дорогую итерацию? (4) Исследуйте $W_B / W_A$ при $\varepsilon \downarrow 0$.

> [!success]- Итог семинара — открыть после своей попытки
> $N_A = \lceil C_A / \varepsilon \rceil$, $N_B = \Big\lceil \frac{\log(C_B / \varepsilon)}{\log(1/q)} \Big\rceil$. $W = T N$: порядки $O(1/\varepsilon)$ и $O(\log(1/\varepsilon))$. B выгоднее, когда $T_B N_B < T_A N_A$. $\frac{W_B}{W_A} \approx \frac{T_B}{T_A C_A \log(1/q)}\, \varepsilon \log \frac{C_B}{\varepsilon} \to 0$: при высокой точности логарифм побеждает любое отношение $T_B / T_A$.
