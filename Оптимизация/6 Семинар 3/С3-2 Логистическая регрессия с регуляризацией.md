# С3-2 Логистическая регрессия с регуляризацией

> [!question] Условие · семинар 3, [[OptChapter_Sem3_slides.pdf#page=11|сл. 11–20]]
> $f(x) = \sum_{i=1}^m \log\big(1 + e^{-y_i a_i^\top x}\big) + \frac{\lambda}{2}\|x\|_2^2$, $y_i \in \{-1, 1\}$, $\lambda > 0$; $A$ — матрица со строками $a_i^\top$. (1) Найдите градиент и гессиан. (2) Покажите $\lambda$-сильную выпуклость. (3) Найдите глобальную $L$. (4) Какой фиксированный шаг гарантирует теория лекции? (5) Запишите ньютоновскую систему. (6) Сравните стоимость градиентного метода и Ньютона при плотной $A$.

> [!success]- Итог семинара — открыть после своей попытки
> С $q_i = \frac{1}{1 + e^{y_i a_i^\top x}}$: $\nabla f = -\sum_i q_i y_i a_i + \lambda x$, $\nabla^2 f = A^\top D(x) A + \lambda I$, $D = \operatorname{Diag}\big(q_i(1 - q_i)\big)$. $D \succeq 0 \Rightarrow \nabla^2 f \succeq \lambda I$. Из $q(1 - q) \le \frac14$: $L = \lambda + \frac14 \|A\|_2^2$, шаг $\alpha = 1/L$. Система $(A^\top D A + \lambda I)\, p_k = -\nabla f(x_k)$. Градиент — $O(mn)$; гессиан — $O(mn^2)$, факторизация — $O(n^3)$, память — $O(n^2)$.
