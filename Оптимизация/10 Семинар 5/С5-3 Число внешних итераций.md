# С5-3 Число внешних итераций

> [!question] Условие · семинар 5, [[OptChapter_Sem5_slides.pdf#page=10|сл. 10–12]]
> В барьерном методе $t_{k+1} = \mu t_k$, $\mu > 1$, $t_0 > 0$; для точного решения центрирующей задачи $0 \le f(x^\star(t)) - f^\star \le \frac mt$. Критерий остановки: $m / t_k \le \varepsilon$.
> (1) Получите явную формулу для $t_k$.
> (2) Найдите минимальное число внешних увеличений $t$, достаточное для критерия остановки.
> (3) Для $m = 100$, $t_0 = 1$, $\varepsilon = 10^{-4}$ найдите это число при $\mu = 2, 10, 20$.
> (4) Объясните, почему отсюда не следует, что на практике нужно брать $\mu$ сколь угодно большим.

> [!success]- Итог семинара — открыть после своей попытки
> $t_k = \mu^k t_0$. $\frac{m}{\mu^k t_0} \le \varepsilon \iff k \ge \frac{\log(m / (\varepsilon t_0))}{\log \mu}$, $k_{\min} = \max\Big\{0, \Big\lceil \frac{\log(m / (\varepsilon t_0))}{\log \mu} \Big\rceil\Big\}$. Здесь $\mu^k \ge 10^6$: $\mu = 2$ — $k = 20$ ($2^{19} < 10^6 < 2^{20}$), $\mu = 10$ — $k = 6$, $\mu = 20$ — $k = 5$. Это только внешние обновления; каждое требует новой центрирующей задачи. При большом $\mu$ предыдущая центральная точка — худший старт, нужно больше ньютоновских шагов: полная работа $\approx \sum_k$ работа центрирования при $t_k$.
