# С5-2 Монотонность вдоль центральной траектории

> [!question] Условие · семинар 5, [[OptChapter_Sem5_slides.pdf#page=7|сл. 7–9]]
> $\min_x f(x)$ при $s_i(x) \le 0$, $Ax = b$; $\phi(x) = -\sum_{i=1}^m \log(-s_i(x))$, $x^\star(t) \in \arg\min_{Ax = b} \{t f(x) + \phi(x)\}$. Для $0 < t_1 < t_2$ обозначим $x_1 = x^\star(t_1)$, $x_2 = x^\star(t_2)$.
> (1) Используя только оптимальность $x_1$ и $x_2$, докажите $f(x_2) \le f(x_1)$.
> (2) Докажите $\phi(x_1) \le \phi(x_2)$.
> (3) Объясните смысл обоих неравенств для движения по центральной траектории при увеличении $t$.

> [!success]- Итог семинара — открыть после своей попытки
> Оптимальность: $t_1 f(x_1) + \phi(x_1) \le t_1 f(x_2) + \phi(x_2)$ и $t_2 f(x_2) + \phi(x_2) \le t_2 f(x_1) + \phi(x_1)$. Сумма: члены с $\phi$ сокращаются, $(t_2 - t_1) f(x_2) \le (t_2 - t_1) f(x_1)$, откуда $f(x_2) \le f(x_1)$. Из первого: $\phi(x_2) - \phi(x_1) \ge t_1 (f(x_1) - f(x_2)) \ge 0$. С ростом $t$ вес цели растёт: $f(x^\star(t))$ не возрастает, $\phi(x^\star(t))$ не убывает — точка уходит от области, предпочитаемой барьером, к решению, часто лежащему на границе. Доказана только нестрогая монотонность.
