# Л2 сл44 Дополняющая нежёсткость из сильной двойственности

> [!abstract] Утверждение · [[OptChapter_Lecture2_slides.pdf#page=44|сл. 44–45]]
> Пусть $x^\star$ — оптимальная точка прямой задачи, $(\lambda^\star, \nu^\star)$ — оптимальные двойственные переменные и имеет место сильная двойственность. Тогда
> $$\lambda_i^\star s_i(x^\star) = 0 \quad \forall i.$$
> Дополняющая нежёсткость при сильной двойственности следует из равенства прямого и двойственного оптимальных значений, а не является произвольным дополнительным условием.

## На пальцах
Сквозной пример с лишним неактивным ограничением $x \ge -5$, то есть $s_2 = -5 - x \le 0$. В $x^\star = 1$ оно равно $-6$.
- Цепочка $f(x^\star) = g(\lambda^\star) \le L(x^\star, \lambda^\star) \le f(x^\star)$ зажимает $L(x^\star, \lambda^\star)$ между равными числами, и добавка $\sum_i \lambda_i^\star s_i(x^\star)$ обязана быть нулём.
- Попробуем $\lambda_2 = 0{,}1$: добавка $0{,}1 \cdot (-6) = -0{,}6$, и $L(x^\star, \lambda) = 1 - 0{,}6 = 0{,}4$. Тогда $g(\lambda) \le 0{,}4 < p^\star$ — такой набор множителей не может быть оптимальным при сильной двойственности.
- Сумма неположительных слагаемых равна нулю, только если каждое равно нулю: $2 \cdot 0 = 0$ и $\lambda_2^\star \cdot (-6) = 0$, откуда $\lambda_2^\star = 0$.

Упрощение: нарушитель здесь один и виден сразу. В общем случае тот же довод работает для каждого $i$ по отдельности.
