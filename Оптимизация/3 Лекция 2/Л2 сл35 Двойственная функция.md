# Л2 сл35 Двойственная функция

> [!abstract] Определение · [[OptChapter_Lecture2_slides.pdf#page=35|сл. 35]]
> **Двойственная функция Лагранжа**
> $$g(\lambda, \nu) = \inf_{x \in \mathbb R^n} L(x, \lambda, \nu).$$
> Её значение может быть равно $-\infty$. Для любых $\lambda \ge 0$, любых $\nu$ и любой допустимой $x$: $g(\lambda, \nu) \le L(x, \lambda, \nu) \le f(x)$. Следовательно,
> $$g(\lambda, \nu) \le p^\star \quad \text{при } \lambda \ge 0.$$
> Каждый допустимый набор множителей задаёт нижнюю оценку на оптимальное значение прямой задачи.

Инфимум берётся по всему $\mathbb R^n$, а не по $D$: ограничения уже вошли в $L$ слагаемыми $\lambda_i s_i$ и $\nu_j h_j$, и считать приходится безусловный минимум.

## На пальцах
Сквозной пример. При фиксированном $\lambda$ лагранжиан $(x - 2)^2 + \lambda (x - 1)$ — парабола по $x$ с дном в $x(\lambda) = 2 - \frac{\lambda}{2}$, и $g(\lambda) = \lambda - \frac{\lambda^2}{4}$.

| $\lambda$ | $0$ | $1$ | $2$ | $4$ |
|---|---|---|---|---|
| $g(\lambda)$ | $0$ | $0{,}75$ | $1$ | $0$ |

Все значения $\le p^\star = 1$. При $\lambda = 0$ оценка — просто минимум без ограничения: $\min (x - 2)^2 = 0$.

$g = -\infty$ — обычное дело: $\min x$ при $x \ge 0$, $L = x - \lambda x = (1 - \lambda) x$. При $\lambda \ne 1$ это непостоянная линейная функция, её инфимум $-\infty$. Полезен только $\lambda = 1$: $g(1) = 0 = p^\star$.

Упрощение: одна двойственная переменная, $g$ — кривая. При $m + p$ множителях $g$ — функция на $(m + p)$-мерном пространстве.

```desmos-graph
left=-0.5; right=5;
bottom=-1.5; top=2;
---
y=x-x^2/4|blue
y=1|red|dashed
l=1|slider:0..4.5..0.01
(l,l-l^2/4)|blue|label:g
(2,1)|red|label:λ* = 2
```
На что смотреть: здесь по горизонтали $\lambda$, а не $x$. Синяя — $g(\lambda)$, красный пунктир — $p^\star = 1$. Двигай ползунок $l$ (это $\lambda$): оценка всё время под пунктиром и касается его только при $\lambda = 2$.
