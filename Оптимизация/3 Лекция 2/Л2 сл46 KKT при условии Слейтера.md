# Л2 сл46 KKT при условии Слейтера

> [!abstract] Теорема · [[OptChapter_Lecture2_slides.pdf#page=46|сл. 46]]
> Пусть $f$, $s_1, \dots, s_m$ — дифференцируемые выпуклые функции, ограничения-равенства аффинны и выполнено условие Слейтера. Тогда допустимая $x^\star$ — точка глобального минимума $\iff$ существуют $\lambda^\star \ge 0$ и $\nu^\star$, для которых выполнены условия KKT.
> Достаточность доказана раньше и Слейтера не требует. Необходимость в выпуклой задаче даёт условие Слейтера: из него следуют сильная двойственность и существование оптимальных двойственных множителей.

## На пальцах
Рецепт решения задач семинара на примере $\min x^2 + y^2$ при $x + y \ge 2$.
1. Выпуклость: $f$ выпукла, ограничение $s = 2 - x - y$ аффинно.
2. Слейтер: точка $(2, 2)$, $s = -2 < 0$.
3. KKT перебором активности: $(2x, 2y) + \lambda (-1, -1) = 0$, $\lambda (2 - x - y) = 0$.
   - неактивно, $\lambda = 0$: $x = y = 0$ — недопустимо;
   - активно: $x = y = \frac{\lambda}{2}$ и $x + y = 2$, то есть $(1, 1)$, $\lambda = 2 \ge 0$.
4. По теореме $(1, 1)$ — глобальный минимум (достаточность), и других минимумов нет: каждый обязан был бы пройти KKT (необходимость), а перебор нашёл только эту точку.

Без Слейтера рушится вторая половина пункта 4: в $\min x$ при $x^2 \le 0$ перебор KKT не находит ничего, хотя минимум есть.

Упрощение: одно ограничение, два случая перебора. При $m$ неравенствах случаев до $2^m$ — по подмножествам активных.
