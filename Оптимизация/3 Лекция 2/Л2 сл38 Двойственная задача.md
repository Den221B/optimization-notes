# Л2 сл38 Двойственная задача

> [!abstract] Определение + следствие · [[OptChapter_Lecture2_slides.pdf#page=38|сл. 38–39]]
> **Двойственная задача** ищет наилучшую нижнюю оценку:
> $$\max_{\lambda, \nu} g(\lambda, \nu) \quad \text{при } \lambda \ge 0, \qquad d^\star = \sup_{\lambda \ge 0, \, \nu} g(\lambda, \nu).$$
> Различие: $g(\lambda, \nu)$ — нижняя оценка при фиксированных множителях; двойственная задача ищет лучшую из таких оценок.
> **Следствие.** Двойственная задача выпукла, даже когда исходная невыпукла: максимизировать вогнутую $g$ — то же, что минимизировать выпуклую $-g$, а множество $\{(\lambda, \nu) : \lambda \ge 0\}$ выпукло.

## На пальцах
Сквозной пример: $\max_{\lambda \ge 0} \big(\lambda - \frac{\lambda^2}{4}\big)$. Производная $1 - \frac{\lambda}{2} = 0$ при $\lambda^\star = 2$, $d^\star = 1$. Задача на одну переменную — горка, вершина находится в уме.

Выпуклость исходной задачи не нужна: $\min -x^2$ при $x^2 \le 1$ — невыпуклая задача, два минимума $x = \pm 1$, $p^\star = -1$.
- $L = -x^2 + \lambda (x^2 - 1) = (\lambda - 1) x^2 - \lambda$.
- При $\lambda < 1$ парабола смотрит вниз, $g = -\infty$. При $\lambda \ge 1$ минимум в $x = 0$, $g(\lambda) = -\lambda$.
- Двойственная задача — максимум линейной функции $-\lambda$ на луче $\lambda \ge 1$: выпуклая, $\lambda^\star = 1$, $d^\star = -1$.

Упрощение: в обоих примерах одна двойственная переменная. В общем случае их $m + p$ — по одной на ограничение, сколько бы ни было прямых переменных.
