# Л2 сл17 Стационарная точка

> [!abstract] Определение · [[OptChapter_Lecture2_slides.pdf#page=17|сл. 17]]
> Пусть $\varphi : \mathbb R^n \to \mathbb R$ дифференцируема. Точка $x$ — **стационарная** точка $\varphi$, если $\nabla \varphi(x) = 0$.
> Стационарность необходима для внутреннего локального минимума, но не достаточна: стационарная точка может быть максимумом или седловой точкой.
> Для лагранжиана важна стационарность по $x$ при фиксированных множителях:
> $$\nabla_x L(x, \lambda, \nu) = \nabla f(x) + \sum_{i=1}^m \lambda_i \nabla s_i(x) + \sum_{j=1}^p \nu_j \nabla h_j(x) = 0.$$

## На пальцах
- $\varphi = x^2 - y^2$: $\nabla \varphi(0, 0) = (0, 0)$, но это седло. Вдоль $x$ значения растут, $\varphi(t, 0) = t^2$; вдоль $y$ падают, $\varphi(0, t) = -t^2$.
- $\varphi = -x^2$: в нуле стационарна, и это максимум.

Стационарность лагранжиана — только по $x$, множители заморожены. В сквозном примере $\frac{\partial L}{\partial x} = 2(x - 2) + \lambda = 0$ даёт $x = 2 - \frac{\lambda}{2}$ — своё для каждого $\lambda$. При $\lambda = 0$ это $x = 2$, точка недопустима. Одна стационарность $\lambda$ не выбирает: это делают остальные условия KKT.

Упрощение: седло $x^2 - y^2$ видно в 2D. В $\mathbb R^n$ знаки кривизны по разным направлениям показывает гессиан ([[Б11 Положительная определённость и матричный порядок]]).
