# Л2 сл37 Вогнутость двойственной функции

> [!abstract] Определение + утверждение · [[OptChapter_Lecture2_slides.pdf#page=36|сл. 36–37]]
> Функция $q$ на выпуклом множестве **вогнута**, если для любых $z_1$, $z_2$ из её области и $\theta \in [0, 1]$
> $$q(\theta z_1 + (1 - \theta) z_2) \ge \theta q(z_1) + (1 - \theta) q(z_2); \qquad q \text{ вогнута} \iff -q \text{ выпукла}.$$
> **Утверждение.** Двойственная функция $g(\lambda, \nu)$ всегда вогнута по $(\lambda, \nu)$ — независимо от того, выпукла ли исходная задача.

## На пальцах
Сквозной пример. При фиксированном $x$ лагранжиан как функция $\lambda$ — прямая $L(x, \lambda) = (x - 2)^2 + \lambda (x - 1)$: наклон $x - 1$, высота при $\lambda = 0$ равна $(x - 2)^2$.
- $x = 0$: $4 - \lambda$; $x = 1$: $1$ (горизонталь); $x = 1{,}5$: $0{,}25 + 0{,}5\lambda$; $x = 2$: $\lambda$; $x = 3$: $1 + 2\lambda$.
- $g(\lambda)$ — нижняя огибающая всех таких прямых. При $\lambda = 2$ эти пять прямых дают $2$, $1$, $1{,}25$, $2$, $5$ — минимум $1 = g(2)$. При $\lambda = 0$ — $4$, $1$, $0{,}25$, $0$, $1$, минимум $0 = g(0)$.

Минимум из прямых похож на крышу $\wedge$: у него не бывает ямок. Это и есть вогнутость. Выпуклость задачи для неё не нужна — при любой $f$ по $\lambda$ получаются прямые.

Упрощение: одна переменная $\lambda$, поэтому «аффинная по $(\lambda, \nu)$» — это прямая. При нескольких множителях — плоскости, а огибающая — купол.

![[Л2 сл37 — огибающая прямых.png]]
На что смотреть: серые прямые — $L(x, \lambda)$ для разных $x$, жирная синяя — их нижняя огибающая $g(\lambda) = \lambda - \frac{\lambda^2}{4}$. Каждая прямая лежит не ниже огибающей и касается её при $\lambda = 2(2 - x)$; прямая $x = 3$ касается её только при $\lambda = -2$, за пределами $\lambda \ge 0$. В $\lambda^\star = 2$ огибающую даёт горизонталь $x = 1$ на высоте $p^\star = 1$.

На что смотреть: по горизонтали — $\lambda$, ползунок $l$ — тоже $\lambda$. Пунктир — прямые $L(x, \cdot)$ для $x = 0;\ 0{,}5;\ 1;\ 1{,}5;\ 2;\ 3$, синяя — нижняя огибающая $g$. Красная — прямая того $x$, на котором при данном $\lambda$ достигается минимум $L$: $x(\lambda) = 2 - \frac{\lambda}{2}$. Двигай $l$: красная прямая касается огибающей, и в этой точке она ниже всех остальных — огибающая в каждой точке опирается на свою прямую.
