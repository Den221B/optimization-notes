# Л2 сл42 Условие Слейтера

> [!abstract] Определение · [[OptChapter_Lecture2_slides.pdf#page=42|сл. 42]]
> Выпуклая задача $\min f(x)$ при $s_i(x) \le 0$, $i = 1, \dots, m$, $Ax = b$ удовлетворяет **условию Слейтера**, если есть точка $\bar x$ в общей относительной внутренности областей определения функций, для которой
> $$s_i(\bar x) < 0, \ \ i = 1, \dots, m, \qquad A \bar x = b.$$
> Такую точку называют строго допустимой по неравенствам. Если все функции определены на всём $\mathbb R^n$, достаточно существования $\bar x$ с $s_i(\bar x) < 0$ для всех $i$ и $A \bar x = b$.

## На пальцах
Круг $x^2 + y^2 \le 1$ и полуплоскость $y \ge c$: $s_1 = x^2 + y^2 - 1$, $s_2 = c - y$.
- $c = 0{,}5$: точка $\bar x = (0;\ 0{,}75)$ строго внутри обоих, $s_1 = -0{,}4375 < 0$, $s_2 = -0{,}25 < 0$. Слейтер выполнен.
- $c = 1$: $D = \{(0, 1)\}$ — одна точка, в ней $s_1 = s_2 = 0$, строго допустимых точек нет. Слейтер нарушен.

Равенства строго выполнять не нужно. Множество $\{1\}$ на прямой, заданное равенством $x - 1 = 0$, Слейтеру не мешает. Оно же, заданное двумя неравенствами $x \le 1$ и $x \ge 1$, — мешает.

Упрощение: в 2D «строго внутри» видно глазами. В задачах с областями определения (логарифм, дробь) точку ещё надо брать внутри этих областей — об этом оговорка про относительную внутренность.

```desmos-graph
left=-2; right=2;
bottom=-1.3; top=1.4;
---
c=0.5|slider:-1..1.2..0.01
x^2+y^2\le 1|blue
y\ge c|green
(0,(1+c)/2)|red|label:x̄
```
На что смотреть: допустимое множество — где синий круг перекрывается с зелёной полуплоскостью. Красная точка лежит строго внутри, пока $c < 1$. При $c = 1$ область сжимается в точку $(0, 1)$ на обеих границах — Слейтер нарушен. При $c > 1$ пересечение пусто.
