# Л2 сл13 Множители Лагранжа для равенств

> [!abstract] Утверждение · [[OptChapter_Lecture2_slides.pdf#page=13|сл. 13–14]]
> Пусть $x^\star$ — точка локального минимума задачи с равенствами. Для любой допустимой кривой с $x(0) = x^\star$ функция $t \mapsto f(x(t))$ имеет локальный минимум при $t = 0$, поэтому
> $$\frac{d}{dt} f(x(t)) \Big|_{t = 0} = \nabla f(x^\star)^\top d = 0,$$
> то есть $\nabla f(x^\star)$ ортогонален всем касательным направлениям. При линейной независимости градиентов равенств $\nabla f(x^\star) \in T_{lin}(x^\star)^\perp$. Из линейной алгебры $T_{lin}(x^\star)^\perp = \operatorname{span}\{\nabla h_1(x^\star), \dots, \nabla h_p(x^\star)\}$, значит, есть числа $\nu_1^\star, \dots, \nu_p^\star$:
> $$\nabla f(x^\star) + \sum_{j=1}^p \nu_j^\star \nabla h_j(x^\star) = 0.$$
> Числа $\nu_j^\star$ называются **множителями Лагранжа** для ограничений-равенств.

## На пальцах
$\min\ (x - 1)^2 + (y - 2)^2 + z^2$ при $z = 1$: ближайшая к $(1, 2, 0)$ точка горизонтальной плоскости $z = 1$.
- На плоскости $f = (x - 1)^2 + (y - 2)^2 + 1$, минимум в $x^\star = (1, 2, 1)$, $f = 1$.
- $\nabla f(x^\star) = (0, 0, 2)$ — вертикален, то есть перпендикулярен всем касательным $d = (d_1, d_2, 0)$.
- $\nabla h = (0, 0, 1)$, и $\nabla f + \nu \nabla h = 0$ при $\nu = -2$.

Не в минимуме, в $(0, 2, 1)$: $\nabla f = (-2, 0, 2)$, у него есть горизонтальная часть $(-2, 0, 0)$. Вдоль плоскости в сторону $d = (1, 0, 0)$: $\nabla f^\top d = -2 < 0$ — функция убывает. И $(-2, 0, 2)$ не кратен $(0, 0, 1)$: подходящего $\nu$ нет.

Смысл: в минимуме от градиента остаётся только часть, перпендикулярная ограничению, и её гасит $\nu \nabla h$.

Упрощение: плоскость ровная, касательные направления видны сразу. На кривом ограничении — окружности, сфере — их даёт теорема о неявной функции.
