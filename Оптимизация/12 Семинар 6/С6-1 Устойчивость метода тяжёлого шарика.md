# С6-1 Устойчивость метода тяжёлого шарика

> [!question] Условие · семинар 6, [[OptChapter_Sem6_slides.pdf#page=2|сл. 2–12]]
> $f(x) = \frac\lambda2 x^2$, $\lambda > 0$; метод тяжёлого шарика $x_{k+1} = x_k - \alpha f'(x_k) + \beta (x_k - x_{k-1})$, $\alpha > 0$, $\beta \ge 0$.
> (1) Получите рекуррентное соотношение для $x_k$ и выпишите характеристический многочлен.
> (2) Найдите необходимые и достаточные условия на $\alpha$, $\beta$, при которых $x_k \to 0$ для любых $x_{-1}$, $x_0$.
> (3) Определите, когда корни характеристического многочлена вещественные, а когда комплексно-сопряжённые; свяжите тип корней с характером сходимости.
> (4) При $\lambda = 4$ исследуйте $(\alpha, \beta) = (0{,}2;\ 0)$, $(0{,}2;\ 0{,}5)$, $(0{,}7;\ 0{,}5)$ и вычислите несколько первых итераций при $x_{-1} = x_0 = 1$.

> [!success]- Итог семинара — открыть после своей попытки
> $x_{k+1} = (1 - \alpha\lambda + \beta) x_k - \beta x_{k-1}$, $p(r) = r^2 - (1 - \alpha\lambda + \beta) r + \beta$. Решение $C_1 r_1^k + C_2 r_2^k$ (при двойном корне $(C_1 + C_2 k) r^k$) стремится к нулю при любых начальных данных $\iff |r_1|, |r_2| < 1$. Необходимость: $r_1 r_2 = \beta$ даёт $\beta < 1$; $p(-1) = 2(1 + \beta) - \alpha\lambda > 0$ — у вещественных корней из $(-1, 1)$ это произведение положительных множителей, у комплексных $|1 + r_1|^2$. Достаточность: комплексные корни имеют модуль $\sqrt\beta < 1$; вещественный корень $\ge 1$ дал бы $p(1) \le 0$, но $p(1) = \alpha\lambda > 0$; корень $\le -1$ дал бы $p(-1) \le 0$. Итог: $0 \le \beta < 1$, $0 < \alpha\lambda < 2(1 + \beta)$; при $\beta = 0$ — условие GD $0 < \alpha\lambda < 2$. Дискриминант $D = (1 - \alpha\lambda + \beta)^2 - 4\beta$: при $D < 0$, то есть $|1 - \alpha\lambda + \beta| < 2\sqrt\beta$, — затухающие колебания с модулем $\sqrt\beta$; вещественные корни — сумма двух геометрических мод, при отрицательных корнях знак чередуется. Числа: $(0{,}2;\ 0)$ — $x_{k+1} = 0{,}2 x_k$: $0{,}2;\ 0{,}04;\ 0{,}008;\ 0{,}0016$, монотонно. $(0{,}2;\ 0{,}5)$ — $x_{k+1} = 0{,}7 x_k - 0{,}5 x_{k-1}$, $D = -1{,}51$, модуль $\sqrt{0{,}5}$: $0{,}2;\ -0{,}36;\ -0{,}352;\ -0{,}0664$. $(0{,}7;\ 0{,}5)$ — $\alpha\lambda = 2{,}8 < 3$, $x_{k+1} = -1{,}3 x_k - 0{,}5 x_{k-1}$, $D = -0{,}31$: $-1{,}8;\ 1{,}84;\ -1{,}492;\ 1{,}0196$ — колебания сильнее, но огибающая затухает.

## На пальцах
Числа пункта (4): $f(x) = 2x^2$ ($\lambda = 4$), старт $x_{-1} = x_0 = 1$. Градиентный спуск устойчив только при $\alpha\lambda < 2$, то есть при $\alpha < 0{,}5$. Инерция $\beta = 0{,}5$ отодвигает границу до $\alpha\lambda < 2(1 + 0{,}5) = 3$, то есть до $\alpha < 0{,}75$.
- $\alpha = 0{,}7$ без инерции ($\beta = 0$): $x_{k+1} = (1 - 2{,}8)\, x_k = -1{,}8\, x_k$. Получаем $x_0, \dots, x_3 = 1;\ -1{,}8;\ 3{,}24;\ -5{,}832$ — разлёт с качанием знака.
- Тот же $\alpha = 0{,}7$ с $\beta = 0{,}5$: $x_{k+1} = -1{,}3\, x_k - 0{,}5\, x_{k-1}$. Получаем $x_0, \dots, x_5 = 1;\ -1{,}8;\ 1{,}84;\ -1{,}492;\ 1{,}0196;\ -0{,}579$. Корни комплексные с модулем $\sqrt{0{,}5} \approx 0{,}71$ — затухание.
- Граница $\alpha = 0{,}75$, $\beta = 0{,}5$: $p(r) = r^2 + 1{,}5\, r + 0{,}5 = (r + 1)(r + 0{,}5)$, один корень равен $-1$. Здесь $x_k = 3(-1)^k - 2(-0{,}5)^k$: $x_0, \dots, x_4 = 1;\ -2;\ 2{,}5;\ -2{,}75;\ 2{,}875$. Значения качаются между $-3$ и $3$ и не затухают — это и есть $p(-1) = 2(1 + \beta) - \alpha\lambda = 0$.

Почему инерция спасает именно большой шаг. Из $x_1 = -1{,}8$ градиентный шаг дал бы $-1{,}8 - 2{,}8 \cdot (-1{,}8) = 3{,}24$ — перелёт. Инерционная добавка $0{,}5\, (x_1 - x_0) = 0{,}5 \cdot (-2{,}8) = -1{,}4$ направлена против этого шага и возвращает точку к $3{,}24 - 1{,}4 = 1{,}84$. С другой стороны треугольника опасности нет: $p(1) = \alpha\lambda > 0$ при любом $\alpha > 0$, поэтому корень $1$ недостижим. Малый шаг делает метод медленным, но не расходящимся.

Упрощение: здесь одно собственное значение. На квадратичной задаче в $\mathbb R^n$ условие нужно для каждого $\lambda_i$, то есть для $\lambda_{\max} = L$: $\alpha < \frac{2(1 + \beta)}{L}$. Скорость задаёт худший модуль корней по всему спектру ([[Л6 сл11 Настройка heavy ball — модуль корней и спектральная полоса]]). Треугольник на коэффициентах $a$, $\beta$ — в [[Б40 Оба корня внутри единичного круга — треугольник устойчивости]].

![[С6-1 Устойчивость метода тяжёлого шарика — треугольник и итерации.png]]
На что смотреть: слева — область устойчивости на плоскости $(\alpha\lambda, \beta)$. Внутри голубой области корни комплексные с модулем $\sqrt\beta$, слева и справа от неё — вещественные: слева положительные, справа отрицательные. Точки — пары $(\alpha, \beta)$ задачи при $\lambda = 4$: три пары семинара, граница $\alpha = 0{,}75$ на правой стороне и GD с $\alpha = 0{,}7$ за пределами области. Справа — $x_k$ для трёх случаев примера: синие затухают, оранжевые качаются между $\pm 3$, красные (GD) уходят за рамку уже на шаге $4$.

На что смотреть: комплексная плоскость, красные точки — два корня $p(r) = r^2 - (1 - \alpha\lambda + \beta)\, r + \beta$. Ползунок `s` задаёт произведение $\alpha\lambda$, ползунок `b` — инерцию $\beta$. Зелёная окружность — единичная, синий пунктир — окружность радиуса $\sqrt\beta$. При `b` $= 0{,}5$ веди `s` от $0$. При $s = 0$ многочлен равен $(r - 1)(r - \beta)$, и корни стоят в $1$ и $0{,}5$. Дальше они сближаются, при $s \approx 0{,}086$ сливаются и уходят на синюю окружность — там модуль ровно $\sqrt{0{,}5}$. При $s \approx 2{,}914$ они снова сливаются, теперь на отрицательной полуоси, и расходятся. При $s = 3$ один корень выходит через $-1$ — это граница $\alpha\lambda = 2(1 + \beta)$. Поставь `b` $= 0$: остаются корни $0$ и $1 - s$, как у градиентного спуска, и выход через $-1$ происходит уже при $s = 2$.
