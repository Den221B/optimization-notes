# Л3 сл22 Без глобальной L-гладкости

> [!abstract] Утверждение · [[OptChapter_Lecture3_slides.pdf#page=22|сл. 22]]
> Стандартные оценки градиентного метода существенно используют $L$-гладкость. Например, у $f(x) = x^4$ производная $f'(x) = 4x^3$ не липшицева на всём $\mathbb R$. Без глобальной $L$-гладкости нет универсального фиксированного шага и универсальной оценки $O(1/k)$ без дополнительных предположений.
> Возможные варианты: локальная липшицевость градиента на области, где остаются итерации; поиск шага с возвратом; другие предположения о регулярности и другие оценки.

## На пальцах
$f = x^4$, $f'' = 12x^2$ растёт без ограничения — единой $L$ нет. Градиентный шаг $x^+ = x - 4\alpha x^3$ с $\alpha = 0{,}1$:
- из $x_0 = 1$: $x_1 = 1 - 0{,}4 = 0{,}6$, дальше сходится;
- из $x_0 = 3$: $x_1 = 3 - 0{,}4 \cdot 27 = -7{,}8$, потом $x_2 \approx 182$ — расходимость.

Граница: $|x^+| > |x|$, когда $|1 - 4\alpha x^2| > 1$, то есть $|x| > \frac{1}{\sqrt{2\alpha}} \approx 2{,}24$. При любом фиксированном $\alpha$ найдётся старт, с которого шаг слишком велик.

Что делать: поиск с возвратом подберёт шаг в каждой точке. Или ограничиться отрезком $|x| \le 1$, где $f'' \le 12$, и взять $\alpha = \frac{1}{12}$: шаг $x^+ = x - \frac{x^3}{3}$ из отрезка не выводит: $x^+ = x \big(1 - \frac{x^2}{3}\big)$, множитель в скобке от $\frac23$ до $1$, поэтому $|x^+| \le |x| \le 1$, и по индукции все итерации остаются в отрезке, где $f'' \le 12$.

Упрощение: в 1D рост кривизны — рост $f''$ на бесконечности. В $\mathbb R^n$ — рост наибольшего собственного значения гессиана.
