# Л3 сл26 Ньютон на квадратичной функции

> [!abstract] Утверждение · [[OptChapter_Lecture3_slides.pdf#page=26|сл. 26]]
> Для $f(x) = \frac12 x^\top A x - b^\top x$, $A \succ 0$: $\nabla f = Ax - b$, $\nabla^2 f = A$, и шаг Ньютона
> $$x_{k+1} = x_k - A^{-1}(A x_k - b) = A^{-1} b = x^\star .$$
> Метод Ньютона точно минимизирует локальную квадратичную модель. Если функция сама квадратична, модель точна во всём пространстве, и решение находится за один шаг.

## На пальцах
Тот же овраг: $A = \operatorname{Diag}(1, 9)$, $b = 0$, $x^\star = 0$.
- Из $(3, 1)$: $x^+ = (3, 1) - A^{-1}(3, 9) = (3, 1) - (3, 1) = (0, 0)$.
- Из $(-5, 2)$: $\nabla f = (-5, 18)$, $A^{-1}\nabla f = (-5, 2)$ — снова ровно в ноль.
- Для сравнения: градиентный метод с лучшим шагом $0{,}2$ уменьшает ошибку в $1000$ раз за $31$ шаг.

Причина: модель квадратичной функции — она сама, и минимум модели — минимум функции. У неквадратичной $x - \ln x$ один шаг из $0{,}5$ даёт $0{,}75$, а не $1$: нужно несколько шагов.

Упрощение: $A$ диагональна. Для любой $A \succ 0$ формула та же, но $A^{-1} g$ — уже решение системы, а не деление по координатам.
