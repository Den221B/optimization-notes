# Л3 сл13 Сходимость в выпуклом случае (Th 5)

> [!abstract] Theorem 5 · [[OptChapter_Lecture3_slides.pdf#page=13|сл. 13–15]]
> Пусть $f$ выпукла и имеет $L$-липшицев градиент, $x^\star$ — точка минимума. Градиентный метод с $\alpha = 1/L$ даёт
> $$f(x_k) - f^\star \le \frac{L \|x_0 - x^\star\|^2}{2k}, \qquad k \ge 1,$$
> то есть $f(x_k) - f^\star = O(1/k)$. Для точности $\varepsilon$ достаточно $k \ge \frac{L \|x_0 - x^\star\|^2}{2\varepsilon}$ — итерационная сложность по этой оценке $O(1/\varepsilon)$.

## На пальцах
Смысл оценки — бюджет. Сложив оценку по шагам, получаем: сумма всех превышений $f(x_{k+1}) - f^\star$ за $N$ шагов не больше $\frac{L}{2}\|x_0 - x^\star\|^2$.
- Пусть $L = 1$, $\|x_0 - x^\star\| = 10$: бюджет $50$.
- Значения $f(x_k)$ не растут, поэтому последнее превышение — самое маленькое и не больше среднего: $f(x_N) - f^\star \le \frac{50}{N}$.
- За $100$ шагов — не больше $0{,}5$, за $5000$ — не больше $0{,}01$. Каждый следующий верный знак — в $10$ раз больше шагов.

Это только верхняя оценка: на $f = \frac12 x^2$ ($L = 1$) шаг $\frac1L = 1$ приводит в минимум сразу. Оценка $O(1/k)$ описывает худший случай — гладкую выпуклую функцию без сильной выпуклости, с почти плоским дном.

Упрощение: бюджет — одно число на весь путь. В доказательстве он складывается из уменьшений $\|x_k - x^\star\|^2$ по шагам.
