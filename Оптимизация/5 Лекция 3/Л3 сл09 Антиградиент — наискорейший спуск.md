# Л3 сл09 Антиградиент — наискорейший спуск

> [!abstract] Утверждение · [[OptChapter_Lecture3_slides.pdf#page=9|сл. 9]]
> Для единичного направления $p$, $\|p\| = 1$, производная по направлению равна $D_p f(x) = \nabla f(x)^\top p$. По неравенству Коши–Буняковского
> $$\nabla f(x)^\top p \ge -\|\nabla f(x)\|,$$
> и минимум достигается при $p = -\nabla f(x) / \|\nabla f(x)\|$. Антиградиент задаёт направление наиболее быстрого локального убывания в евклидовой геометрии.
> **Градиентный метод:** $x_{k+1} = x_k - \alpha_k \nabla f(x_k)$.

## На пальцах
В точке градиент $\nabla f = (3, 4)$, $\|\nabla f\| = 5$. Скорость изменения $f$ по единичному направлению $p = (\cos\theta, \sin\theta)$ равна $3\cos\theta + 4\sin\theta$.
- $p = -(0{,}6;\ 0{,}8)$ — антиградиент: $-1{,}8 - 3{,}2 = -5$. Быстрее нельзя: по Коши–Буняковскому скорость не меньше $-5$.
- $p = (-1, 0)$: $-3$; $p = (0, -1)$: $-4$ — вниз, но медленнее.
- $p = (0{,}8;\ -0{,}6)$: $2{,}4 - 2{,}4 = 0$ — вдоль линии уровня.

Оговорка «в евклидовой геометрии» существенна: наискорейший — не значит «в сторону минимума». В овраге $f = \frac12(x_1^2 + 9x_2^2)$ из точки $(3, 1)$ антиградиент $-(3, 9)$ смотрит поперёк оврага, а минимум — в направлении $-(3, 1)$ ([[Л3 сл25 Направление метода Ньютона]]).

Упрощение: в 2D направления — точки окружности, минимум скорости виден на графике. В $\mathbb R^n$ — точки единичной сферы, ответ тот же.

```desmos-graph
left=-0.5; right=6.8;
bottom=-6; top=6;
---
y=3\cos(x)+4\sin(x)|blue
y=-5|red|dashed
(\pi+0.9273,-5)|red|label:антиградиент
```
На что смотреть: по горизонтали — угол направления $\theta$ в радианах, по вертикали — скорость изменения $f$. Минимум $-5 = -\|\nabla f\|$ — ровно в направлении антиградиента, $\theta \approx 4{,}07$; нули — два направления вдоль линии уровня.
