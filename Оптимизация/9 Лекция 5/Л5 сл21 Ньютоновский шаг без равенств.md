# Л5 сл21 Ньютоновский шаг без равенств

> [!abstract] Метод · [[OptChapter_Lecture5_slides.pdf#page=21|сл. 21]]
> Для $F_t(x) = t f(x) + \phi(x)$: $\nabla F_t(x) = t \nabla f(x) + \nabla \phi(x)$, $\nabla^2 F_t(x) = t \nabla^2 f(x) + \nabla^2 \phi(x)$. Ньютоновское направление определяется линейной системой
> $$\nabla^2 F_t(x)\, \Delta x_{nt} = -\nabla F_t(x). \qquad (10)$$
> Алгоритмически нужно решать эту систему, а не вычислять обратную матрицу.
> Полный шаг может выйти из строгой внутренности. Поэтому $x^+ = x + \alpha \Delta x_{nt}$, $0 < \alpha \le 1$, причём $\alpha$ сначала выбирают так, чтобы $s_i(x + \alpha \Delta x_{nt}) < 0$ для всех $i$, а затем требуют достаточного уменьшения $F_t$, например линейным поиском.

## На пальцах
«Стена» из [[Б31 Стена вместо ограничения — мост к лекции 5]]: $F_t(x) = t x - \log x$, $F_t' = t - \frac1x$, $F_t'' = \frac{1}{x^2}$. Система (10) даёт
$$\Delta x_{nt} = -\frac{t - 1/x}{1/x^2} = x - t x^2 .$$
В переменной $y = t x$ (в центре $y = 1$) полный шаг $y^+ = 2y - y^2$, то есть $1 - y^+ = (1 - y)^2$.
- Из $y = 0{,}5$: $0{,}5 \to 0{,}75 \to 0{,}9375 \to 0{,}996$ — ошибка $1 - y$ каждый раз возводится в квадрат.
- Из $y = 3$: полный шаг даёт $y^+ = 6 - 9 = -3$ — за стеной, где $F_t$ не определена.
- Шаг $\alpha$ сохраняет $x > 0$, пока $1 + \alpha (1 - y) > 0$, то есть при $y = 3$ нужно $\alpha < \frac{1}{y - 1} = \frac12$. С $\alpha = 0{,}4$: $y = 3 + 0{,}4 \cdot (3 - 9) = 0{,}6$, дальше полными шагами $0{,}84 \to 0{,}974 \to 0{,}9993$.

Упрощение: в 1D условие «остаться внутри» — одно неравенство на $\alpha$. При многих ограничениях $\alpha$ ограничивает ближайшая по ходу шага стена, а потом его ещё уменьшают, добиваясь убывания $F_t$ ([[Л3 сл08 Выбор шага и условие Армихо]]).

На что смотреть: синяя — $F_t(x) = x - \ln x$ при $t = 1$ (центр $x = 1$). Красные точки на оси — первые шаги Ньютона из $a$ по формуле $1 - x_k = (1 - a)^{2^k}$, на графике — значения $F_t$ в них. При $a < 2$ точки сбегаются к $1$ за три-четыре шага. Сдвинь $a$ за $2$: первая же точка выпрыгивает левее стены $x = 0$ — полный шаг без контроля $\alpha$ ломает метод.
