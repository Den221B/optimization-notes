# Л5 сл03 Основная задача лекции

> [!abstract] Постановка · [[OptChapter_Lecture5_slides.pdf#page=3|сл. 3–4]]
> $$\min_{x \in \mathbb R^n} f(x) \quad \text{при} \quad s_i(x) \le 0, \ i = 1, \dots, m, \qquad Ax = b. \qquad (1)$$
> - $f, s_1, \dots, s_m$ выпуклы и достаточно гладкие там, где это потребуется; равенства аффинны.
> - Существует точка, для которой $Ax = b$ и $s_i(x) < 0$ для всех $i$. Это условие типа Слейтера; оно понадобится и для барьерной конструкции, и для связи с двойственностью.
>
> Лекция 2 отвечала на вопрос «какими свойствами обладает решение?», лекция 5 — «как это решение находить?». Методы внутренней точки возникают из уже знакомых объектов — выпуклости, KKT, двойственности и метода Ньютона, — когда задачи с неравенствами решают, двигаясь через внутренность допустимого множества.

## На пальцах
Сквозной пример лекции — задача из [[Л2 сл47 Сквозной пример]]: $\min (x - 2)^2$ при $x \le 1$.
- В форме (1): $f(x) = (x - 2)^2$, одно неравенство $s_1(x) = x - 1 \le 0$, равенств нет, $m = 1$. Ответ из лекции 2: $x^\star = 1$, $\lambda^\star = 2$, $f^\star = 1$.
- Строго допустимая точка есть: $x = 0$, $s_1(0) = -1 < 0$. С неё барьерный метод может стартовать.
- Без неё барьер не построить: у задачи $\min x$ при $x^2 \le 0$ ([[Л2 сл24 Вырожденный пример]]) допустимое множество — одна точка $\{0\}$, и $-\log(-x^2)$ не определён нигде.

Упрощение: в 1D внутренность — интервал $x < 1$, а граница — одна точка. В $\mathbb R^n$ граница — кривые и поверхности $s_i(x) = 0$, и строго допустимая точка должна отстоять от всех сразу.

```desmos-graph
left=-1; right=3;
bottom=-0.5; top=5;
---
x<1|green
y=(x-2)^2|blue
(1,1)|red|label:x* = 1
(0,4)|green|label:строго допустимая x = 0
```
На что смотреть: зелёная полоса — допустимые $x \le 1$, её край $x = 1$ — граница, а $x < 1$ — внутренность. Минимум параболы $x = 2$ лежит снаружи, поэтому решение $x^\star = 1$ — на границе. Точка $x = 0$ лежит во внутренности.
