# Л5 сл22 Ньютон при Ax = b — модель с ограничением

> [!abstract] Утверждение · [[OptChapter_Lecture5_slides.pdf#page=22|сл. 22]]
> Пусть текущая точка допустима по равенствам, $Ax = b$, и $x^+ = x + \Delta x$. Метод Ньютона выбирает $\Delta x$, минимизируя локальную квадратичную модель. По Тейлору
> $$F_t(x + \Delta x) \approx F_t(x) + \nabla F_t(x)^\top \Delta x + \tfrac12 \Delta x^\top \nabla^2 F_t(x)\, \Delta x .$$
> $F_t(x)$ от $\Delta x$ не зависит, поэтому направление — минимум $\nabla F_t(x)^\top \Delta x + \frac12 \Delta x^\top \nabla^2 F_t(x)\, \Delta x$. Но новая точка тоже должна удовлетворять равенствам:
> $$A(x + \Delta x) = b, \quad Ax = b \implies A \Delta x = 0.$$
> Ньютоновское направление — решение условной квадратичной задачи с ограничением $A \Delta x = 0$.

## На пальцах
Аналитический центр отрезка $x_1 + x_2 = 1$, $x > 0$: $F(x) = -\log x_1 - \log x_2$, ответ $(\frac12, \frac12)$. Старт $x = (\frac14, \frac34)$.
- $g = \nabla F = (-4, -\frac43)$, $H = \operatorname{Diag}(16, \frac{16}{9})$.
- Допустимые направления — только $\Delta x = (d, -d)$, иначе $x_1 + x_2 \ne 1$. На них модель $g^\top \Delta x + \frac12 \Delta x^\top H \Delta x = -\frac83 d + \frac{80}{9} d^2$, минимум в $d = \frac{3}{20}$. Новая точка $(0{,}4;\ 0{,}6)$.
- Следующие шаги: $x_1 = 0{,}4 \to 0{,}4923 \to 0{,}499996$; ошибка $0{,}1 \to 0{,}0077 \to 0{,}000004$. Это даже быстрее квадратичной: из $(\frac12 - e, \frac12 + e)$ шаг даёт $e^+ = \frac{2e^3}{\frac14 + e^2}$ — кубическая сходимость, подарок симметрии задачи. Проверка: $\frac{2 \cdot 0{,}1^3}{0{,}26} \approx 0{,}0077$.

Упрощение: здесь направления с $A\Delta x = 0$ образуют прямую, и задача сводится к одной переменной $d$. При $p$ равенствах в $\mathbb R^n$ это подпространство размерности $n - p$, и вместо подстановки решают блочную систему ([[Л5 сл24 Блочная система Ньютона]]).
