# Л5 сл41 Phase I — поиск строго допустимой точки

> [!abstract] Метод · [[OptChapter_Lecture5_slides.pdf#page=41|сл. 41]]
> Чистый логарифмический барьер требует стартовать из точки с $Ax = b$, $s_i(x) < 0$. Такую точку можно заранее не знать, поэтому решению исходной задачи часто предшествует **Phase I** — вспомогательная задача поиска строго допустимой точки. Одна базовая конструкция:
> $$\min_{x, r} r \quad \text{при} \quad s_i(x) \le r, \ i = 1, \dots, m, \qquad Ax = b.$$
> Если найдено $r < 0$, то $s_i(x) \le r < 0$ для всех $i$, следовательно, $x$ строго допустима для исходных неравенств.
> Поиск внутренней стартовой точки — отдельный подготовительный этап, а не бесплатное предположение барьерного метода. Полная организация Phase I требует дополнительных технических деталей; здесь важен сам принцип.

## На пальцах
Ограничения $x \ge 1$ и $x \le d$: $s_1 = 1 - x$, $s_2 = x - d$. Phase I: $\min r$ при $1 - x \le r$, $x - d \le r$, то есть $r \ge \max\{1 - x,\ x - d\}$. Минимум — в середине $x = \frac{1 + d}{2}$, $r^\star = \frac{1 - d}{2}$.
- $d = 3$: $r^\star = -1 < 0$ — точка $x = 2$ строго допустима, с запасом $1$ до обеих стен.
- $d = 1$: $r^\star = 0$ — допустимая точка есть ($x = 1$), но строго допустимой нет: барьер построить нельзя.
- $d = -1$: $r^\star = 1 > 0$ — допустимых точек нет вовсе.

Три исхода говорят о точном оптимуме $r^\star$. Случай $r^\star = 0$ даёт допустимую точку, только если минимум достигается: у ограничения $e^{-x} \le 0$ Phase I $\min r$ при $e^{-x} \le r$ имеет $r^\star = \inf e^{-x} = 0$, а допустимых точек нет. И значение $r \ge 0$ на промежуточной итерации ничего не доказывает: задача Phase I могла быть ещё не решена.

Упрощение: в 1D Phase I решается в уме — это середина отрезка. В общем случае это ещё одна задача оптимизации, и её тоже можно решать барьером: строго допустимая точка для неё есть сразу — любой $x$ с $Ax = b$ и $r > \max_i s_i(x)$.

На что смотреть: синяя — $\max\{1 - x,\ x - d\}$, красная точка — её минимум $r^\star$, зелёный пунктир — уровень $0$. Пока точка ниже пунктира ($d > 1$), строго допустимая точка есть. Тяни $d$ к $1$: точка поднимается на пунктир — внутренность пропала; при $d < 1$ точка выше — ограничения несовместны.
