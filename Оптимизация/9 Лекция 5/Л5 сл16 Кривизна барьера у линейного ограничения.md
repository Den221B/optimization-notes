# Л5 сл16 Кривизна барьера у линейного ограничения

> [!abstract] Утверждение · [[OptChapter_Lecture5_slides.pdf#page=16|сл. 16]]
> Для $s_i(x) = a_i^\top x - b_i$
> $$\nabla^2 \phi_i(x) = \frac{a_i a_i^\top}{(b_i - a_i^\top x)^2}, \qquad d^\top \nabla^2 \phi_i(x)\, d = \frac{(a_i^\top d)^2}{(b_i - a_i^\top x)^2}.$$
> - $a_i^\top d = 0$: $d$ параллельно границе; это ограничение не добавляет кривизны в таком направлении;
> - $a_i^\top d \ne 0$: движение идёт поперёк границы, и кривизна положительна;
> - при $b_i - a_i^\top x \to 0+$ кривизна в направлениях, пересекающих границу, резко возрастает.
>
> Из-за сильной неоднородности кривизны скалярный размер шага градиентного метода может быть неудобен, и для центрирующей задачи естественно обратиться к Ньютону.

## На пальцах
Ограничение $x_1 \le 1$: $a = (1, 0)$, $b = 1$. Точка $x = (0{,}9;\ 0)$, запас $b - a^\top x = 0{,}1$.
- Вдоль границы, $d = (0, 1)$: $a^\top d = 0$, кривизна $0$.
- Поперёк, $d = (1, 0)$: $\frac{1^2}{0{,}1^2} = 100$.
- Наискосок, $d = \frac{1}{\sqrt2}(1, 1)$: $\frac{(1/\sqrt2)^2}{0{,}01} = 50$ — половина: работает только проекция $d$ на нормаль.
- Ближе к стене, $x = (0{,}99;\ 0)$: поперёк уже $10^4$, вдоль — по-прежнему $0$.

Упрощение: одно ограничение даёт кривизну только поперёк себя. Несколько ограничений складываются, и форма «эллипса кривизны» зависит от того, к каким стенам точка ближе.

![[Л5 сл16 — эллипсы кривизны.png]]
На что смотреть: в каждой точке треугольника нарисовано множество направлений $d$ с $d^\top \nabla^2 \phi\, d \le \frac{1}{16}$. Где кривизна большая, эллипс узкий. У стены $x_1 = 0$ он сплющен поперёк неё в щель, у наклонной стены — поперёк наклонной. Где две перпендикулярные стены на равном расстоянии, а третья далеко, кривизна почти одинакова во все стороны — почти круг.
