# Л5 сл44 Возмущённая прямодвойственная система KKT

> [!abstract] Определение · [[OptChapter_Lecture5_slides.pdf#page=44|сл. 44]]
> Пусть $z = (z_1, \dots, z_m)$, $\Lambda = \operatorname{diag}(\lambda)$. Тогда
> $$\nabla f(x) + \sum_i \lambda_i \nabla s_i(x) + A^\top \nu = 0, \quad Ax - b = 0, \quad s(x) + z = 0, \quad \Lambda z - \tfrac1t \mathbf 1 = 0, \quad \lambda > 0, \quad z > 0. \qquad (25)$$
> Естественные невязки:
> $$r_{dual} = \nabla f(x) + \sum_i \lambda_i \nabla s_i(x) + A^\top \nu, \qquad r_{pri,eq} = Ax - b,$$
> $$r_{pri,ineq} = s(x) + z, \qquad r_{cent} = \Lambda z - \tfrac1t \mathbf 1 .$$

## На пальцах
Сквозной пример в переменных $(x, \lambda, z)$ при $t = \frac85$, $\frac1t = \frac58$. Равенств нет, поэтому невязки три:
$$r_{dual} = 2(x - 2) + \lambda, \qquad r_{pri,ineq} = x - 1 + z, \qquad r_{cent} = \lambda z - \tfrac58 .$$
- Точка $(0, 1, 2)$: $r_{dual} = -3$, $r_{pri,ineq} = 1$, $r_{cent} = \frac{11}{8}$ — нарушено всё.
- Центр для старого $t = \frac23$, точка $(\frac12, 3, \frac12)$: $r_{dual} = 0$, $r_{pri,ineq} = 0$, $r_{cent} = \frac32 - \frac58 = \frac78$. Нарушено только центрирование.
- Новый центр $(\frac34, \frac52, \frac14)$: все три невязки равны нулю.

Упрощение: здесь три скалярных уравнения. В лекции это блоки размеров $n$, $p$, $m$, $m$, а неизвестных $(x, \lambda, \nu, z)$ — всего $n + 2m + p$, столько же, сколько уравнений.
