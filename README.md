# Дополнительные главы оптимизации — карта знаний

Obsidian-хранилище по курсу «Дополнительные главы оптимизации» ([страница курса](https://www.hse.ru/edu/courses/1163624977)), преподаватель — Алия Джанабекова. Курс разобран целиком: от школьной выпуклости до условия Поляка–Лоясиевича. У каждого утверждения есть формулировка со слайда, пример, который можно прокрутить в голове, и картинка. У каждого экзаменационного вопроса — полный ответ и путь подготовки от базы.

## Что внутри

| | |
|---|---|
| **База** | 46 заметок: линал, анализ, ряды, вероятность — то, без чего лекции не читаются |
| **Лекции 1–7** | 233 заметки, по одной на определение и утверждение |
| **Семинары 1–6** | 34 задачи с итогом семинара |
| **Экзамен** | 38 вопросов программы: полный ответ с доказательством, «на пальцах», типичные ошибки, самопроверка с ответами |
| **Гейты** | 140 пунктов «умею без подсказки», по гейту на лекцию |
| **Маршруты** | `Маршрут Л1–Л7.canvas` — учебные блоки по ступеням: слева база, стрелка «A освоить перед B» |
| **Пути к вопросам** | для каждого из 38 вопросов — упорядоченный список блоков, от 7 до 61 шага |
| **Картинки** | около 100 PNG и GIF, больше 150 интерактивных графиков с ползунками |

Все числа в примерах проверены в sympy. Примеры «на пальцах» прошли отдельную проверку агентом-судьёй, доказательства в карточках экзамена — независимого рецензента.

## Как открыть

1. Склонировать репозиторий и открыть его папку в Obsidian: «Open folder as vault».
2. Поставить плагин **Live Plots**. Без него графики `desmos-graph` видны как код.
3. Начать отсюда:
   - `Оптимизация/00 Оптимизация — маршрут.md` — порядок изучения;
   - `Оптимизация/Маршрут Л1.canvas` — то же картинкой;
   - `Оптимизация/00 Оптимизация — экзамен.md` и `00 Оптимизация — пути к вопросам.md` — подготовка к экзамену;
   - `Оптимизация/00 Оптимизация — гейты.md` — проверить себя перед следующей лекцией.

GitHub не отрисует ссылки `[[…]]`, холсты `.canvas` и графики — смотреть в Obsidian.

## Как устроена заметка

1. Формулировка со слайда со ссылкой на страницу.
2. «На пальцах» — один пример в 1D или 2D, числа считаются в уме. По возможности показано, что ломается без условия.
3. Картинка или график с ползунком — если у понятия есть форма.
4. Внизу свёрнутый блок «Мои заметки» — пустой, для своих слов.

## Как сделано

Хранилище собрано вместе с двумя ИИ-агентами, Den221B вёл работу и принимал решения:
- **Claude** (Anthropic) — заметки базы и лекций, примеры «на пальцах», картинки, карточки экзамена, гейты, ревью маршрутов;
- **GPT / Codex** (OpenAI) — холсты-маршруты лекций и общий граф курса, карта экзамена, «Пути к вопросам».

Агенты проверяли работу друг друга. Числа сверены в sympy, примеры прошли отдельную проверку агентом-судьёй, доказательства в карточках экзамена — независимого рецензента. Ошибки всё равно возможны — issues и pull requests приветствуются.
